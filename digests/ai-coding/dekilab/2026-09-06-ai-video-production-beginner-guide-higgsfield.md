## 요약 (주제별)

### 1. 이 영상의 전제 — AI 영상 제작 워크플로의 세대 교체
- **예전 방식**: 프롬프트를 계속 바꿔가며 ① 이미지 모델에서 이미지 생성 → ② 영상 모델로 옮겨 컷을 하나씩 생성 → ③ 음성 별도 제작 → ④ 편집. 다단계 수작업이 필수였다.
- **지금 방식**: 영상에 넣을 **이미지만 레퍼런스로 첨부**하고 프롬프트 한 번 입력하면 훨씬 높은 품질의 결과가 나온다는 것이 화자의 핵심 주장([00:18], 주장/미검증).
- 대상 독자는 명시적으로 **AI 영상 제작 입문자**이며, 여러 장르를 실제로 만들어 보이며 원리를 잡아주는 구성.

### 2. 도구 선택 — Higgsfield(올인원 AI 스튜디오)
- 자막에서는 "익스필드/히스필드/익스프레드"로 오인식되나 문맥상 **Higgsfield**. 이미지·비디오 및 기타 기능을 한곳에 모은 **올인원 스튜디오**로 소개된다.
- 선택 근거: 원래는 이미지는 이미지 사이트, 비디오는 비디오 사이트로 이동해야 했는데 올인원 덕분에 제작이 효율화됐다는 것.
- [의견] "강력한 기획력과 마케팅을 바탕으로 정말 매일같이 업데이트되고 있다"는 화자 평가.
- 그 외 기능으로 **Higgsfield MCP · 슈퍼 컴퓨터 · 마케팅 스튜디오**가 있다고 이름만 언급하고, 상세는 자신의 다른 영상으로 넘긴다(자기 채널 내부 유입).

### 3. 입문자 셋업 — 한글화 + 두 탭 원칙 + 추천 모델
- **한국어 설정**: 페이지 **가장 하단**에서 언어 변경. "번역이 안 돼 쓰기 어렵다"는 반응이 많았지만 이제 한글 버전 제공.
- **두 탭 원칙**: 영상 제작이 목적이면 **좌측 상단의 이미지 탭 / 비디오 탭 두 개만** 본다. 나머지는 비디오를 한 번 만들어 보고 부족함을 느낄 때 하나씩 확장.
- **추천 모델 조합**: 이미지 = **GPT Image 2**, 비디오 = **Seedance 2.5**(자막 "시덴스"). 근거는 "2026년 9월 기준 가장 성능이 괜찮은 모델로 알려져 있다"(주장/미검증). 덕분에 입문자 프롬프트가 부실해도 결과가 괜찮게 나온다는 논리.

### 4. 시작 분기 — 이미지부터 vs 바로 비디오
- **얼굴·배경·제품이 이미 정해진 경우**: 이미지 탭에서 그 요소들을 먼저 생성 → 그 이미지를 비디오 모델의 레퍼런스로 투입.
- **아이디어를 빨리 눈으로 확인하고 싶은 경우**: 이미지 단계를 건너뛰고 곧장 비디오 생성 모델로.

### 5. 실전 절차 A — 이미지 생성 (광고 사례)
- 이미지 탭 → GPT Image 2 선택 → 이미지 생성 화면 진입. 처음 쓰면 **아무 이미지도 없는 상태가 정상**.
- 하단 프롬프트 창에 장면을 입력하고, **모델 · 가로세로 비율 · 생성 개수**를 정한 뒤 우측 **생성하기** 클릭. 버튼 옆 숫자는 **소모 크레딧**.
- 예시 프롬프트: "오이 그리고 민트맛 탄산음료, **'오이오이'**라고 적혀 있음". 화자 조언은 "너무 고민하지 말고 상상되는 내용을 그냥 적어라"([04:08]).
- **수정 방법**: 이미지 하단 **레퍼런스 버튼** → 고칠 내용 기술. 예: "파란색 에너지 음료 느낌으로 바꾸어 줘" → 기존 느낌만 교체된 결과물.
- **모델(인물) 이미지**: 특정 얼굴을 계속 재사용하려면 인물 이미지를 만들어 둔다. 예: "아이돌 스타일의 20대 한국 여성, 그린 계열 여름 복장". 생김새·피부색·옷차림도 같은 방식으로 수정 가능.
- **배경 이미지**: 배경을 고정하려면 배경도 따로 생성. 예시는 단순히 "경포 해변".

### 6. 실전 절차 B — 비디오 생성과 파라미터
- 상단 **비디오 탭** → Seedance 2.5 선택 → 하단 **레퍼런스 추가하기** → 이미지 생성 탭에서 만들어 둔 이미지들을 **모두 선택**.
- AI 생성 이미지가 아니어도 됨: **판매할 제품 사진이나 내 테스트 이미지**를 그대로 첨부해도 동일하게 동작.
- 설정 항목: **비디오 생성 길이 · 비율 · 해상도**. 값 지정 후 비디오 프롬프트 입력.
- **한 줄 프롬프트 시연**: "오이 음료 광고 영상"만 적어도 Seedance가 첨부된 레퍼런스를 확인하고 학습한 광고 영상들을 바탕으로 광고를 만들어 준다.

### 7. Seedance 2.5의 기능적 진전 (화자 설명, 미검증)
- **멀티샷**: 여러 샷·여러 구도를 자동 생성. 기존 모델은 "한 샷, 한 구도에서 정해진 시간만큼"만 나와서, 구간마다 첫 이미지를 따로 만들고 비디오화하는 반복 작업이 필요했다.
- **오디오 레퍼런스**: 이미지·영상뿐 아니라 **오디오까지 첨부** 가능. 첨부한 오디오가 생성 영상에 함께 들어간다.
- **립싱크**: 성능이 대폭 향상되어, 첨부한 음악 파일에 맞춰 "립싱크를 한다"는 **프롬프트 한 줄**만으로 자연스러운 결과.
- **길이**: 최대 **30초**. 몇 달 전만 해도 5초, 많아야 10초 수준이었다는 대비.
- **캐릭터 일관성**: 캐릭터를 하나 잡아두면 그 캐릭터로 여러 영상 제작 가능 → **시리즈물**로 확장 가능.

### 8. 프롬프트 전략 — 감 키우기 + AI에게 프롬프트 외주
- **입문 단계**: 복잡하게 쓰지 말고 만들고 싶은 내용만 단순 입력 → 단순 입력 결과와 복잡 입력 결과를 비교하며 감을 키운다.
- **디렉팅 단계**: 예시 15초 영상 기준으로 **어떤 샷·어떤 구도·어떤 내레이션**이 들어갈지를 프롬프트에 명시.
- **AI 외주 루프**: 프롬프트 작성이 어려우면 **아무 AI나** 켜서("어떤 AI든 상관없습니다" [08:04]) 만들고 싶은 영상을 설명하고 프롬프트 제작을 요청. 생각나는 내용 정도만 줘도 된다.
- **반복 수정**: 나온 프롬프트를 읽고 결과물을 상상해 본 뒤, "바다를 배경으로 해 줘" 식으로 AI에게 재요청해 묘사를 하나씩 고쳐 나간다. 완성된 프롬프트를 복사해 넣으면 **디렉팅이 반영된 결과물**이 나온다.

### 9. 비용·리스크 주의
- **비디오 생성은 이미지 생성보다 크레딧 소모가 훨씬 크다**는 점을 명시적으로 경고([06:29]).
- 소모량은 **영상 길이와 해상도에 비례**해 증가한다. 즉 긴 고해상도 영상을 반복 시도하는 것이 비용의 주 원인.

### 10. 시연된 세 장르 결과물
- **광고**: 오이·민트맛 가상 탄산음료 "오이오이". 한 줄 프롬프트 버전과 AI로 다듬은 디렉팅 버전 두 가지를 비교 재생. 후자에는 내레이션("오이오이, 상쾌한 바람처럼" [09:19])이 들어간다.
- **뮤직비디오**: 여자 5인조 아이돌 + 강원도 강릉 배경. 아이돌 이미지 + 강릉 장소 이미지 + 음원을 레퍼런스로 동시 투입. 이후 립싱크 버전도 시연. (가사 채록은 자동자막 뭉개짐으로 `[불명확]`)
- **드라마/브이로그**: "요즘 유행인 갸루 스타일" 캐릭터의 화장품 파우치 소개 브이로그. 일관된 캐릭터로 구어체 대사 연기.
- [의견] 화자 평가: "확실히 어색했던 과거의 모습과는 전혀 다른 고퀄리티", "연기나 표정들도 무척 자연스럽다".

### 11. 결론과 세일즈 구조
- 영상의 한 줄 결론: **레퍼런스가 프롬프트와 만나면서** 한층 더 고퀄리티 결과물이 나온다([12:01]).
- 세일즈/유입 장치(정보로서 1회 기록): ① Higgsfield **영상 설명란 링크**로 바로 시작 유도(제휴 여부는 영상에서 언급되지 않음), ② 다른 기능은 **자기 채널의 다른 영상**으로 유도, ③ 질문은 **댓글**로, ④ **좋아요** 요청.

## 3줄 오리엔테이션
- AI 영상 제작이 "이미지 따로 → 영상 컷 따로 → 음성 따로 → 편집"의 다단계 노가다에서 "레퍼런스 이미지 몇 장 + 프롬프트 한 번"으로 압축됐다는 것이 이 영상의 전제다.
- 도구는 Higgsfield(자막 표기 "익스필드/히스필드") 하나로 통일하고, 입문자는 좌측 상단의 **이미지 탭**과 **비디오 탭** 딱 두 개만 보라고 못 박는다. 추천 모델은 이미지 = GPT Image 2, 비디오 = Seedance 2.5(2026년 9월 기준, 화자 주장).
- 광고 / 뮤직비디오 / 일상 브이로그 드라마 세 장르를 실제로 만들어 보이며, Seedance 2.5의 멀티샷·오디오 레퍼런스·립싱크·최대 30초 길이·캐릭터 일관성을 하나씩 시연한다.

## 전문 — 시간순 워크스루

### [00:00–00:34] 문제 제기 — 예전 워크플로 vs 지금
화자는 AI 모델 발전으로 이제 "정말 간단한 방법으로 고퀄리티 영상"을 만들 수 있게 됐다고 연다. 예전에는 영상 하나를 만들려면 프롬프트를 계속 바꿔가며 이미지 모델에서 이미지를 뽑고, 영상 모델로 옮겨 컷을 하나씩 뽑고, 음성까지 따로 만들어 편집까지 해야 했다는 것.

> "이젠 영상 속에 넣을 이미지만 [레퍼런스]로 넣어 두고 프롬프트만 입력하면 훨씬 더 수준급 고퀄리티의 영상이 나오기 시작했습니다." [00:18]

그래서 이 영상의 목적은 "AI 영상 제작을 처음 시작하는 분들"에게 여러 장르의 제작 과정을 직접 보여주며 시작점을 잡아주는 것이라고 밝힌다.

### [00:34–01:04] 도구 소개 — Higgsfield는 올인원 AI 스튜디오
오늘 사용할 도구는 Higgsfield(자막 오인식: "익스필드/히스필드/익스프레드")다. 이미지부터 비디오, 그 외 여러 기능을 한곳에 탑재한 **올인원 AI 스튜디오**라고 소개한다. [의견] 화자는 이 서비스가 "강력한 기획력과 마케팅을 바탕으로 정말 매일같이 업데이트되고 있다"고 평가한다. 원래는 이미지는 이미지 생성 사이트, 비디오는 비디오 생성 사이트로 각각 이동해야 했지만, 올인원 스튜디오 덕분에 한층 효율적으로 결과물을 만들 수 있게 됐다는 것이 도구 선택의 근거다.

### [01:04–01:28] 첫 셋업 — 한국어 설정부터
사용 전 가장 먼저 할 일로 **한글 설정**을 꼽는다. "번역이 안 돼서 쓰기 어렵다, 영어가 너무 불편하다"는 반응이 많았는데, 이제 한글 버전을 제공한다는 것. 페이지 **가장 하단**으로 내려가면 언어를 한국어로 바꿀 수 있고, 영어로 돼 있다면 한국어로 전환한 뒤 쓰면 훨씬 편하다고 안내한다.

### [01:28–02:03] 입문자는 두 탭만 보면 된다
기능이 많아 처음 들어오면 어디부터 손대야 할지 막막할 수 있다는 점을 인정하면서, AI 영상 제작이 목적이라면 **좌측 상단의 이미지 탭과 비디오 탭 딱 두 가지만** 보라고 정리한다. 나머지 기능은 일단 비디오를 만들어 보고 부족함을 느낄 때 하나씩 시도하라는 순서. 그 외 기능으로 **Higgsfield MCP, 슈퍼 컴퓨터, 마케팅 스튜디오** 등이 있다고 이름만 언급하고, 궁금하면 자신의 다른 영상들을 참고하라고 안내한다(자기 채널 내부 유입 안내).

### [02:03–02:22] 추천 모델 조합 — GPT Image 2 + Seedance 2.5
모델 선택에서 헤매지 말라며 조합을 지정해 준다. 이미지 모델은 **GPT Image 2**, 비디오 모델은 **Seedance 2.5**(자막 오인식 "시덴스 2.5")로 시작할 것을 추천한다. 근거는 "현재 2026년 9월 기준으로 가장 성능이 괜찮은 모델들로 알려져 있기 때문"(주장/미검증). 그래서 입문자로서 프롬프트가 조금 부족해도 좋은 결과물이 나올 수 있다는 논리다.

### [02:22–02:55] 분기 판단 — 이미지부터? 바로 비디오?
만들고 싶은 영상이 뭔지만 알면 된다며, 먼저 확인할 갈림길 하나를 제시한다.
- **얼굴·배경·제품이 이미 정해져 있는 경우**: 이미지 탭에서 그 요소들의 이미지를 먼저 만들고, 그 이미지를 비디오 생성 모델에 넣어 영상으로 만든다.
- **아이디어를 일단 결과물로 빨리 보고 싶은 경우**: 이미지 단계를 건너뛰고 바로 비디오 생성 모델로 간다.

### [02:55–03:08] 오늘 만들 세 가지 장르
오늘은 **광고 영상 / 뮤직비디오 / 드라마(스토리) 같은 영상**을 하나씩 만들어 보면서 "이런 식으로 영상을 만들 수 있구나" 하는 원리를 확인하면 된다고 구성을 예고한다. 먼저 광고 영상부터.

### [03:08–03:45] 이미지 생성 화면 구조와 크레딧 표시
좌측 상단 이미지 탭에서 GPT Image 2 모델을 고르면 곧바로 이미지 생성 탭으로 넘어간다. 화자 화면에는 미리 만들어 둔 이미지들이 떠 있지만, 처음 쓰는 사람은 **아무 이미지도 없는 상태가 정상**이라고 짚어준다. 하단에는 프롬프트 입력창이 있고, 상상하는 장면을 여기에 적은 뒤 이미지 모델 · 가로세로 비율 · 생성 개수를 정하고 오른쪽 **생성하기** 버튼을 누르면 된다. 버튼 옆의 숫자는 **소모되는 크레딧**을 뜻한다.

### [03:45–04:16] 실습 1 — 오이맛 탄산음료 광고 이미지
예시로 탄산음료 광고를 잡는다. "오이맛 탄산음료가 생각났다"고 가정하고, 프롬프트에 **"오이 그리고 민트맛 탄산음료, '오이오이'라고 적혀 있음"** 식으로 상상되는 내용을 적는다.

> "이런 식으로 상상되는 내용들을 너무 고민하지 마시고 적어 주시면 됩니다." [04:08]

이렇게 생성하면 프롬프트에 적은 대로의 결과물을 받아볼 수 있다는 시연.

### [04:16–04:35] 이미지 수정 — 레퍼런스 버튼으로 재생성
생성된 이미지를 고치고 싶으면 이미지 하단의 **레퍼런스 버튼**을 눌러 수정하고 싶은 내용을 적으면 된다. 예시로 "파란색 에너지 음료 느낌으로 바꾸어 줘"라고 요청하니 기존 이미지의 느낌만 바꾼 결과물로 교체돼 나온다.

### [04:35–05:09] 광고 모델(인물) 이미지 만들기
광고에 등장할 인물 모델도 만들어 둔다. 특정 얼굴을 고집하지 않는다면 곧장 비디오 생성으로 넘어가도 되지만, **한 모델을 정해두고 계속 재사용**하고 싶다면 인물 이미지를 하나 만들어 두는 게 좋다는 조언. 예시 프롬프트는 "아이돌 스타일의 20대 한국 여성, 그린 계열의 여름 복장을 착용하고 있는 이미지". 수정하고 싶으면 앞서와 같이 해당 이미지를 첨부해 생김새·피부색·옷차림 등을 바꿀 수 있다.

### [05:09–05:23] 배경 이미지까지 지정하기
광고가 진행될 배경도 고정하고 싶다면 배경 이미지도 만들어 둔다. 예시는 간단히 **"경포 해변"** 정도로 입력. 이렇게 해두면 모델이 임의로 고른 배경이 아니라 내가 지정한 배경에서 나온 결과물을 확인할 수 있다.

### [05:23–05:59] 비디오 탭으로 이동 — 레퍼런스 첨부
이미지를 다 만들었으면 상단 **비디오 탭**으로 넘어간다. 모델은 추천대로 **Seedance 2.5**를 선택하고, 하단의 **레퍼런스 추가하기** 버튼을 누른 뒤 이미지 생성 탭으로 가면 아까 만들어 둔 이미지들이 보인다. 제작한 이미지들을 **모두 선택**해 넣으면 된다. AI로 만든 이미지가 아니라 판매할 제품 사진이나 테스트해 볼 내 이미지가 있다면, 그 이미지를 그대로 첨부해도 똑같이 동작한다.

### [05:59–06:16] 비디오 파라미터 — 길이·비율·해상도
아래로 내리면 **비디오 생성 길이, 비율, 해상도** 등을 설정할 수 있다. 좌측에서 원하는 길이를 고르고 적절한 값들을 넣은 다음, 이미지 때와 마찬가지로 **비디오 프롬프트**를 입력한다.

### [06:16–06:29] 입문자 프롬프트 전략 — 감 키우기
처음 비디오를 만들 때는 복잡한 내용보다 **만들고 싶은 내용만 단순하게** 넣어보라고 권한다. 간단히 입력했을 때 나오는 결과와 복잡하게 입력했을 때 나오는 결과를 비교하며 "이 정도까지 나오는구나" 하는 감을 키워 나가는 방식.

### [06:29–06:41] 크레딧 경고 — 비디오는 이미지보다 훨씬 비싸다
비디오 생성은 이미지 생성보다 **크레딧 소모가 훨씬 크기** 때문에 주의하라고 명시적으로 경고한다. 소모량은 **영상의 길이와 해상도에 비례**해서 커진다.

### [06:41–07:10] 실습 2 — 한 줄 프롬프트로 광고 뽑기
프롬프트에 **"오이 음료 광고 영상"** 정도만 적고 생성해 보면, Seedance가 앞서 넣은 레퍼런스들을 확인하고 지금까지 학습한 광고 영상들을 바탕으로 광고 영상을 만들어 준다. 이어 결과 영상이 재생된다(약 [06:54]–[07:10] 구간, 나레이션 없는 광고 컷).

### [07:10–07:38] Seedance 2.5의 멀티샷 — 컷 나눠 만들 필요가 사라졌다
Seedance 2.5는 **멀티샷**을 지원해 여러 샷·여러 구도의 영상을 자동으로 만들어 준다. 기존 모델들은 **한 가지 샷, 하나의 구도에서 정해진 시간만큼만** 결과물이 나오는 경향이 있어서, 영상이 진행되는 부분마다 첫 이미지를 따로 생성하고 그걸로 비디오를 만드는 과정이 반복적으로 필요했다는 것. 지금은 간단한 프롬프트만으로도 그 과정 없이 뛰어난 결과물이 나온다는 대비다.

### [07:38–07:54] 디렉팅하려면 프롬프트를 구체화해야 한다
자동에 맡기지 않고 직접 디렉팅하고 싶다면 당연히 프롬프트를 조금씩 구체화해야 한다. 예시 기준으로 **15초짜리 영상 동안 어떤 샷에, 어떤 구도에, 어떤 내레이션이 들어갈지**를 프롬프트에 적어 넣는 방식이다.

### [07:54–08:28] 프롬프트를 AI에게 대신 짜게 하기
그런데 처음 영상을 만드는 입장에서 원하는 내용을 프롬프트에 전부 담기는 쉽지 않다. 그래서 **AI로 프롬프트를 구체화**하는 우회로를 제시한다.

> "AI는 어떤 AI든 상관없습니다. 이미 사용하고 있는 AI를 켜 주시면 되는데요." [08:04]

만들고자 하는 영상을 설명하면서 프롬프트를 제작해 달라고 요청하면 되고, 이때 **지금 생각나는 내용 정도만** 넣어 요청해도 AI가 그 내용을 포함한 프롬프트를 만들어 준다.

### [08:28–08:55] AI 프롬프트 반복 수정 루프
생성된 프롬프트를 보고 고치고 싶은 게 있으면 AI에게 다시 요청해 수정한다. 예시로 "바다를 배경으로 해 줘"라고 하니 AI가 바다 배경 결과물이 나오도록 프롬프트를 바꿔 준다. 화자는 생성된 프롬프트를 **읽어 보며 어떤 결과물이 나올지 한 번 더 상상해 보고**, 수정 사항이 있으면 프롬프트에 묘사된 내용을 하나씩 고쳐 나가라고 권한다.

### [08:55–09:21] 디렉팅 프롬프트로 재생성한 광고 결과
수정된 프롬프트를 복사해 붙여 넣고 생성하면, 간단한 한 줄 프롬프트가 아니라 **내 디렉팅이 들어간 결과물**이 나온다. 결과 영상이 재생되며 내레이션이 들어간다.

> "오이오이, 상쾌한 바람처럼" [09:19]

### [09:21–09:52] 실습 3 — 오디오 레퍼런스로 뮤직비디오 만들기
Seedance 2.5는 레퍼런스로 이미지나 영상뿐 아니라 **오디오까지 첨부**할 수 있다. 오디오를 붙이면 생성될 영상에 그 오디오가 함께 들어간다. 예시로 **여자 5인조 아이돌이 강원도 강릉을 배경으로 촬영한 뮤직비디오**를 만들고 싶다면, 레퍼런스에 아이돌 이미지들 + 강릉을 표현하는 장소 이미지들 + 뮤직비디오에 쓸 음원을 함께 넣으면 그 레퍼런스들이 반영된 결과물이 나온다.

### [09:52–10:15] 생성된 뮤직비디오 재생
만들어진 뮤직비디오가 재생된다. 여름·바다·태양을 소재로 한 가사의 곡이 흐르고 아이돌 그룹 영상이 이어진다. [불명확: 자동자막의 가사 채록이 심하게 뭉개져 있어 정확한 가사는 확인 불가 — 원문 "기는 건 능이도록 아름다운", "통의 빛 하얀 파도의 실어보는 우리의 꿈", "매일이 선물 같은 여름", "망설리지 말고 지금 순간을"]

### [10:15–10:38] 립싱크 기능 — 프롬프트 한 줄로
Seedance 2.5에서는 **립싱크 기능 성능도 대폭 향상**되어, 첨부한 음악 파일에 맞춰 "립싱크를 한다"는 프롬프트만 줘도 자연스러운 결과물이 나온다고 설명한다. 이어 립싱크된 결과 영상이 재생된다("가슴이 [불명확] 멈출 수 없어 / 온 세상이 우리를 축복해 / 두 손을 맞잡고" [10:26]–[10:38]).

### [10:38–11:02] 품질·길이 진전 — 최대 30초
결과물에 대해 화자는 "확실히 어색했던 과거의 모습과는 전혀 다른 고퀄리티"라고 평가한다([의견]). 그리고 **영상 생성 길이가 최대 30초까지**로 꽤 넉넉해졌다는 점을 강조한다. 몇 달 전까지만 해도 **5초, 많아야 10초** 정도로 제한적이었는데, Seedance 모델을 기준으로 더 고퀄리티에 더 긴 영상을 손쉽게 생성할 수 있게 됐다는 비교(주장/미검증).

### [11:02–11:27] 캐릭터 일관성 — 시리즈물로 확장
뛰어난 **일관성 유지 능력** 덕분에 캐릭터를 하나 잡아두면 그 캐릭터로 여러 영상을 만들 수 있고, 그래서 **하나의 시리즈물**로 영상 제작을 이어갈 수 있다고 설명한다. 예시로 "요즘 유행인 갸루 스타일 캐릭터"가 여러 일상 브이로그를 담는 영상들을 만든다고 할 때, 해당 레퍼런스를 넣고 생성하면 모델의 일관성이 유지된 결과물이 쉽게 나온다.

### [11:27–11:54] 생성된 브이로그 드라마 클립
갸루 캐릭터의 화장품 파우치 소개 브이로그 클립이 재생된다. 캐릭터가 화장품을 꺼내 보이며 "풀메는 집에서 하고 밖에서는 립이랑 컨실러만 고친다", "[불명확: 원문 '오사카는 습에서'] 오후 되면 컬이 다 풀려서 카페 화장실에서 빠르게 다시 만다", "밥 먹고 나면 한 번 더 뿌린다"는 식의 자연스러운 구어 대사를 이어간다.

> "저처럼 귀여워지려면 이 정도는 해야죠. 그럼 다녀올게요." [11:50]

### [11:54–12:06] 마무리 평가 — 레퍼런스 × 프롬프트
화자는 영상 속 **연기나 표정도 무척 자연스럽다**고 평가하며([의견]), 결국 **레퍼런스가 프롬프트와 만나면서** 한층 더 고퀄리티의 결과물이 나오고 있는 것이라고 이 영상의 원리를 한 문장으로 정리한다.

### [12:06–12:22] CTA — 설명란 링크·댓글·좋아요
마지막으로 오늘 소개한 Higgsfield는 **영상 설명란에 링크**해 뒀으니 바로 시작해 볼 수 있다고 안내하고(세일즈/유입 장치 — 제휴 여부는 영상에서 언급되지 않음), 따라 만들다 궁금한 점이 있으면 언제든 댓글로 질문해 달라고 한다. 도움이 됐다면 좋아요를 눌러 달라는 요청으로 마친다.
