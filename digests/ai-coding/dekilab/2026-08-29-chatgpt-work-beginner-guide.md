## 요약 (주제별)

### 챗지피티 워크란 무엇인가 — 챗 모드와의 차이
- 우리가 아는 챗지피티는 **채팅창에 질문하면 답변하는 대화형 AI(챗 탭)**. 비교적 최근 출시된 **워크(Work) 탭**은 내 PC 안 폴더·파일에 **직접 접근해 생성·수정·삭제**하는 도구다.
- 핵심 효용: 지금까지 한 땀 한 땀 만들던 작업물을 **프롬프트(한국어 요청)만으로** AI가 대신 만든다. 코드 한 줄, 개발자 도구(터미널·IDE) 불필요.
- 데스크톱 앱 상단에 챗 / 워크 탭이 나뉘어 있고, 이 영상은 워크 탭만 다룬다.

### 왜 워크로 입문하나 — 화자가 든 3가지 이유 (전부 화자 주장)
- **무료로 바로 테스트 가능** — 시작·테스트에 별도 유료 구독 불필요.
- **토큰 소모가 적음** — 구독 후 여러 작업을 시킬 때 "비슷한 격"의 클로드 쪽 도구보다 토큰이 덜 소모되는 것으로 "알려져 있다"(미검증, 비교 대상은 `[불명확: 원문 "클로드 코워크"]`).
- **접근성** — 개발자 도구 없이 **앱으로 바로** 시작. 마무리에서도 "현시점 개발 안 하는 일반인에게 접근성이 가장 좋은 AI 툴"이라고 평가([의견]).

### 설치·초기 세팅 절차
- 검색창에 "챗지피티 데스크탑" 검색 → 다운로드 페이지 → **OS에 맞춰 다운로드**(윈도우면 윈도우 버튼) → 설치 파일 더블 클릭 설치 → 앱 실행 → **로그인**(기존 계정 / 구글 계정 / 휴대전화 번호).
- **프로젝트 만들기**: 프로젝트 선택 → 새 프로젝트 → **폴더 추가**로 내 PC에 빈 폴더 생성·선택(화자는 "챗지피티 워크" 폴더) → 프로젝트 이름 입력(화자는 "실습") → 프로젝트 만들기.
- 개념 정리: **프로젝트 = 수행할 작업의 이름**, **선택한 폴더 = 그 작업이 이뤄지는 공간**.

### 설정값 — 모델 / 추론 강도 / 속도
- **모델** = 챗지피티의 "두뇌". 요청 작업을 얼마나 똑똑한 두뇌로 수행할지. **목록 아래→위로 갈수록 더 똑똑한 모델**.
- **추론 강도** = 선택한 모델이 얼마나 "머리를 쥐어짜서" 결과를 낼지.
- **속도** = 추론 강도와 별개로 얼마나 빨리 처리할지. **"빠름" 선택 시 사용량이 더 빨리 소모**된다는 주의.
- 초보 권장: 나머지는 그대로 두고 모델만 바꿔 시작(`[불명확: 원문 "5.6 루나"]`). 유료 사용자는 상위 모델도 무방(`[불명확: 원문 "테라나 솔 모델"]`).

### 권한 3단계 — "나 대신 승인"으로 시작
- **승인 요청**: 작업 폴더 내용을 수정할 때마다 사용자에게 매번 허락을 받는 모드.
- **나 대신 승인**: AI가 문제없다고 판단한 부분은 알아서 진행하고 위험해 보이는 것만 허락을 받는 구조. **처음 시작하는 사람에게 화자가 추천**하는 설정.
- **전체 권한**: 인터넷 연결·파일 삭제까지 모든 권한 위임.
- 참고: 이 대목과 후반 컴퓨터 유즈 시연에서 화자가 주체를 "클로드"라고 말하는 **말실수**가 두 차례 있다(문맥상 챗지피티).

### 실습 ① 회의록 → 공유용 대시보드 웹사이트
- 상황 설정: 회의를 간단히 메모하거나 녹음기로 통째 녹음해 두는 실무 관행. 여기서는 **가상의 회의 녹취록**을 사용.
- 절차: **프로젝트 폴더에 녹취록 파일을 넣고** → "이 폴더 안 회의 녹취록 파일을 읽고 회의록으로 정리해 줘"라고 요청 → GPT가 파일을 읽고 **핵심 결정 사항·후속 일정**을 정리한 회의록을 **그 폴더 안에 파일로 생성**.
- 확장: "방금 만든 회의록을 **대시보드 웹사이트** 형태로 만들어 줘" → 회의 내용이 들어간 대시보드 생성 → **공유 링크** 요청 시 팀원과 공유 가능. 내부적으로는 복잡한 코드가 쓰였지만 사용자는 "해 줘"만 했다는 점을 강조.

### 실습 ② PPT 제작 — "디자인 문서" 재사용 원리
- 절차: 기존에 쓰던 **PPT 디자인을 프로젝트 폴더에 넣고** → "폴더 안 PPT 디자인 이미지를 참고해 **나만의 PPT 디자인 문서**를 생성하고, 그 문서를 참고해 '**3분기 주식 시장 전망**' 주제로 PPT를 만들어 줘" 요청. 디자인 문서에는 **색상·글씨체** 등 디자인 요소를 담게 함.
- 결과: 리서치도 함께 요청했기에 **웹에서 팩트 체크를 거친 리서치 정보** + 레퍼런스 디자인이 입혀진 PPT 생성(팩트 체크 품질 검증은 영상에 없음).
- 재사용 원리: **디자인 문서 하나만 있으면** 이후 어떤 주제의 PPT도 같은 디자인으로 생성 가능. **PPT가 아니어도 보고서·리포트 양식**에 동일 적용 가능 — 화자가 "이 원리를 꼭 익히라"고 강조한 지점.
- [의견]/화자 주장(미검증): 화자 본인 워크플로가 "직접 제작"에서 "생성 후 검토만"으로 바뀌었고 **거의 10분 정도**만 써서 결과물을 만든다.

### 실습 ③ 이미지 모델 활용
- 화자 주장: 챗지피티 생태계의 이미지 모델은 성능이 가장 좋은 축이고, **클로드에는 별도 이미지 모델이 없다**는 점이 차별점(모델명 `[불명확: 원문 "GPT 2.0 영 모델"]`).
- **직장인 용례 — 제안서 표지**: 제목·비율·회사 이름·스타일 정도만 입력하면 별도 디자인 과정 없이 표지 이미지 생성. 결과물은 **우측 상단 "열기" 옆 "다른 이름으로 저장"**으로 다운로드.
- **1인 사업자 용례 — 스마트스토어 히어로 이미지**: 딸기 상세 페이지 예시. **가진 사진을 프로젝트 폴더에 넣고** "이 사진 바탕으로 상세 페이지 히어로 이미지 만들어 줘" → 광고용 이미지 즉시 생성.
- [의견]/미검증: "이제 외주를 주지 않아도 웬만한 작업물은 GPT로 디자인 가능", "비용을 아낄 수 있다".

### 실습 ④ 플러그인 + 예약 작업 — 매일 아침 데일리 브리핑
- **플러그인 = GPT에서 외부 서비스(구글 캘린더·Gmail·노션 등)를 연결하는 것**의 명칭. 연결해 두면 GPT가 해당 서비스로 넘어가 데이터를 읽어 온다.
- 연결 절차: 하단 플러그인 버튼 → 플러그인 연결 → 모든 플러그인 찾아보기 → 원하는 서비스 **설치** → 구글 계정 로그인 → 서비스 **승인**.
- 요청 예: "**매일 오전 8시**에 내 구글 캘린더와 Gmail을 확인해 오늘의 업무를 브리핑 형태로 현재 '실습' 폴더에 **PDF로 생성**해 줘" — 브리핑에 **일정 / 일주일 내 온 메일 중 답장 필요한 것 / 우선순위**를 담게 함.
- 확인: 하단 "열기"로 예약 작업 설명 확인, **좌측 사이드바 "예약" 탭**에 예약 작업 목록. 매일 아침 날짜가 적힌 데일리 브리핑 파일이 폴더에 쌓인다.
- **제약(중요)**: 이 예약 작업은 **해당 시간에 PC가 켜져 있어야** 동작한다.

### 실습 ⑤ 컴퓨터 유즈 — GPT에게 PC를 맡기기
- 개념: 마우스를 움직이고 클릭하고 타이핑하며 **내 PC 상에서 직접 작업을 수행**. 플러그인이 **이미 존재하는 연동 범위 내에서만** 동작하는 것과 달리, 컴퓨터 유즈는 **프롬프트로 요청한 임의의 작업**을 수행한다.
- 사용법: 프롬프트 입력창에 **@ + "컴퓨터"** 입력 → 최상단 컴퓨터 기능 선택 → 실행 시 뜨는 허용 창에서 **"이 대화에서 허용"** 클릭.
- **시연 A**: "카카오톡을 열어 '나에게 보내기'로 '안녕 오늘도 파이팅' 보내 줘" → 앱 실행·창 클릭·문구 입력·전송까지 수행.
- **시연 B(복합 작업)**: "네이버 접속 → 가운데 증권 버튼 클릭 → 주요 뉴스 중 댓글 반응 복사 → 메모장 켜서 붙여넣기" → 중간에 **뜬 팝업창까지 닫고** 요청대로 완수.
- 이점: **내 마우스와 별개로 GPT의 마우스가 생성**되어 내 작업을 방해하지 않음 → 일을 던져 두고 나는 다른 일을 하며 생산성을 높일 수 있다([의견]).
- 예고: 컴퓨터 기능을 다른 기능과 **융합**하는 방법은 나중에 별도로 다루겠다.

## 3줄 오리엔테이션
- AI를 한 번도 안 써 본 사람이 "챗지피티 워크(ChatGPT Work)"로 입문하는 방법을 설치부터 실습까지 훑는 입문 가이드다. 워크는 채팅만 하는 챗 모드와 달리 **내 PC의 폴더·파일에 직접 접근해 생성/수정/삭제**하는 도구다.
- 실습은 다섯 갈래다: ① 회의 녹취록 → 회의록 → 공유용 대시보드 웹사이트, ② 기존 디자인을 참고한 PPT 자동 제작, ③ 이미지 모델로 제안서 표지·스마트스토어 히어로 이미지, ④ 플러그인(구글 캘린더·Gmail) + 예약 작업으로 매일 아침 데일리 브리핑 PDF, ⑤ 컴퓨터 유즈로 카카오톡·네이버를 직접 조작.
- 코드는 한 줄도 안 치고 "이거 이렇게 해 줘"라는 한국어 요청만 쓴다. 중간(14:29~15:12)에 데키랩 강의 홍보가 있고, 끝에는 실습 프롬프트를 오픈 채팅방에서 배포한다는 유입 안내가 붙는다.

## 전문 — 시간순 워크스루

### [00:00–00:38] 오프닝 — 왜 챗지피티 워크인가
화자는 AI를 오늘 처음 시작한다면 **챗지피티 워크**를 추천한다며, 이유로 무료로 시작할 수 있다는 점과 "이거 이렇게 좀 해 줘"라는 요청만으로 큰 효율을 누릴 수 있다는 점을 든다. 활용 예로 귀찮은 문서 작업, PPT 제작, 상세 페이지 이미지 제작을 들고, 매일 정해진 시간에 업무를 대신 해 주는 **"나만의 직원 하나 뽑는 효용"**([의견], 화자의 비유)까지 언급한다. 심지어 카카오톡을 스스로 열어 대신 메시지를 보낼 정도로 성능이 올라왔다고 예고하며, 코드 한 줄 없이·복잡한 개발자 도구 없이 미뤄 온 AI 입문을 할 수 있게 구성했다고 말한다.

> "코드는 한 줄도 안 치고 복잡한 개발자 도구 없이 챗지피티 워크만으로 계속 미뤄왔던 AI 입문을 하실 수 있게끔 도와드리도록 하겠습니다." [00:25]

### [00:40–01:06] 챗(chat)과 워크(Work)의 차이
챗지피티라는 이름은 AI를 안 써 본 사람도 들어봤을 텐데, 우리가 아는 형태는 **채팅창에 질문하면 답변해 주는 대화형 AI**다. 반면 비교적 최근 출시된 **워크**는 내 PC 안에 있는 폴더와 파일에 직접 접근해 **파일을 생성·삭제·수정까지 해 주는 도구**라고 정의한다. 즉 지금까지 한 땀 한 땀 만들어 온 작업물을 프롬프트만으로 AI가 대신 만들어 준다는 것이 핵심 차이다.

### [01:06–01:39] 워크를 고른 세 가지 이유
화자가 제시한 이유는 셋이다. **첫째, 무료로 바로 사용해 볼 수 있다** — 일단 시작해서 테스트하는 데 별도 유료 구독이 필요 없다. **둘째, 토큰 소모** — 새로 구독해 여러 작업을 시킬 때 소모되는 토큰이 "비슷한 격"인 클로드 쪽 도구보다 더 적게 소모되는 것으로 "알려져 있다"고 말한다(화자 주장/미검증, 비교 대상은 `[불명확: 원문 "클로드 코워크"]`). **셋째, 접근성** — 터미널이나 IDE 같은 개발자용 도구를 쓸 필요 없이, 휴대폰 앱 쓰듯 **앱으로 바로 시작**할 수 있다.

### [01:39–02:19] 설치 — 챗지피티 데스크톱 앱
실습은 설치부터 시작한다. 검색창에 "챗지피티 데스크탑"이라고 검색하면 데스크톱 앱 다운로드 페이지가 나오고, 그 페이지에서 사용 중인 **운영체제에 맞춰 다운로드**하면 된다(윈도우 사용자는 윈도우 버튼 클릭). 잠시 기다려 설치 파일이 받아지면 더블 클릭해 설치하고, 설치가 끝나면 챗지피티를 바로 실행할 수 있는 데스크톱 앱이 생긴다. 앱을 더블 클릭하면 로그인 창이 뜬다.

### [02:19–02:39] 로그인
로그인 창에서 "계속하기" 버튼을 클릭하고, 이미 계정이 있으면 그 계정으로 로그인한다. **구글 계정이나 휴대전화 번호로도 로그인**할 수 있으니 편한 방법을 쓰면 된다. 로그인이 완료되면 데스크톱 앱 화면이 실행된다.

### [02:39–03:14] 화면 구조 — 챗 탭 vs 워크 탭
앱 가장 상단에 **챗(Chat)**과 **워크(Work)** 탭이 나뉘어 있다. 챗은 흔히 알려진 GPT의 **채팅 모드**로, 궁금한 내용을 질문하고 답변받는 형식이다. 오늘 다룰 것은 워크이므로 워크 탭을 클릭한다. 워크 탭은 버튼이 많아 복잡해 보이지만, 화자는 **사용에 꼭 필요한 것만 먼저 배우면 나머지는 응용해서 알아낼 수 있다**고 안내한다.

### [03:14–03:31] 프롬프트 입력창과 첨부
가장 먼저 볼 것은 **프롬프트 입력창**으로, 모든 작업이 여기서 시작된다. 이 공간에 **한국어로** 원하는 요청을 입력하면 된다. **플러스(+) 버튼**을 누르면 내가 가진 이미지나 파일을 더해서 함께 대화할 수도 있다.

### [03:31–04:26] 모델·추론 강도·속도 설정
우측에서 모델을 선택할 수 있는데, 모델·추론 강도·속도 등 항목이 많아 복잡해 보이지만 요점만 짚는다. **모델은 챗지피티의 "두뇌"**로, 내가 요청한 작업을 얼마나 똑똑한 두뇌로 수행할지를 정하며 **아래에서 위로 올라갈수록 더 똑똑한 모델**이다. **추론 강도**는 선택한 모델이 얼마나 "머리를 쥐어짜서" 결과물을 낼지, **속도**는 그와 별개로 그 작업을 얼마나 빨리 처리할지를 정하는 값인데 **"빠름"을 선택하면 사용량이 더 빨리 소모**된다는 점을 주의하라고 한다. 복잡하면 다른 건 그대로 두고 **모델만 바꿔서 시작하라**고 권하고(권장 모델 `[불명확: 원문 "5.6 루나"]`), 유료 사용자라면 상위 모델까지 써도 무방하다고 덧붙인다(`[불명확: 원문 "테라나 솔 모델"]`).

### [04:26–05:25] 프로젝트 만들기 — 작업 폴더 지정
설명할 것 두 가지가 더 남았다며 실습을 겸해 진행한다. 먼저 **"프로젝트 선택"** 버튼을 누르면 처음 쓰는 사람은 프로젝트가 비어 있으므로 **"새 프로젝트"**를 클릭한다. 워크는 내 PC에 직접 접근해 파일을 생성·수정·삭제하므로, 그 작업이 이뤄질 **폴더를 내 컴퓨터에 만들어 지정**해야 한다. **"폴더 추가"** 버튼을 눌러 화자는 "챗지피티 워크"라는 **빈 폴더**를 하나 만들어 선택하고, 프로젝트 이름은 "실습"이라고만 적은 뒤 **"프로젝트 만들기"**를 클릭한다. 정리하면 **프로젝트 = 내가 수행할 작업의 이름**, **선택한 폴더 = 그 프로젝트가 이뤄지는 공간**이다.

### [05:25–06:25] 권한 3단계 — "나 대신 승인"으로 시작
작업 전에 **권한** 개념을 짚는다. 권한이란 챗지피티가 내 PC에 접근해 작업할 때 **어디까지 알아서 진행해도 되는지**를 정하는 설정이다. 세 단계를 이렇게 설명한다. **① 승인 요청** — 작업 폴더 안 내용을 수정할 때마다 사용자에게 계속 허락을 받는 모드. **② 나 대신 승인** — AI가 판단해 별문제 없겠다 싶은 부분은 알아서 진행하고, 위험해 보이는 것만 허락받는 구조(이 대목에서 화자는 주체를 "클로드"라고 말하는데, 문맥상 챗지피티를 가리키는 말실수로 보인다). **③ 전체 권한** — 인터넷 연결이든 파일 삭제든 모든 권한을 위임하는 설정. 처음 시작한다면 **"나 대신 승인"**을 선택한 상태로 실습하라고 추천하고, 지금 설명이 다 이해되지 않아도 실습을 따라가다 보면 자연스럽게 이해된다고 안심시킨다.

### [06:26–07:12] 실습 ① 회의록 제작 — 녹취록 파일을 읽혀 정리
첫 실습은 **회의록 제작**이다. 회사에서 회의 기록을 남기려고 간단히 정리하거나, 최근에는 녹음기로 회의 자체를 녹음해 두는 경우가 많다는 상황 설정에서 출발해, **가상의 회의 녹취록**을 챗지피티에 전달해 깔끔한 회의록 형태로 만드는 실습을 한다. 방법은 단순하다 — 아까 만든 **프로젝트 폴더 안에 녹취록 파일을 넣고**, "이 폴더 안에 있는 회의 녹취록 파일을 읽고 회의록으로 정리해 달라"고 **간단히 요청만** 하면 GPT가 실제로 폴더 안 파일을 읽고 회의록을 작성하기 시작한다.

### [07:12–07:39] 결과 확인 — 폴더에 결과물 파일이 생성됨
잠시 기다리면 녹취 내용을 바탕으로 **핵심 결정 사항과 후속 일정** 등을 한눈에 보기 쉽게 정리해 준다(`[불명확: 원문 "회의 소고간 일정"]`). 그리고 만들어 둔 폴더 안에 **회의록 파일이 실제로 들어와 있는 것**을 확인할 수 있다. 화자가 한 일은 폴더에 녹취록 파일을 놓고 "회의록으로 만들어 줘"라고 요청한 것뿐인데, GPT가 순식간에 내 컴퓨터의 파일을 읽고 그 폴더 안에 결과물까지 생성해 줬다는 점을 강조한다.

### [07:39–08:19] 한 걸음 더 — 회의록을 공유용 대시보드 웹사이트로
여기서 더 나아가 그 문서를 **다른 사람과 공유할 수 있는 웹사이트 형태**로 발전시킬 수 있다. "방금 만든 회의록을 대시보드 웹사이트 형태로 만들어 달라"고 요청하면 회의 내용이 모두 들어간 **대시보드**를 순식간에 만들어 주고, 이어 **공유 링크**를 요청하면 함께 회의한 팀원들과 그 웹사이트를 공유할 수 있다. 웹사이트 안에는 복잡한 코딩 언어가 쓰였지만 사용자는 "뭐뭐 해 줘"라고만 요청했을 뿐이라는 점을 짚는다.

> "이제 AI 성능이 대단하다 못해 무서울 지경인데요." [08:16] ([의견])

### [08:19–08:55] 실습 ② PPT 제작 — 내 디자인을 참고 자료로
두 번째 실습은 **파워포인트 제작**이다. 발표 자료를 한 땀 한 땀 만드는 대신, **내가 원래 쓰던 디자인을 바탕으로** 내용만 넣어 PPT를 제작하는 방식이다. 절차는 기존에 쓰던 **PPT 디자인을 프로젝트 폴더 안에 넣어 두고**, "폴더 안에 있는 PPT 디자인 이미지를 참고해 **나만의 PPT 디자인 문서를 생성**하고, 그 디자인 문서를 참고해 **'3분기 주식 시장 전망'** 주제로 PPT를 제작해 달라"고 요청하는 것이다. 이때 디자인 문서에는 **색상·글씨체 같은 디자인 요소**를 넣어 달라고 요청했다.

### [08:55–09:22] 결과 — 리서치 + 디자인이 입혀진 PPT, 그리고 재사용
리서치까지 요청했기 때문에 GPT는 **웹사이트에서 팩트 체크를 거친 리서치 정보**를 바탕으로, 레퍼런스로 넣은 디자인을 입힌 PPT를 생성해 준다(팩트 체크 수준에 대한 검증은 영상에 없음). 핵심 이점은 재사용이다 — **디자인 문서만 있으면** 다음에 어떤 주제의 PPT를 만들더라도 그 문서를 참고해 원하는 PPT를 마음껏 생성할 수 있다.

### [09:22–09:59] 화자의 워크플로 변화와 응용 범위
[의견] 화자는 자신도 발표 자료를 만들 때 파워포인트를 하나하나 만드는 대신, **원래 쓰던 디자인 문서를 참고해 필요한 내용을 입력해 만들게 하고 마지막에 조금씩 검토만 하는 형태**로 워크플로가 바뀌었다고 말한다. 그 결과 **거의 10분 정도의 시간만 써서** 결과물을 만들고 있다고 주장한다(화자 주장/미검증). PPT 기능은 꼭 써 보길 추천하며, **꼭 PPT가 아니어도 자주 쓰던 보고서 양식이나 리포트 양식을 첨부해** 동일한 방식으로 결과물을 만들 수 있으니 이 원리를 꼭 익히라고 강조한다.

### [09:59–10:18] 실습 ③ 이미지 — GPT 이미지 모델
다음은 **이미지**다. 챗지피티 생태계에서 이미지 모델을 빼놓을 수 없다며, 현재 성능이 가장 좋은 모델 중 하나로 GPT 계열 이미지 모델을 든다(`[불명확: 원문 "GPT 2.0 영 모델"]`). 경쟁사라 할 수 있는 **클로드에는 별도의 이미지 모델이 없지만** 챗지피티에는 강력한 이미지 모델이 있으니 꼭 써 봐야 한다고 말한다(화자 주장).

### [10:18–11:14] 활용 A — 제안서 표지 이미지
이미지 모델을 어디에 쓰냐는 질문에, 단순히 "강아지 이미지 생성해 줘", "여성 모델 생성해 줘" 식으로도 쓸 수 있지만 **직장인·지식 근로자** 관점의 예시를 든다. 바로 **제안서 표지 이미지** 생성이다. 원래는 별도 디자인 과정을 거쳐 필요한 내용을 넣고 디자인을 한 땀 한 땀 입혀야 했지만, 이제는 **안에 들어갈 제목·비율·회사 이름·스타일 정도만 입력**하면 바로 결과물이 나온다. 실제로 요청한 비율과 제목, 회사 이름, 차분하고 깔끔한 배경 이미지까지 반영된 결과물을 바로 받는다. 결과물은 **우측 상단 "열기" 옆의 "다른 이름으로 저장"** 버튼으로 내려받을 수 있다.

### [11:14–12:11] 활용 B — 스마트스토어 상세 페이지 히어로 이미지
직장인뿐 아니라 **1인 사업자**가 이미지 모델을 쓸 상황이 훨씬 많다고 한다. 예시는 **스마트스토어 상세 페이지의 히어로 이미지**다. 딸기를 파는 상세 페이지를 만드는 상황에서 사진은 있지만 히어로 이미지로는 추가 작업이 필요한 경우, **프로젝트 폴더에 그 이미지만 넣어 두고** "첨부한 이 사진을 바탕으로 스마트스토어 상세 페이지에 들어갈 히어로 이미지를 생성해 달라"고 요청하면, 별도 디자인 없이 원래 갖고 있던 이미지로 **광고 이미지를 바로 생성**해 준다.

> "혼자서 일하시는 사장님들, 1인 사업자분들께서는 이제 더 이상 외주를 주지 않아도 웬만한 작업물들은 GPT를 활용해서 디자인을 진행해 볼 수도 있겠죠." [11:56] ([의견]/미검증. 이어 "광고비를 아낄 수 있다"고 말하는데 문맥상 외주·디자인 비용을 가리키는 것으로 보인다.)

### [12:11–13:07] 실습 ④-1 플러그인 연결 — 구글 캘린더·Gmail
다음은 **"나만을 위해 일하는 비서 한 명 뽑기"**다. 출근했을 때 오늘 할 일을 한 장으로 정리해 보고하는 시스템을 만든다. 이때 구글 캘린더나 Gmail 같은 **외부 서비스 연결을 GPT에서는 "플러그인"이라고 부른다**고 설명한다. 플러그인만 연결해 두면 GPT가 언제든 Gmail이면 Gmail, 노션이면 노션으로 넘어가 **데이터를 읽어 챗지피티로 가져온다**. 연결 절차는 **하단 플러그인 버튼 → 플러그인 연결 → 모든 플러그인 찾아보기 → (예: Gmail, 구글 캘린더) 설치 버튼 클릭 → 구글 계정 로그인 → 해당 서비스 승인**이다. 화자는 이미 연결된 상태로 시연한다.

### [13:07–13:44] 실습 ④-2 예약 작업 — 매일 오전 8시 데일리 브리핑
준비가 끝나면 GPT에게 이렇게 요청한다: **"매일 오전 8시에 내 구글 캘린더와 Gmail을 확인해서 오늘의 업무를 브리핑 형태로 현재 '실습' 폴더에 PDF로 생성해 달라."** 브리핑에는 **일정**, **일주일 내 온 메일 중 답장이 필요한 메일** 정리, **우선순위** 등을 담아 출근하자마자 오늘 할 일을 한 번에 이해할 수 있게 해 달라고 요청한다. 그러면 요청대로 **매일 아침 8시에 날짜가 적힌 데일리 브리핑 파일**을 생성해 주겠다고 응답한다.

### [13:44–14:26] 예약 작업 확인과 전제 조건 — PC가 켜져 있어야 함
하단의 "열기" 버튼을 클릭하면 해당 **예약 작업에 대한 설명**을 볼 수 있고, **좌측 사이드바의 "예약" 탭**에서도 방금 만든 예약 작업을 확인할 수 있다. 이후 내 폴더에는 매일 아침 정해진 시간에 **오늘 할 일정과 중요 메일 기준의 브리핑**이 생성된다. 다만 중요한 제약이 있다 — **이 예약 작업은 해당 시간에 PC가 켜져 있어야 가능하다**. 그래도 밤새 온 메일을 하나씩 확인하거나 캘린더를 일일이 체크하는 것보다는 훨씬 효율적이라고 평가한다([의견]).

### [14:26–15:12] 세일즈 — 데키랩 강의 소개 (1회 기록)
마지막 기능을 소개하기 전, **30초간 데키랩에서 출시한 강의**를 소개한다. 오늘 실습처럼 프롬프트만으로 원하는 결과물을 받는 세상이 되었고, **GPT든 클로드든 "AI에게 어떻게 요청할 것인가"라는 동작 원리·방식이 중요**하다는 게 논지다. 그런데 막상 내 업무에 적용하려면 막막한 경우가 많고, 프롬프트를 던졌는데 엉뚱한 결과가 나와 어디서부터 고쳐야 할지 모르겠는 경우가 있다며, **데키랩이 실제로 쓰는 워크플로를 처음부터 끝까지 직접 만들어 보며 체화하는 강의**라고 설명한다. **실시간 채팅방**이 있어 모르는 내용을 질문하며 성장할 수 있다고 하고, 자세한 내용은 **영상 설명란** 참고를 안내한다.

### [15:12–15:47] 실습 ⑤ 컴퓨터 유즈 — 개념
마지막 실습은 **컴퓨터 유즈(Computer Use)**로, 말 그대로 챗지피티에게 내 컴퓨터를 맡기는 기능이다. **마우스를 움직이고 클릭하고 직접 타이핑하면서** 내가 할 일을 내 PC 상에서 직접 해 준다. 앞서 연결한 플러그인은 **이미 존재하는 플러그인 안에서만** 활용할 수 있는 반면, 이 기능은 **프롬프트만으로 어떤 작업이든 실행해 달라고 요청**하면 챗지피티가 알아서 진행해 준다는 것이 차이다.

### [15:47–16:34] 시연 A — 카카오톡 "나에게 보내기"
프롬프트 입력창에서 **골뱅이(@) + "컴퓨터"**를 입력하면 최상단에 컴퓨터 기능을 선택할 수 있다. 그 상태에서 **"카카오톡을 열어서 '나에게 보내기'로 '안녕 오늘도 파이팅'이라고 메시지 보내 줘"**라고 요청한다. 하단에 기능 허용 여부를 묻는 창이 뜨면 **"이 대화에서 허용"**을 클릭하고 잠시 기다리면, GPT가 카카오톡 앱을 켜고 "나에게 보내기" 창을 클릭해 요청한 문구를 작성해 전송한다. 화자는 자신의 마우스는 따로 있는데도 작업이 진행된다는 점을 짚으며, **내 마우스와 별개로 GPT의 마우스가 생성되어 작업하기 때문에 내 작업을 방해받지 않는다**고 설명한다.

> "저는 손을 대고 있지 않는데도 챗지피티가 제가 요청한 걸 이해해서 작업을 실행해 준 건데요." [16:21]

### [16:34–17:21] 시연 B — 네이버 증권 뉴스 댓글 복사 → 메모장 붙여넣기
더 복잡한 작업을 시연한다. 다시 @컴퓨터를 입력하고 **"검색창에 네이버를 입력해 접속 후 가운데 있는 증권 버튼을 클릭하고, 주요 뉴스 중에서 댓글 반응을 복사해서 메모장 앱을 켜서 붙여 넣어 달라"**고 요청한다(이 대목에서도 화자는 주체를 "클로드"라고 말하는데 문맥상 챗지피티를 가리키는 말실수로 보인다). 실행 결과, 새 창이 켜지고 마우스가 등장해 네이버를 입력·접속하고 가운데 증권 버튼을 클릭하며, **팝업창이 뜨자 그 팝업까지 닫은 뒤** 주요 뉴스 중 가장 아래 뉴스를 읽고 댓글을 찾아 복사해 붙여 넣는다.

### [17:21–17:52] 컴퓨터 유즈의 의미와 예고
화자는 직접 써 보면 보는 것보다 더 신기할 거라며, **플러그인에서 지원하지 않는 작업도 GPT의 두뇌를 활용해 내 마음대로 이어갈 수 있다**고 정리한다. 그리고 **내 마우스를 건드리지 않아 작업을 방해하지 않으므로**, 원래 내가 해야 할 일을 GPT에게 던져 주고 나는 다른 일을 하면서 생산성을 높일 수 있을 것 같다고 평가한다([의견]). 컴퓨터 기능을 **다른 기능들과 융합**해 더 유용하게 쓰는 방법은 나중에 별도로 다루겠다고 예고한다.

### [17:52–18:33] 마무리 — 입문 권유와 오픈 채팅방 프롬프트 배포
오늘은 챗지피티 워크를 함께 알아봤다고 정리하며, **무료로도 사용해 볼 수 있으니 AI 사용을 망설였다면 이번 기회에 입문해 보라**고 권한다.

> "개인적으로 챗지피티 워크가 현시점 개발을 하지 않는 일반인들에게 접근성이 가장 좋은 AI 툴이 아닌가 생각하고 있는데요." [18:03] ([의견])

워크로 실습해 보고 느낀 소감을 **댓글**에 적어 달라고 요청하고, **오늘 사용한 프롬프트는 전부 오픈 채팅방에서 공유하고 있으니** 댓글에 소감을 남기고 오픈 채팅방에 들어와 무료로 받아 실습해 보라고 안내한다(세일즈·유입 구조, 1회 기록). 다음 강의에서 보자는 인사로 끝난다.
