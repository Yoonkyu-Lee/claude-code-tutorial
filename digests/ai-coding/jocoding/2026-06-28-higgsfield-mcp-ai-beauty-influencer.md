> 검증 배너: **Higgsfield 협찬(지원) 영상**이다. 화자가 소개하는 도구 성능·기능은 광고주 제품에 대한 화자 시연/주장이며 독립 검증이 아니다. 표기는 자막의 훼손된 도구명을 설명란 목차·링크로 매핑해 교정하고 원문을 병기했다.

## 요약 (주제별)

### 무엇을 만드는가 (프로젝트 목표)
- Higgsfield MCP를 Claude(데스크톱)에 붙여, 가상의 여성 뷰티 인플루언서 **"유나"**를 만들고 셀피·메이크업 비포/애프터 영상·화장품 광고 이미지·말하는 영상까지 대화 프롬프트만으로 "공장형"으로 생산하는 실습.
- 최종 목표는 유나의 인스타그램·틱톡 계정을 실제로 키워, AI 인플루언서로 화장품 협찬·광고를 받을 수 있을지 실험하는 것(영상은 제작 과정까지, 성장·수익화는 예고 단계).

### 도구 — Higgsfield란 (광고주 소개, 주장)
- 이미지·영상·오디오 생성 모델을 한곳에 모아 쓰는 플랫폼. 예: 이미지 모델 Nano Banana, 중국 영상 모델 Seedance(자막 "시덴스"). 하나만 구독하면 여러 공개 모델을 모아 쓸 수 있다는 것이 셀링포인트(광고주 주장).
- [의견] 기능·모델이 너무 많아 뭘 써야 할지 헷갈리는 게 단점 → 그래서 **MCP·CLI·스킬**을 공개해, AI 에이전트에 목적만 말하면 알아서 기능·모델을 조합·선택해주는 방식으로 쓴다.

### 실전 절차 ① MCP 연결
- `higgsfield.ai/mcp` 접속 → 연결 방식 MCP 선택(에이전트로 Claude·Cursor·OpenCode·LM Studio 등 지원, 여기선 Claude) → 표시된 Higgsfield URL 복사.
- Claude 데스크톱: 프로필 → 설정 → 커넥터 → 맞춤 설정 → 플러스 → "커스텀 커넥터 추가" → 원격 서버 URL에 붙여넣고 이름 지정 → 추가 → 연결 → 브라우저에서 Higgsfield 계정과 연동 → 허용. 이후 Claude가 내 구독 계정으로 이미지·영상 생성 가능.

### 실전 절차 ② 캐릭터(Element) 등록으로 얼굴 일관성 확보
- Higgsfield의 핵심 기능: 특정 인물을 캐릭터로 잡아 일관성 유지하며 여러 이미지·영상 생성. 등록 방식은 **Soul 캐릭터**와 **Element** 두 가지 — Element가 즉시 등록돼 채택.
- "유나"로 이름 정하고 Element 등록 → Element 탭 "Use"로 프롬프트+Element ID 자동 입력 → 그 ID 기반 생성이 더 정확. 모델은 자동으로 Nano Banana 2 선택됨(프롬프트로 모델·비율 지정 가능).
- [의견] 한 장으로만 만든 Element는 덜 닮을 수 있음 → 얼굴을 여러 각도(GPT Image 2 명시)로 뽑아 정면·좌·우 세 컷을 담은 Element로 갱신하면 얼굴 유지가 좋아짐.

### 실전 절차 ③ 메이크업 비포/애프터 영상
- 유나 Element ID로 캐주얼 셀피 이미지를 "count 4"로 4장 동시 생성 → 잘 나온 것을 비포로 선택 → 이미지 기능으로 "화장 완료 애프터 이미지" 생성(유나 명시 + 비포 이미지를 레퍼런스 미디어 + Element 함께 작용).
- 비포→애프터 전환은 **시작 프레임/엔드 프레임** 방식, Generate Video → **Seedance 2.0**으로 제작. 비포/애프터가 확 변하는 바이럴형 영상이 나옴.
- [의견] 오디오도 생성되지만 실제 업로드 땐 플랫폼 제공 음악이 더 나을 것. 최종 프롬프트들은 고정 댓글에 모아 공개.

### 실전 절차 ④ 화장품 UGC 광고 (마케팅 스튜디오)
- **마케팅 스튜디오 + UGC(유저 제너레이트 컨텐츠)** 기능으로 제품 소개 콘텐츠 제작. UI 대신 Claude Code 연결 MCP로 실행.
- 제품(임의 선택: **메디테라피 콜라겐 펩타이드**) 사진 + 모델이 제품 든 참고 이미지를 첨부 → 하나의 프롬프트로 제품 등록(Product ID 발급)까지 처리 → "Use"로 제품 태그 → 유나가 제품 든 다양한 구도 광고 이미지 생성. 제품 글씨 디테일까지 잘 유지됨.

### 실전 절차 ⑤ 말하는(움직이는) 영상
- 생성 이미지에서 "Animate" → 프롬프트 자동 입력, 상세 프롬프트 추가하면 대사하는 영상 생성(프롬프트는 ChatGPT와 짬). 유나가 "안녕하세요, 유나예요. …이런 세럼 하나쯤은 많이 쓰더라고요"라고 말하는 광고 영상 완성. [의견] 글씨 안 깨지고 제품 퀄리티 잘 유지.

### 부가 기능 — Predict Virality(바이럴 예측)
- 특정 영상의 바이럴 정도를 예측·점수화(숏폼에 뇌가 어떻게 반응하는지 분석). [의견] 정확도가 아주 높진 않겠지만 Meta 연구 기반인 듯하고 재미로 참고할 만함.

### 자동화·수익화 구상 (예고, [의견])
- 수동은 오래 걸림 → **CLI**를 Claude Code·Codex 등으로 맥미니 같은 데 띄워 주기적으로 사진·영상 생성 후 인스타그램·틱톡 자동 업로드 = 자동 포스팅으로 계정 성장("공장형"의 핵심).
- 유나 계정을 실제로 만들어 광고 수주 가능성을 실험 예정. "화장품 회사면 광고 달라"는 반농담 제안으로 마무리.

### 자막 표기 주의 (오인식 교정)
- 자동자막이 도구명을 심하게 훼손: **Higgsfield** → "필드/익스필드/핵스필드/픽스필드", **Nano Banana** → "나노바나", **Seedance** → "시덴스", **GPT Image** → "GPT 이미지", **메디테라피** → "매디/매립 테라피", **ChatGPT** → "채치T", 캐릭터 이름 **유나** → "윤나". 도구명은 설명란 목차·바로가기 링크로 매핑해 교정했다. "Seedance"는 자막 "시덴스"의 유력 추정.

- 실제 목표는 가상의 여성 뷰티 인플루언서 "유나"를 캐릭터(Element)로 등록해 일관된 얼굴로 셀피·메이크업 비포/애프터 영상·화장품 UGC 광고 이미지·말하는 영상까지 "공장형"으로 찍어내는 것.

### [00:20–00:31] 강의 소개
> "안녕하세요. 조코딩입니다." [00:21]

이번 영상은 Higgsfield의 지원(협찬)을 받아, Higgsfield MCP와 Claude를 연결해 AI 인플루언서 계정을 만들고 운영해보는 내용이라고 밝힌다.

### [00:31–02:03] 광고주 Higgsfield 소개
Higgsfield(자막 "필드")를 "다양한 이미지·영상·오디오 생성 모델을 한 번에 모아서 쓸 수 있는 플랫폼"으로 소개한다. 예로 이미지 모델 Nano Banana(자막 "나노바나"), 중국의 Seedance(자막 "시덴스", 영상용 모델로 추정) 같은 것들을 원래는 각각 구독해야 하지만, Higgsfield 하나만 구독하면 현재 공개된 여러 이미지·영상·오디오 모델과 기능을 모아서 쓸 수 있다는 것이 핵심 셀링포인트다(광고주 주장).
- [의견] 다만 막상 구독해 직접 쓰려 하면 이미지·비디오·오디오마다 기능과 모델이 너무 많아 "어떤 걸 써야 할지 굉장히 헷갈린다"고 지적한다. 내 목적에 맞는 기능/모델이 뭔지 알기 어렵다는 것.
- 화자는 "요즘은 사람이 직접 메뉴 들어가 특정 기능 쓰는 일이 거의 없고, AI 에이전트한테 원하는 것만 말하면 알아서 해주는 시대"라고 전제를 깐다. 그래서 Higgsfield도 시대에 맞춰 **MCP**, **CLI**(커맨드 라인 연결), **스킬**까지 공개했고, 이제 AI 에이전트에 Higgsfield 사용법을 주면 목적만 말해도 기능들을 조합해 최적의 기능·모델을 골라 만들어주는 절차가 가능해졌다고 설명한다.

### [02:03–02:16] 강의 목표
오늘은 Higgsfield MCP 사용법을 익히고, 직접 AI 인플루언서를 만들어 사진·영상을 뽑아보는 것이 목표라고 정리한 뒤 MCP 연결부터 시작한다.

### [02:16–04:11] Higgsfield MCP를 Claude에 연결
연결 절차를 단계별로 시연한다.
- `higgsfield.ai/mcp`(자막 "필드.ai/mcp") 주소에 접속하면 연결 화면이 나온다. 연결 방식으로 MCP를 선택하고, 에이전트는 Claude·Cursor·OpenCode·LM Studio 등 여러 곳과 연결 가능한데 오늘은 Claude를 고른다.
- 1번 항목의 Higgsfield URL을 복사 → Claude 데스크톱 클라이언트에서 내 프로필 → 설정 → 커넥터 → 맞춤 설정으로 진입 → 플러스 버튼 → "커스텀 커넥터 추가"를 누른다.
- 복사한 URL을 "원격 서버 URL"에 붙여넣고, 이름은 "Higgsfield"(자막 "픽스필드")로 지정 후 추가. 그다음 연결 버튼을 누르면 브라우저가 떠서 내가 구독한 Higgsfield 계정과 Claude를 연결할 수 있고, 허용(Allow)을 누르면 커스텀 커넥터 연결이 완료된다.
- 이렇게 하면 Claude가 Higgsfield 도구를 알아서 쓸 수 있는 상태가 되어, 내 구독 계정으로 이미지·영상을 자유롭게 뽑아준다.

### [04:11–07:10] 뷰티 인플루언서 이미지 만들기 + 캐릭터(Element) 등록
새 채팅을 시작한다. Claude는 원래 이미지/영상 생성 기능이 없지만 Higgsfield MCP 커넥터를 붙였으니 가능해진다. 플러스 → 커넥터에서 Higgsfield가 잘 들어간 걸 확인하고 켠 뒤, 이미지 생성 프롬프트를 작성한다.
- 프롬프트에는 자연스러운 여성 뷰티 인플루언서를 만드는 내용과 함께, 어떤 모델을 쓸지·어떤 비율로 만들지도 명시한다. Claude가 "Higgsfield와 연결하여 이미지 생성"을 시도하고, "항상 허용"을 누르면 알아서 생성된다. 처음엔 잘 안 나와 새로고침을 누르자 네 명의 AI 인플루언서 후보를 다양하게 뽑아준다.
- **Element(엘리먼트) 등록**: Higgsfield에는 특정 인물을 하나의 캐릭터로 잡아 일관성을 유지하며 여러 이미지·영상을 생성하는 기능이 있다. 이 인플루언서를 캐릭터로 등록하기 위해 먼저 이름을 정하는데, 이름 추천을 받아 "유나"로 정한다(자막에 "윤나"로도 표기되나 뒤 영상에서 본인이 "유나예요"라고 말함 → 유나로 통일). 등록 방식은 **Soul 캐릭터(자막 "소울 캐릭터")** 또는 **Element** 두 가지가 있는데, Element가 즉시 등록 가능해 이걸로 진행한다. "유나로 이름 정하고 Element로 등록해줘"라고 시키자 Element에 유나 캐릭터가 새로 등록된다.
- 이 유나 캐릭터를 쓰려면 프롬프트만 입력해도 되지만, 더 정확히 하려면 Element 탭에서 "Use"를 누르면 하단에 프롬프트가 자동 입력되고 유나 Element ID가 표시된다. 이 ID 기반으로 생성하면 Element를 잘 불러와 더 정확하게 만든다. 카페에 있는 사진을 붙여 생성해보자 모델은 알아서 Nano Banana 2(자막 "나노바나 2")가 선택된다. 모델이나 비율은 프롬프트로 추가 지정 가능.
- [의견] 결과가 "전반적으로 좀 덜 닮게" 나온 것 같아 보강한다. Element를 한 장으로만 만들어 완전하지 않을 수 있으니, 유나 얼굴을 다양한 각도로 만들어 Element로 보강하면 더 닮은 얼굴이 나온다는 것. "다양한 각도로 뽑아보는" 프롬프트에 GPT Image 2(자막 "GPT 이미지 2")까지 명시해 좌·우·후면을 생성한다. 후면은 안 쓸 것 같아 좌우로 Element를 등록해 강화하고, 다시 정면·좌측·우측 세 컷을 모두 담은 새 유나(Element가 "슬라이스1" 형태로 갱신)로 바꿔, 이 Element ID로 유나 얼굴이 잘 유지되게 만든다.

### [07:10–09:45] 메이크업 비교(비포/애프터) 영상 만들기
뷰티 인플루언서가 흔히 하는 "비포 애프터" 영상을 구현한다.
- 유나 얼굴 Element를 잡아, 지금까지는 텍스트→이미지 위주였으니 이번엔 화장한 모습을 이미지로 만든 뒤 **시작 프레임/엔드 프레임**을 이용해 변화하는 과정을 영상으로 담는 방식.
- 먼저 유나 Element ID로 캐주얼 셀피 프롬프트를 넣어 이미지를 생성하되 "count 4"를 넣어 한 번에 네 장을 뽑는다(개수 지정으로 여러 장 동시 생성 가능). 그중 잘 나온 걸 비포 이미지로 고른다.
- 그 비포 이미지에 이미지 기능을 써서 "화장을 완료한 애프터 이미지를 만들어줘"라고, 뒤에 부가 프롬프트를 붙여 요청한다. 프롬프트가 조금씩 잘 안 나와 수정을 거쳤는데, 유나를 명시하고 이미지를 레퍼런스 미디어로 놓고 Element도 함께 작용시키니 잘 나왔다고 평가한다.
- 이 비포→애프터 이미지 전환 영상을 만든다. 최종 프롬프트들은 **고정 댓글에 모아 남기겠다**고 안내한다(세일즈/자료 안내 성격). Generate Video가 동작하고 Seedance 2.0(자막 "시덴스 2.0")으로 영상 제작이 진행된다. 다양하게 만들어진 것 중 잘 나온 걸 보면 비포→애프터가 확 변하는 바이럴형 영상이 잘 만들어진다.
- [의견] 소리도 함께 생성되긴 하지만, 실제 업로드 때는 플랫폼이 제공하는 음악을 쓰는 게 더 나을 것 같다고 덧붙인다.

### [09:45–10:20] 바이럴 예측(Predict Virality) 기능
추가로 **Predict Virality(자막 "프레딕트 바이러럴리티")** 기능을 소개한다. 특정 영상의 바이럴 정도를 예측해주는 기능으로, [의견] "정확도가 엄청 높진 않겠지만 Meta의 연구를 기반으로 만들어진 것 같고 재밌게 나온다"고 평한다. 실행하면 숏폼에 대해 뇌가 어떻게 반응하는지 분석해 점수화해 보여준다. 바이럴될 영상을 어느 정도 미리 예측해볼 수 있으니 참고로 알아두면 좋다고 정리한다.

### [10:20–12:36] Higgsfield 마케팅 스튜디오로 화장품 UGC 만들기
뷰티 인플루언서의 핵심 콘텐츠인 "화장품 소개"를 만들어 협찬·광고로 수익화하는 시나리오다.
- Higgsfield의 **마케팅 스튜디오(Marketing Studio)** 기능을 쓴다. **UGC(유저 제너레이트 컨텐츠)** — 화장품을 들고 소개하는 듯한 이미지/영상을 만드는 기능. UI로도 되지만 더 간단하게 Claude Code와 연결된 MCP로 시킨다.
- 프롬프트를 미리 준비했는데, 유나를 사용하되 제품을 등록하고 마케팅 스튜디오로 제작하는 것을 하나의 프롬프트에 담았다. 등록할 제품 사진으로 임의로 **메디테라피 콜라겐 펩타이드(자막 "매디테라피/매립 테라피")** 화장품을 골라, 화장품 이미지와 "모델이 화장품을 들고 있는" 참고 이미지를 함께 첨부한다.
- 입력 후 Claude에 시키자 Higgsfield MCP로 마케팅 스튜디오를 이용하고, 인물 Element 등록과 마찬가지로 제품(Product)이 등록되며 Product ID가 나온다. "Use"를 누르면 해당 화장품이 태그된다.
- 프롬프트에 이미지 생성도 추가해뒀기 때문에 다양한 구도의 이미지를 알아서 뽑는다. 마케팅 스튜디오에서 바로 비디오도 만들 수 있지만, [의견] 이미지로도 광고가 되니 먼저 이미지를 생성한다. Product ID로 "유나가 제품을 광고하는 사진"을 생성하자, 유나가 메디테라피 화장품을 자연스럽게 들고 있는 이미지들이 출력되고 눌러보면 글씨 디테일까지 거의 잘 유지된다.

### [12:36–13:32] 움직이는(말하는) 뷰티 인플루언서 만들기
생성된 이미지를 Higgsfield MCP와 연결된 상태에서 "Animate"를 눌러 애니메이션을 진행할 수 있다. 프롬프트가 자동 입력되고, 뒤에 더 상세한 내용을 적으면 이미지가 대사를 하는 영상으로도 만들 수 있다. 프롬프트는 ChatGPT(자막 "채치T")와 대화하며 짜봤고, 중간에 대사도 넣었다. 생성된 영상에서 유나가 이렇게 말한다:
> "안녕하세요. 유나예요. 요즘 피부 관리할 때 이런 세럼 하나쯤은 많이 쓰더라고요. 가볍게 쓰기 좋아요." [13:10]

[의견] "글씨가 잘 안 깨지고 거의 똑같이 나왔다"며, 제품 퀄리티가 잘 유지된 채로 나온 것을 강조한다.

### [13:32–14:28] 실제로 광고를 받을 수 있을까 + CLI 자동화 예고
Higgsfield로 AI 뷰티 인플루언서를 만들어봤고, 방금 만든 인플루언서로 인스타그램·틱톡 계정을 실제로 생성했다고 밝힌다. 이 계정들을 키워, 진짜로 성장시켜 실제 제품 광고를 받을 수 있을지 실험해보겠다고 한다.
- [의견] 이렇게 수동으로 하면 시간이 오래 걸리는데, 방금은 Higgsfield MCP만 Claude에 붙여 썼지만 **CLI**도 있다. Claude Code나 Codex 같은 것으로 맥미니 같은 데 띄워놓고, 주기적으로 CLI로 사진·영상을 만들어 자동으로 인스타그램·틱톡에 업로드하게 해두면 자동으로 계속 포스팅해 계정을 성장시킬 수 있다는 구상("공장형"의 핵심).
- 이 계정으로 다양한 실험을 해보겠다고 하고, "화장품 회사를 하시면 광고 주시면 이런 식으로 잘 다뤄드리겠다"는 반농담조 광고 제안과 구독·좋아요 요청으로 마무리한다.
