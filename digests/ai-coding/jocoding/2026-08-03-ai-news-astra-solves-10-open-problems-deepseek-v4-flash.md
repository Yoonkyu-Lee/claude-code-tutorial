## 요약 (주제별)

### 1. OpenAI Astra — 미해결 수학·이론CS 난제 10개 해결 (주장)
- 최소 10년 이상 주요 진전이 없던 수학·이론 컴퓨터 과학의 미해결 난제 10개를 AI가 풀어 결과를 공유했다(주장). 예시로 "고차원 구형(sphere) 패킹 밀도의 새로운 상한값", "이진 코드 및 구형 코드" 관련 유명 난제가 언급됐다.
- 대충 써서 해결한 척하는 할루시네이션이 아니라, 각 논증을 **Lean 인증서(Lean certificate)로 공식화**해 검증 가능하게 만들었다는 점이 핵심(화자는 세부 내용은 이해 못 했다고 밝힘).
- 이 성과는 OpenAI의 차세대 주요 모델 **Astra의 내부 버전**으로 얻어졌다(주장). [의견] 화자는 새 모델이 나올 때마다 기존 난제를 풀 수 있다는 사실에서 "특이점이 얼마 안 남았다"고 느끼며, 박사급 전문 영역까지 AI가 넘어서면 그 진로로 가는 사람이 줄지 않을까 우려한다.

### 2. GPT 5.6 — 가격 인하 + 속도 옵션 + Harness에 따른 점수 급변
- **가격 인하(7월 30일부터)**: 가장 가벼운 모델 Luna 가격 80% 인하(입력·출력 1.2달러), 중간 모델 Terra 20% 인하(입력 2달러 / 출력 12달러). [의견] 화자는 저렴한 DeepSeek 대응 성격이 아닐까 추정.
- **5.6 Sol 업데이트**: Sol 수준 품질을 유지하면서 Standard 대비 최대 2.5배 빠른 속도를, 2배 가격에 제공(속도 위주 업데이트).
- **Harness가 점수를 좌우한다**: 두 설정 활성화만으로 ARC-AGI3 점수가 3배로 올랐다(주장). 기본 OpenAI harness로는 출력 토큰이 늘수록 점수가 조금 오르는 정도(10%대). 그러나 "리즈닝을 보유하면서 압축"하는 방법론을 적용한 harness로 바꾸니 **같은 모델인데 13.3% → 38.3%** 로 급등.
- 시사점: 벤치마크는 모델 성능만이 아니라 **API 설정·harness 설계·프롬프트 방식** 같은 눈에 안 띄는 요소가 함께 측정되는 것 → harness가 매우 중요하다.

### 3. DeepSeek-V4-Flash 정식 출시
- 이전엔 프리뷰였고, 이번엔 **정식 버전** — API + 오픈 웨이트 + **MIT 라이선스**(무료 다운로드·자유 사용).
- 성능: 이전 Pro 모델을 크게 상회. 화자 표현으로 "Fable 나오기 전 최강이던 **Opus 4.8과 거의 견주는 수준**"(주장). Artificial Analysis 기준으로 구글의 최첨단 Flash 모델과 점수가 같다(무료로 아무나 받는 모델이 그 수준).
- 가격: cost-per-intelligence 최하단급. 구글이 가성비로 밀던 Gemini 3.5 Flash Lite보다 성능은 좋으면서 훨씬 저렴하고, **Fable 5보다 105배 싸다**(주장).
- 로컬 실행(오픈 웨이트라 Unsloth 등에서 양자화 모델 배포): 손실 거의 없는 4bit ≈ 162GB, 3bit 양자화 ≈ 128GB 통합 메모리에서 실행 가능, 2bit면 더 넉넉. GGX(DGX) Spark 등 보유자는 돌려볼 만하다.

### 4. Anthropic — Claude Code 프롬프트 80% 삭감 & 새 컨텍스트 엔지니어링 규칙
- Y Combinator 영상에 Claude Code 헤드 **보리스 체르니(Boris Cherny)** 가 출연해 팁을 공유(주장).
- **프롬프트 80% 삭감**: 모델 지능이 향상되면서 이전 모델의 부족함을 메우려 넣었던 시스템 프롬프트 구문의 80% 이상을 삭제. 방법은 "기존 프롬프트·코드를 지우고 생 모델의 실제 반응을 관찰하며 **필요한 부분만 다시 채워 넣는**" 절제 과정.
- 또 다른 Claude Code 팀원의 글 "New Rules of Context Engineering": 예전엔 지침을 극도로 상세히 적었지만, 이제는 **자율적 판단에 위임**하는 편이 낫다. 도구 사용법을 친절히 설명하지 않아도, **파라미터·구조만 명확히 설계**하면 예시 없이도 모델이 사용법을 안다.
- [의견] 화자: Anthropic 모델을 쓴다면 기존 harness/스킬을 그대로 두지 말고, 지우고 생 모델에서 조금씩 다시 쌓아 올리면 더 좋아질 확률이 있다.

### 5. 안드레 카파시(Andrej Karpathy) — LLM 테스트 진화 (팰리컨 → 반지의 제왕 3D)
- 예전엔 "자전거 탄 펠리컨 SVG 생성"으로 LLM을 테스트하는 게 유행이었지만, 이제 모델들이 그걸 잘 만들어 테스트가 변별력을 잃음.

### 6. Seedance 2.5 — 영상 생성 글로벌 런칭
- 영상 생성 강자 Seedance의 **2.5 모델**이 누구나 쓸 수 있게 글로벌 런칭. 비싸지만 성능은 향상.
- 기능: 단일 생성으로 **네이티브 30초** 영상, 인터랙티브 편집, 롱 비디오, 최대 **3분 영화급 프로덕션 파이프라인**. **Maya·Blender 플러그인**도 출시 — 3D 도구에서 3D만 만들면 영상으로 변환.
- 데모: 로지텍 광고(30초 원샷), 2.5 vs 2 비교(더 현실적), 프로즌 타임 효과, 시간 되감기, 노래·K팝 뮤비 생성(다양한 장면이 아이돌 뮤비처럼). 화자 직접 테스트도 괜찮게 나옴.
- 이용처: Dreamina에서 뽑을 수 있고 **1회 약 1만 원**이라 신중히. [의견] 화자: 지금까지 퀄리티 중 가장 좋다.

### 7. MiniMax H3 — 오픈 웨이트 영상 생성 멀티모델

### [00:00–01:36] OpenAI Astra, 10대 미해결 난제 해결 (주장)
수학·이론 컴퓨터 과학에는 최소 10년 이상 주요 결과에 진전이 없던 미해결 난제가 많은데, 이번에 그중 10개를 AI가 풀어 결과를 공유했다고 화자가 소개한다. [의견] "인간이 아무리 머리 싸매도 못 풀던 걸 AI가 해결하는 세상", "특이점 개념이 얼마 안 남았다는 생각이 든다"고 말한다. 문제 목록이 공개돼 있지만 화자는 읽어도 무슨 문제인지 잘 모르겠다고 하며, "고차원 구형 패킹 밀도에 대한 새로운 상한값", "이진 코드 및 구형 코드" 같은 유명 미해결 문제라고 전한다.

> "그냥 대충 써 가지고 그냥 해결한 척하는 할루시네이션이 아니라 각 논증을 린 인증서로 공식화했다고 합니다." [00:45]

즉 검증 가능하게 공식화하는 방법론(Lean certificate)을 썼다는 것이 포인트이고, 화자 자신은 세부는 이해 못 하지만 "딱 봐도 미해결됐을 것 같은" 철저한 증명이라고 화면을 보여준다. 이 성과는 OpenAI의 차세대 주요 모델 **Astra의 내부 버전**으로 얻어졌으며, 새 모델이 나오면 기존 난제를 풀 수 있다는 사실을 보여준다(주장). [의견] 박사급으로 그것만 공부해야 겨우 이해하는 영역인데 AI가 그 이상을 달성하면 그 진로로 가는 사람이 점점 줄지 않을까 우려한다.

### [01:36–02:24] GPT 5.6 가격 인하 + 속도 업데이트
GPT 5.6이 가격 대비 성능의 한계를 확장했다. **7월 30일부터** 가장 가벼운 모델 **Luna**는 가격을 80% 인하했고(입력·출력 1.2달러), 중간 모델 **Terra**도 20% 인하했다(입력 2달러 / 출력 12달러). 또한 **5.6 Sol** 수준 품질을 유지하면서 Standard 대비 최대 2.5배 빠른 속도를 2배 가격에 제공하는 속도 위주 업데이트가 있었다. [의견] 화자는 가성비 모델로 달러당 성능을 더 잘 쓸 수 있게 됐다며, DeepSeek이 워낙 저렴해 그 대비 아닐까 추정한다.

### [02:24–03:24] Harness가 벤치마크를 좌우한다 (ARC-AGI3)
두 가지 설정을 활성화하는 것만으로 **ARC-AGI3 점수를 3배**로 높였다는 소식. 기본으로 세팅돼 있던 OpenAI harness로는 출력 토큰이 늘수록 점수가 조금 오르는 정도(10% 살짝 넘는 수준)였는데, "리즈닝을 보유하면서 압축"하는 방법론을 적용한 harness로 바꾸니 같은 모델인데도 점수가 약 40%까지 올랐다. 구체적으로 **13.3% → 38.3%**로 급등.

> "벤치마크 측정 … 모델의 성능을 측정하는 것도 있지만 API 설정, 하네스 설계, 프롬트 방식 등 눈에 띄지 않는 여러 요소들이 함께 측정되는 거라는 걸 다시 한번 상기시켜 드린다고 합니다." [03:08]
