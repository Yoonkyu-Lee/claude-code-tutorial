# AI에게 맡기는 주식 자동매매 - Codex와 NH투자증권 API로 투자 에이전트 만들기

> 조코딩 JoCoding · 2026-09-01 · 조회수 29,475회 · 21분 34초 · [영상 링크](https://youtu.be/CGDibbwGfvk)
> 정리 방식: 시간순 심층 워크스루 (paraphrase) + 주제별 상세 요약
> 검증 배너: 이 영상은 **NH투자증권 API 서비스(자막상 "나무 플러그")의 홍보성 콘텐츠**다. 서비스 특징(안정성·활용도·수수료 우대 등)과 이벤트 조건은 전부 **화자/제공사 주장**이며 제3자 검증되지 않았다. 영상에 나오는 매매 결과("전반적으로 플러스", "벌써 올랐습니다")는 **극히 짧은 구간의 화면 표시값**일 뿐 수익률 근거가 아니며, 화자 스스로 예시임을 밝힌다. 투자 판단·손실 책임은 전적으로 시청자 본인에게 있다.
> 자막 주의: 한국어 자동자막 기반이라 브랜드명·명령어 음차 오인식이 많다. 문맥으로 교정 가능한 것은 교정했고, 불확실한 자리는 `[불명확]`으로 남겼다.

## 요약 (주제별)

### 1. 전체 구성 — 무엇을 어떻게 만드는가
- 목표물: **NH투자증권 API 서비스(자막상 "나무 플러그") + OpenAI Codex 앱**으로 만드는 국내·미국 주식 자동매매 에이전트. 코드를 직접 쓰지 않는 "바이브 코딩" 방식을 표방한다.
- 3단계 진행: **모의투자 세팅 → 실전투자 전환(텔레그램 승인 연동) → 클라우드 상시 가동(DigitalOcean)**.
- 핵심 전제([의견]): API 가이드 문서는 이제 사람이 읽으라고 만든 게 아니라 **AI 에이전트가 읽고 구현하는 것**이라는 주장 [00:53].

### 2. 준비물과 계정 — 실행에 필요한 것 전부
- **NH투자증권 계좌** — 없으면 앱스토어에서 "나무증권" MTS를 받아 계좌 개설.
- **API 신청** — 자막상 `NH플러그.com`(정확한 도메인 표기는 `[불명확]`) → 신청하기 → **QR 로그인**(나무증권 MTS로 인증) → 약관 동의 → 신청 → 하단 **보안 인증 키 확인** → **앱 키(App Key) / 앱 시크릿(App Secret)** 두 개 발급.
- **ChatGPT 계정** — Codex 앱 연결에 필수.
- **Codex 앱** — `openai.com/codex`에서 Windows/Mac 인스톨러 다운로드 후 설치.
- **텔레그램 앱 + 봇** — 실전투자 단계에서만 필요.
- **DigitalOcean 계정 + 신용카드** — 클라우드 상시 가동 단계에서만 필요.
- 보안 당부: 앱 키·앱 시크릿은 "내 계좌 접속용 API 비밀번호 같은 것"이라 **외부 노출 금지**, 메모장 등에 본인만 보게 저장 [04:48~05:07].

### 3. 실전 절차 — 한 개의 한글 프롬프트가 하는 일
- 조코딩이 **자신의 GitHub에 프롬프트와 예제 코드를 미리 올려 두었다**. 시청자는 복사 버튼으로 복사해 Codex 채팅창에 붙여넣고 엔터만 치면 된다(링크는 설명란·고정 댓글).
- 설계 원칙 두 가지: ① **비개발자 기준** — 터미널 사용·파일 직접 수정이 전혀 없다. ② **공식 홈페이지 링크만 걸어 두어**, 사용법이 바뀌면 에이전트가 스스로 탐색해 새 방법을 적용하게 했다 [06:58~07:15].
- 프롬프트가 지시하는 5단계: **① 저장소 다운로드(git 없어도 됨) → ② Python 설치·가상환경 생성 → ③ 셋업 실행 후 키 입력 → ④ 투자 상담 → ⑤ 전략 검사 후 자동매매 예약 등록**.
- 프롬프트가 **한글**이라 코드를 고칠 필요 없이 원하는 문장으로 수정해 붙여넣으면 동작이 바뀐다 [08:04~08:11].
- Codex 프로젝트는 `+` 버튼 → 이름 `NH` → 소스 폴더 지정(화자는 C드라이브에 `NH` 폴더 생성)으로 만든다.

### 4. API 키 입력 방식 — 채팅창에 넣지 않는 이유
- 키를 Codex **채팅창에 그대로 넣으면 값이 AI 쪽으로 넘어간다**. 그렇다고 `.env` 파일을 만드는 방식은 비개발자에게 복잡하다.
- 해결책으로 프롬프트가 **키 입력 전용 웹페이지를 자동으로 띄우게** 설계했다. 거기에 앱 키·앱 시크릿을 넣고 모의/실전을 고른 뒤 저장·연결 확인 [08:29~08:53].
- 연결 후에는 Codex 채팅창에 **"연결됐다"** 한마디만 보내면 다음 단계로 넘어간다.

### 5. 투자 전략 수립 — AI 상담 방식
- 사람마다 투자 성향·관심 종목이 다르므로, **Codex가 투자 자문 전문가처럼 질문을 던지고 답을 받아** 전략을 만든다. 질문 세트는 프롬프트에 미리 넣어 두었다 [09:12~09:30].
- 화자의 선택(모의 단계): **국내·미국 양쪽 투자**, **반도체·AI 대형주 위주**. 현재 환율까지 확인한 뒤 최종안 제시.
- 최종안의 **종목과 매매 방식은 AI가 임의로 잡아 준 것**이며, 마음에 안 들면 자연어 대화로 수정 가능. "이대로 진행"이라고 보내면 **전략 파일이 자동 수정**된다 [09:49~10:08].
- 실전 전환 시에는 **모의 전략을 그대로 쓸지, 다시 상담해 새로 짤지** 선택하게 된다. 화자는 재상담을 택하고 **국내장·미국장 + 프리마켓/애프터마켓 전부 포함**으로 잡았다 [12:44~12:59].

### 6. 자동매매 실행 구조 — Codex 예약 기능
- Codex에 **"예약" 기능**이 실제로 있고, 프롬프트가 `NH 자동 매매`라는 예약 작업을 자동 등록한다. **기본 주기는 1시간**이며 예시일 뿐이라 변경 가능 [07:54~08:02, 10:34~10:44].
- 1사이클 동작: **투자 원칙 확인 → 관련 종목 뉴스 조회 → 투자 판단 → 매수/매도 실행 → 결과 및 판단 이유 출력 → 대시보드 갱신**.
- 장이 안 열린 시간대에는 아무것도 하지 않고 넘어가고, 열려 있으면 실제로 돈다. **컴퓨터가 켜져 있어야** 예약이 동작한다 [11:23~11:31, 16:46~16:58].
- 대시보드에서 보이는 것: **보유 종목, 손익, 시간대별 매매 내역, 각 판단의 이유**.
- 관측된 예시 결과: **알파벳(Alphabet) 3주 매도 주문, 나머지 유지** — 매도 사유도 함께 표시됨 [11:51].

### 7. 리스크 통제 장치 — 텔레그램 승인 게이트
- 화자 스스로 "실전 투자가 그냥 자동으로 막 되면 위험하다"고 전제하고 **텔레그램 연동을 실계좌 사용의 필수 조건**으로 걸었다 [13:21].
- 규칙: **주문마다 텔레그램 알림 → 3분 안에 승인 시 체결 → 3분 경과 시 취소 → 거절 누르면 미체결**.
- **예외: 미리 정해 둔 손절·익절은 항상 승인 없이 자동 진행**된다("못 하면 안 되니까") [15:49~15:56].
- 설계 의도 요약: "AI한테 완전히 맡기는 게 아니라... **승인을 누르지 않으면 주문이 나가지 않습니다**" [16:15].
- 텔레그램 봇 만들기: 텔레그램 공식 앱 설치 → 돋보기에서 **BotFather** 검색(체크 표시 확인) → 프로필의 **앱 열기** → **새 봇 생성(`/newbot`)** → 이름·프사 지정, **아이디는 반드시 `bot`으로 끝나고 중복 불가** → 생성 후 나오는 **API 키(봇 토큰) 복사** → 설정 화면에 붙여넣고 토큰 확인 → 봇 채팅방에서 **Start** → 실계좌로 저장 → Codex에 **"다 했다"** 입력 [13:46~15:40].

### 8. 클라우드 상시 가동 — DigitalOcean
- 문제: 노트북을 끄면 예약이 멈춘다. 상시 켜 둘 PC가 없으면 클라우드로 옮긴다.
- 선택: **DigitalOcean의 Droplet**. "컴퓨터를 빌려주는 업체"라는 비유.
- **비용(화자 설명): Codex에서 연동해 쓰려면 월 24달러짜리 Droplet이 필요**하다고 한다. Account → Billing에서 신용카드를 등록해야 하며 사용한 만큼 과금.
- Codex **플러그인** 메뉴에서 "디지털" 검색 → DigitalOcean 플러그인 설치 → 로그인·승인으로 계정 연동 → 기본 명령어 1회 실행만으로 세팅·체크·예약 작업 등록이 **전부 자동** 완료 → **SSH 호스트 추가 및 연결**.
- [의견] 장점은 **리모트 Codex의 SSH** 사용 — "Mac mini 한 대를 빌려 항상 켜 놓듯이" 쓸 수 있다 [17:59~18:07].
- 원격 프로젝트: 프로젝트 `+` → **원격 선택** → `NH클라우드` 생성 → 소스 폴더는 루트의 `workspace` → 이후 **로컬과 완전히 동일한 절차**(같은 프롬프트, 키 입력, 이번엔 실제 계좌 선택). 이후에는 **내 컴퓨터를 꺼도 돌아간다**.

### 9. API 개념 설명 (비개발자용)
- **UI(User Interface)** = 사람이 차트를 보고 매수·매도 버튼을 누르는 접점. 인터페이스 = "정보나 신호를 주고받는 접점·경계면".
- **API** = 사람이 아니라 **프로그램**이 차트를 조회하고 주문을 넣기 위한 경계면. Application(증권사 앱) + Programming(프로그램) + Interface(경계면).
- 한 줄 정의: "**API는 조회나 주문을 요청하는 공식 창구**" [02:33].

### 10. 서비스 특징 주장 (전부 제공사/화자 주장, 미검증)
- Windows·Mac·Linux 어디서든 사용 가능(플랫폼 비종속), 사용법이 쉬움.
- **보유한 모든 계좌**로 거래 가능.
- 안정적인 API 제공.
- 상세한 API 가이드 문서 + **공식 GitHub에서 SDK와 MCP까지 제공** → 에이전트 연결이 쉽다는 것이 화자가 꼽는 핵심 강점([의견]) [03:31~03:43].

### 11. 세일즈·프로모션 구조 (정보로서 1회 기록)
- 영상은 NH투자증권 API 서비스 홍보 성격이며, 후반부에 **런칭 프로모션 3종**을 안내한다(제공사 안내 전달).
  1. **국내 주식 매매 수수료 1년간 우대**, 나무 계좌가 없는 **최초 신규 고객은 국내 주식 거래 수수료 24개월 완전 무료**.
  2. 이 API로 거래 시 **약 29,000원 상당 ChatGPT Plus 이용권**, **선착순 8,000명**.
  3. **선착순 1,000명 굿즈**(자막 "멀티플러그 굿즈" — 서비스명 오인식으로 보임).
- 신청 링크는 설명란·고정 댓글, **정확한 대상·기간·방법은 공식 이벤트 페이지 확인**이라고 명시한다 [20:37].
- 조코딩 GitHub 프롬프트 저장소 링크도 설명란·고정 댓글로 안내된다.

### 12. 화자의 주관·주의 발언 정리 ([의견] / 미검증)
- [의견] "전반적으로 플러스인데 모의 매매라서 아쉽습니다. 아, 진짜 돈 넣을 걸" [12:10] — **모의계좌 화면 표시값**에 대한 소감. 수익률 근거 아님.
- [의견] 실계좌 1사이클 후 "아, 벌써 올랐습니다" [16:36] — 극히 짧은 구간의 표시값.
- **마무리 당부(리스크 안내)**: "이거는 그냥 예시일 뿐이니까요. 직접 여러분만의 전략을 짜셔서 **모의 환경에서 충분히 테스트를 해 보신 다음에 실 거래에 적용**하라" [21:02].
- 영상 어디에도 **수익률 수치·목표 수익·백테스트 결과는 제시되지 않는다**. 제시된 것은 설정 절차와 1~2사이클의 화면 예시뿐이다.

## 3줄 오리엔테이션
- NH투자증권이 내놓은 증권 API 서비스(자막상 "나무 플러그")를 OpenAI의 **Codex 앱**에 붙여, 코드를 한 줄도 직접 쓰지 않고 **국내·미국 주식 자동매매 에이전트**를 만드는 과정을 처음부터 끝까지 시연하는 튜토리얼이다.
- 실제 작업은 조코딩이 GitHub에 **미리 짜 둔 한글 프롬프트 하나를 복사·붙여넣기**하는 것이 전부다. 그 프롬프트가 저장소 다운로드 → Python 설치·가상환경 → API 키 입력 → 투자 상담 → 전략 파일 수정 → 1시간 주기 예약 등록까지 순서대로 지시한다.
- 흐름은 **모의투자 → 실전투자 → 클라우드 상시 가동** 3단계다. 실전 단계에서는 텔레그램 봇을 연동해 **주문마다 사람이 3분 안에 승인해야 체결**되게 하고(손절·익절만 예외), 마지막에 DigitalOcean Droplet(월 $24)에 원격으로 같은 세팅을 올려 PC를 꺼도 돌게 만든다.

이 시점의 손익은 **모의투자 계좌의 화면 표시값**이며 검증된 수익률이 아니다.

### [00:11–01:05] 인트로 — "API 문서는 이제 사람이 보라고 만든 게 아니다"
조코딩은 이번 영상의 주제를 NH투자증권의 API 서비스(자막상 "나무 플러그")를 활용한 "바이브 자동매매" 만들기로 소개한다. 이 서비스는 NH투자증권이 만든 API 서비스로, 시세 정보 조회나 매매 주문을 API를 통해 처리할 수 있다.

전통적으로 API를 쓰려면 Python을 직접 설치하고 프로그램을 깔고 코드를 짠 다음, API 가이드 문서를 꼼꼼히 읽어가며 하나하나 개발해야 했다. 하지만 지금은 AI 에이전트·바이브 코딩의 시대라는 것이 화자의 전제다.

> "이제 이거는 사람이 보라고 만든 게 아니죠. AI 에이전트가 이거 보고 그냥 딸깍 한 번이면 싹 다 이해하고 내가 원하는 대로 구현을 해 줄 수가 있습니다." [00:53]

### [01:06–02:38] API란 무엇인가 — UI와 대비해 설명
API 용어를 모르는 시청자를 위한 개념 설명 구간이다. API는 Application Programming Interface의 약자인데, 풀어 써도 어렵기는 마찬가지라 화자는 UI와 대비해 설명한다.

주식 투자를 할 때 증권사 앱을 받아 차트를 보고 매수·매도 버튼을 누르는데, 이렇게 사람이 누르고 보는 접점이 **UI(User Interface)**다. 인터페이스는 "정보나 신호를 주고받는 접점이나 경계면"으로 정의된다. 그렇다면 사람이 아니라 **프로그램**이 차트를 보고 주문을 넣으려면 그에 맞는 경계면이 필요한데, 그 역할이 API라는 설명이다. 프로그램은 차트 조회 API를 통해 증권사에 요청을 보내고 차트 정보를 받아온다. Application(증권사 애플리케이션)과 Programming(프로그램)이 Interface(경계면)로 상호작용한다는 식으로 약자를 풀어준 뒤 한 줄로 정리한다.

> "API는 조회나 주문을 요청하는 공식 창구라고 요약을 해 볼 수가 있겠습니다." [02:33]

### [02:38–03:44] 서비스 재소개와 특징 — SDK와 MCP까지 제공
API를 이해했다는 전제로 서비스를 다시 소개한다. 내가 만든 투자 전략이 담긴 프로그램을 NH투자증권의 트레이딩 시스템에 연결해, 시세 조회·잔고 조회·주문 등을 연동할 수 있게 해 주는 API 서비스라는 것이다. 그러면 사람이 직접 매수·매도 버튼을 누르지 않아도 프로그램이 API를 통해 자동매매를 진행할 수 있다.

이어지는 특징은 모두 **제공사 측 주장**이다. ① 활용도가 높다 — Windows·Mac·Linux 어디에 한정되지 않고 어디서든 쓸 수 있다. ② 사용법이 쉽다. ③ 보유한 **모든 계좌**로 거래가 가능하다. ④ 안정적인 API를 제공한다. ⑤ 상세한 API 가이드 문서와 함께 **공식 GitHub**가 있고, 거기서 **SDK와 MCP까지 제공**한다. 화자는 마지막 항목을 두고 그래서 손쉽게 에이전트에 연결해 자동매매를 돌려볼 수 있다고 평한다([의견]).

### [03:44–05:09] 신청 절차 — QR 로그인부터 앱키·앱시크릿 발급까지
실제 신청 과정을 화면으로 따라간다. 자막상 `NH플러그.com`(정확한 도메인 표기는 `[불명확]`)에 접속해 **신청하기**를 클릭하면 API 사용 신청 화면이 뜨고, 화자는 **QR 로그인**을 택한다. QR 코드가 뜨면 나무증권 MTS 앱으로 로그인한다.

아직 NH투자증권 계좌가 없다면 구글 플레이 스토어나 앱 스토어에서 "나무증권"을 검색해 MTS를 받고, 그 앱에서 계좌 개설을 진행하면 된다. 스마트폰 카메라로 QR을 찍으면 앱에 로그인 요청이 오고, 확인을 누르면 API 사용 신청 화면으로 들어간다. 서비스 이용약관에 동의하고 신청하기를 누른 뒤(화자는 이미 발급받은 상태라 QR 인증을 한 번 더 거친다), 하단의 **보안 인증 키 확인**을 클릭하면 **앱 키(App Key)와 앱 시크릿(App Secret)** 두 개의 API 키가 나온다.

화자는 이 키의 성격을 "내 계좌에 접속할 때 필요한 API의 비밀번호 같은 것"이라고 설명하며, 노출되면 안 되니 메모장 같은 곳에 나만 볼 수 있게 저장해 두라고 당부한다. 개발할 때 이 값을 쓰게 된다.

### [05:09–05:52] Codex 설치 — openai.com/codex
개발 도구로는 **ChatGPT를 만든 OpenAI의 개발자용 도구 Codex**를 쓴다. `openai.com/codex`로 들어가면 다운로드 화면이 나오고, Windows 버전 또는 Mac 버전 다운로드 버튼이 뜬다. 인스톨러를 받아 클릭해 설치하고 실행하면 Codex 앱이 열린다. 이때 **ChatGPT 계정 연결이 필요**하므로, 아직 가입하지 않았다면 가입 후 연결하라고 안내한다.

### [05:52–06:24] Codex 프로젝트 만들기
Codex 앱에서 **프로젝트 옆 `+` 버튼**을 눌러 새 프로젝트를 만든다. 프로젝트 이름은 `NH`로 정하고, 소스 폴더를 지정한다. 폴더 위치는 아무 데나 상관없지만 화자는 C드라이브에 `NH`라는 폴더를 새로 만들어 지정한다. 폴더 선택 후 **프로젝트 만들기**를 누르면 이후 작업이 그 폴더 안에서 이루어진다.

### [06:24–08:13] 조코딩이 미리 만들어 둔 한글 프롬프트 — 5단계 자동 진행
NH투자증권 공식 GitHub의 API 문서를 직접 읽고 Codex에 넣어 시켜도 되지만, 화자는 시간을 아껴 주기 위해 **자신의 GitHub에 프롬프트를 미리 다 짜 두었다**고 밝힌다. 참고용 예제 코드도 함께 올려 두었고, 주소는 본문과 고정 댓글에 남긴다고 한다. 페이지를 조금 내리면 나오는 프롬프트를 **복사 버튼으로 복사해 붙여넣기만** 하면 된다.

붙여넣기 전에 프롬프트 설계 의도를 설명한다. 첫째, **개발을 모르는 사람 기준**으로 만들어서 터미널을 쓰거나 파일을 직접 수정하는 일이 전혀 없도록 했다. 둘째, 사용법은 언제든 바뀔 수 있으므로 **공식 홈페이지 링크들만 걸어 두어**, 바뀐 게 있으면 에이전트가 알아서 탐색해 새로운 방법을 적용하게 했다.

프롬프트가 지시하는 처리 순서는 다음과 같다.
1. **예제 코드와 틀이 들어 있는 저장소를 내려받는다** — git이 없어도 그냥 다운로드되도록 처리.
2. **Python 설치와 가상환경 생성** — 원래 일일이 직접 해야 했던 부분을 에이전트가 대신한다.
3. **셋업 실행 후 키 입력**.
4. **투자 상담** — 투자 전략은 개인마다 다르므로 개인에게 맞는 전략을 세우도록 돕는다.
5. **전략 검사 후 실제 자동매매가 되도록 예약을 건다** — 기본값은 **한 시간에 한 번 시장을 보고 매매**.

화자는 한 시간 주기는 예시일 뿐이니 각자 입맛대로 바꾸라고 하며, 프롬프트가 **한글**이라 코드를 고칠 필요 없이 원하는 방향으로 문장만 수정해 붙여넣으면 된다고 덧붙인다.

### [08:13–09:07] 프롬프트 실행 → 키 입력 웹페이지 → 모의투자 연결
복사한 프롬프트를 Codex의 NH 프로젝트 채팅창에 붙여넣고 엔터를 누른다. 잠시 기다리면 **웹페이지가 하나 열린다**. 앱 키와 앱 시크릿을 넣어야 하는데, 채팅창에 그대로 입력하면 값이 AI 쪽으로 넘어가 버린다. 그렇다고 `.env` 파일을 만들어 넣는 방식은 비개발자에게 복잡하므로, 화자는 **키 입력 전용 웹사이트를 띄우도록** 설계했다고 설명한다.

메모장에 복사해 둔 앱 키·앱 시크릿을 각 칸에 붙여넣고, 처음이므로 **모의투자**로 진행한다. 저장하고 연결 확인을 누르면 연결이 되고, 모의계좌라 현금 잔고가 크게 표시된다. 그 뒤 Codex 채팅창에 **"연결됐다"** 한마디만 보내고 엔터를 치면 다음 단계로 넘어간다.

### [09:07–10:07] AI 투자 상담 — 전략 수립
"연결됐다"를 보내면 곧바로 **투자 상담**이 시작된다. 사람마다 투자 성향도 다르고 하고 싶은 종목도 다르므로, AI가 그걸 파악할 수 있도록 마치 투자 자문 전문가처럼 Codex 안에서 채팅으로 상담을 받고 나만의 전략을 세우게끔 여러 질문을 넣어 두었다는 설명이다. 질문에 하나씩 답하면 투자 전략이 자동으로 만들어진다.

화자의 답변 결과는 **국내와 미국 양쪽 투자**, **반도체·AI 대형주 위주** 전략이다. 이어 현재 환율까지 확인하고 최종안을 보여준다. 종목과 매매 방식 설정은 **AI가 임의로 잡아 준 것**이라, 그대로 가도 되고 수정하고 싶으면 Codex와 상담하듯 자연어로 대화해 고칠 수 있다. 화자는 이대로 진행하기로 한다.

### [10:07–11:09] 전략 파일 수정과 자동매매 예약 등록
"이대로 진행"이라고 보내면 AI가 알아서 **전략 파일을 수정**하고, 조금 기다리면 "자동매매 준비 완료"가 뜬다. 상담한 투자 전략에 맞춰 전략 파일이 수정되도록 프롬프트에 설정해 두었다는 것이다. 촬영 시점에는 장이 닫혀 있어 실제 매매는 아무것도 일어나지 않았다.

대신 **자동매매 예약 등록**까지 자동으로 되도록 해 두었다. 한 시간마다 시장을 확인하며 매매하는 로직인데, **Codex에 실제로 "예약" 기능이 있어서** 열기 또는 예약 메뉴로 들어가면 `NH 자동 매매`라는 항목이 새로 만들어진 것을 볼 수 있다. 거기 적힌 명령어가 한 시간에 한 번씩 실행된다. 실행되면 NH 프로젝트 안에서 설정한 전략과 최신 뉴스를 가져와 투자 판단을 내리고 실제 매매를 진행한다. 뉴스나 설정값에 해당하면 매수하고, 전략에 따라 매도해야 하면 매도가 이루어진다.

### [11:09–12:25] 장 개장 후 실제 동작 — 뉴스 조회, 매도 주문, 대시보드
그대로 두면 장이 열렸을 때 한 시간 주기로 알아서 동작한다. 현재는 모의투자 설정이므로 모의투자로 매매가 진행된다. 컴퓨터를 계속 켜 두면 예약 작업이 계속 돌아가 한 시간에 한 번씩 기록이 찍힌다. 장이 안 열렸을 때는 "장 안 열려 있음"으로 아무 것도 하지 않고 넘어가고, 장이 열려 있으면 **상담을 통해 결정한 투자 원칙을 확인하고, 관련 종목의 뉴스 조회까지 진행**한다.

한 사이클이 끝나면 처리 결과가 나온다. 화면에는 **알파벳(Alphabet) 3주 매도 주문**, 나머지는 유지라는 결과가 뜨고, **AI가 판단한 이유까지 함께 표시**된다. 이어 자동매매 현황 대시보드가 열려 보유 종목과 손익을 한눈에 보여준다.

> "아, 전반적으로 플러스인데 모의 매매라서 아쉽습니다. 아, 진짜 돈 넣을 걸." [12:10]

[의견] 위 발언은 모의계좌 손익을 보고 한 소감이며, 특정 성과를 보장하는 근거가 아니다. 대시보드 아래쪽에는 지금까지 자동매매가 돌면서 **언제 무엇을 샀는지 시간대별 기록과 그 이유**가 전부 나열된다.

### [12:25–13:16] 실전투자 전환 — 전략 재상담
모의투자를 확인했으니 실제 돈으로 넘어간다. NH 프로젝트의 아무 채팅창에나 **"실전 투자"**라고 입력하면 실투자 준비가 시작된다. 이때 선택지가 두 개 제시된다. **모의투자 전략을 그대로 가져갈 것인가**, 아니면 **실제 돈이니 다시 투자 상담을 통해 전략을 새로 정할 것인가**. 화자는 실제 투자 상황에 맞게 전략을 조정하기로 하고, **국내장·미국장에 프리마켓/애프터마켓까지 모두 포함**하는 것으로 잡는다. 상담을 통해 후보군과 실전용 전략을 세운 뒤 "이대로 진행"을 보내면 전략이 실전에 맞게 수정된다.

### [13:16–13:46] 실전 전환 설정 화면과 텔레그램 승인 장치
진행하면 **실전 전환용 설정 화면**이 열린다. 여기서 중요한 안전장치가 등장한다.

> "실전 투자는 그냥 자동으로 막 되면 위험할 수 있기 때문에 이렇게 텔레그램과 연동하는 과정이 있습니다." [13:21]

텔레그램으로 알림을 받고 **사람의 승인이 있어야 매매가 진행**되도록 설정하는 것이다. 우선 앱 키·앱 시크릿을 처음과 똑같이 입력하고, 그다음 텔레그램 승인 연결을 진행한다. **텔레그램 연동이 되어 있어야 실제 계좌를 쓸 수 있다.**

### [13:46–15:00] 텔레그램 봇 만들기 — BotFather와 /newbot
봇 토큰이 필요하므로 텔레그램 봇 만드는 법을 따로 설명한다. 먼저 구글 플레이 스토어나 애플 앱 스토어에서 **텔레그램 공식 앱**을 받아 설치·로그인한다. 하단 돋보기 아이콘을 눌러 **BotFather**를 검색하면 체크 표시(공식 인증)가 달린 계정이 나온다. 이 계정을 클릭해 프로필로 가면 **앱 열기** 버튼이 있고, 누르면 앱이 열리면서 **새 봇 생성(create new bot / `/newbot`)** 버튼이 나온다.

여기서 봇의 이름과 프로필 사진 등을 정할 수 있다. 화자는 `NH_조코딩_bot`으로 이름을 지었다. 중요한 규칙은 **아이디가 반드시 `bot`으로 끝나야 한다**는 것이고, 중복되지 않는 고유한 이름이어야 한다. **Create Bot**을 누르면 봇이 생성되고 **API 키(봇 토큰)**가 표시되는데, 복사(copy) 버튼을 눌러 복사해 사용하면 된다.

### [15:00–15:40] 봇 토큰 입력 → 채팅 시작 → 실계좌 저장
복사한 봇 토큰을 설정 화면에 붙여넣고 **토큰 확인**을 누르면 내가 만든 봇과 연결된다. 연결된 봇을 눌러 채팅을 시작할 수 있는데, 스마트폰으로 링크를 전송해 열면 텔레그램 앱에서 채팅방이 열린다. 채팅방에서 **시작(Start)** 버튼을 누르면 연결이 완료된다. 그 뒤 설정 화면으로 돌아가 **실제 계좌**로 세팅하고 저장하면 실계좌와 연동된다. 마지막으로 Codex 채팅으로 돌아와 **"다 했다"**라고 입력한다.

### [15:40–16:46] 실계좌 전환 완료 — 3분 승인 규칙와 예외
이제 실제 계좌로 전환이 끝났다. 동작 규칙은 다음과 같다.
- **주문마다 텔레그램으로 확인 알림**이 간다.
- 사람이 **3분 안에 승인하면 매매가 체결**되고, **3분이 지나면 취소**된다.
- **거절**을 누르면 주문이 나가지 않는다.
- 예외: **손절·익절은 놓치면 안 되므로, 미리 정해 놓은 손절·익절은 항상 승인 없이 진행**된다.

실주문 상황에서 텔레그램 알림이 오는 화면을 보여주며 화자는 설계 의도를 명확히 밝힌다.

> "그냥 AI한테 완전히 맡기는 게 아니라 실제로 텔레그램으로 마지막으로 확인한 뒤에 제가 명시적으로 승인을 눌러야 전송이 되도록 구현을 해 놨습니다. 그래서 승인을 누르지 않으면 주문이 나가지 않습니다." [16:15]

### [16:46–17:11] 실계좌 한 사이클 결과와 상시 가동 문제
한 사이클이 완료되면 모의투자 때와 마찬가지로 자동매매 현황에서 보유 종목을 볼 수 있다. 화자는 "아, 벌써 올랐습니다"라고 반응하는데([의견], 짧은 구간의 화면 표시값), 어떤 매매를 했고 왜 그런 판단을 내렸는지 상세 내역도 함께 확인된다.

여기서 구조적 제약이 하나 드러난다. **자동매매가 계속 돌려면 Codex가 켜진 컴퓨터가 켜져 있어야** 예약이 동작하고, 프로젝트의 Python 파일이 실행된다. 노트북을 쓴다면 꺼야 할 때가 생기므로, 상시 켜 둘 컴퓨터가 없다면 **클라우드 서비스**를 쓰면 된다는 것이다.

### [17:11–18:10] DigitalOcean Droplet 준비 — 월 $24와 결제 등록
클라우드는 여러 선택지가 있지만 화자는 **DigitalOcean**을 쓴다. "쉽게 말해 컴퓨터를 빌려주는 업체"이며, 클라우드 컴퓨터에 올려 놓고 돌린다고 생각하면 된다는 설명이다. 회원 가입을 하고, **Droplet**이라는 서비스를 이용한다.

비용 관련 사항은 다음과 같다(화자 설명). **Codex에서 연동해 쓰려면 월 24달러짜리 Droplet을 사용해야 한다**고 한다. 비용이 드는 서비스이므로 DigitalOcean에 가입한 뒤 왼쪽 메뉴 **Account → Billing**에서 신용카드를 등록해 두어야 하고, 등록해 두면 사용한 만큼 비용이 빠져나간다.

### [18:10–19:03] Codex의 DigitalOcean 플러그인과 원격 SSH 연결
Codex의 **플러그인** 메뉴로 들어가 "디지털"로 검색하면 **DigitalOcean 플러그인**이 나온다. 화자가 꼽는 장점은 **리모트 Codex의 SSH를 쓸 수 있다**는 점으로, 마치 Mac mini 한 대를 빌려 항상 켜 놓듯이 쓸 수 있다는 비유를 든다([의견]).

플러그인을 설치하고 로그인·승인까지 마치면 계정이 연동된다. 설치 후 **사용해 보기**를 눌러 기본 명령어를 그대로 실행하면, 계정이 연동된 상태라 세팅이 자동으로 진행된다. 명령어 한 번에 체크와 **예약 작업 등록**까지 전부 자동 완료된다. Codex의 **SSH 호스트 추가**도 되고 바로 연결된다. 토글해서 켜면 원격 클라우드 서버와 연동되며, Codex에서 로그인을 한 번 해 주면 "연결됨" 상태가 된다.

### [19:03–19:50] 원격 프로젝트 생성 — 로컬과 동일한 절차 반복
왼쪽에서 **앱으로 돌아가기**를 눌러 프로젝트 `+`를 누르면 이번에는 **로컬뿐 아니라 원격도 설정 가능**하다. 다음을 눌러 `NH클라우드`라는 프로젝트를 새로 만들고 소스 폴더를 지정하는데, 화자는 루트 폴더의 `workspace`로 들어가 거기에 만든다. 프로젝트를 추가하면 클라우드 컴퓨터와 연결된 프로젝트가 생기고, **여기서 같은 작업을 하면 원격에서 동작하므로 돌려놓고 컴퓨터를 꺼도 알아서 돌아간다**.

절차는 로컬과 동일하다. GitHub에서 같은 명령어(프롬프트)를 복사해 넣으면 원격 서버에서 자동매매 설정 화면이 뜨고, 똑같이 키를 넣는다. 실제 자동매매를 하려면 이번에는 **실제 계좌**를 선택해 저장하고 연결을 누르면 된다. 나머지 과정은 로컬과 전부 같다.

### [19:50–20:43] 나무 플러그 런칭 프로모션 이벤트 3종 (제공사 안내)
서비스 런칭 프로모션 이벤트가 진행 중이라며 세 가지를 소개한다. 아래는 전부 **제공사 측 안내를 화자가 전달한 것**이다.
1. **국내 주식 매매 수수료 1년간 우대 혜택** 제공. 게다가 아직 나무 계좌가 없는 **최초 신규 고객**이라면 **국내 주식 거래 수수료 24개월간 완전 무료**.
2. **약 29,000원 상당의 ChatGPT Plus 이용권** — 이 API 서비스를 사용해 거래하면 제공. **선착순 8,000명**.
3. **선착순 1,000명에게 굿즈** 제공(자막상 "멀티플러그 굿즈", 서비스명 오인식으로 보임).

신청 링크는 설명란과 고정 댓글에 남긴다고 안내하며, 정확한 이벤트 대상·기간·신청 방법은 **공식 이벤트 페이지에서 확인**하라고 덧붙인다.

### [20:43–21:31] 마무리 — "예시일 뿐, 모의에서 충분히 테스트하라"
전체 흐름을 되짚는다. 서비스 신청 → Codex 설치 → 프롬프트 한 방으로 자동매매 세팅 → 투자 성향에 맞춘 전략 수립과 데이터 연계 → 모의 자동매매 → 실제 자동매매까지 함께 진행했다는 정리다. 그리고 마지막 당부가 붙는다.

> "여러분들도 해 보실 때 이거는 그냥 예시일 뿐이니까요. 직접 여러분만의 전략을 짜셔서 모의 환경에서 충분히 테스트를 해 보신 다음에 실 거래에 적용을 하셔서..." [21:02]

영상에서 사용된 링크들은 고정 댓글과 설명란에 남겨 두었으니 직접 해 볼 사람은 참고하라고 안내하고, 구독·좋아요 요청과 함께 영상을 마친다.
