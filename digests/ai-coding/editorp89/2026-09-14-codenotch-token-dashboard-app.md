# [시즌 3] 컴퓨터에 토큰 계기판을 달아주는 심플 앱, Codenotch(무료)

> editorp89 · 2026-09-14 · 611회 · 3분 35초 · [영상 링크](https://youtu.be/_L6Ih-UEhTY)
> 정리 방식: 시간순 심층 워크스루 (paraphrase) + 주제별 상세 요약
> 검증 배너: 앱 기능·동작에 대한 서술은 대부분 화자가 자기 화면에서 시연·설명한 내용이며, 공식 문서로 교차검증된 것이 아니다. 화자는 "이거 쓴다고 돈 받은 거 없다"고 직접 밝혔다(광고 아님 주장, 미검증).

## 요약 (주제별)

### 도구 정체 — Codenotch가 뭘 하는 앱인가
- 화면 가장자리에 **노치(notch) 형태의 status 창**을 상시 띄워 AI 에이전트 상태를 보여주는 macOS용 오픈소스 무료 앱.
- 표시 항목 세 가지: ① Claude Code·Codex 등 **요금제 사용량(usage)** ② **세션 잔여 / 리셋 시점** ③ 지금 **에이전트가 돌고 있는지 여부**.
- 배포처는 GitHub(github.com). 링크는 영상 더보기란에 넣겠다고 안내 [01:01].
- 영상 제목의 "토큰 계기판"이라는 표현대로, 새로운 기능을 만드는 앱이 아니라 **이미 있는 상태값을 눈에 보이게 계기판화하는** 성격이다.

### 설치 절차
- GitHub 페이지의 macOS용 다운로드 버튼(자막 "다운로드 4 메고 S" = download for macOS)에서 받는다.
- 설치는 macOS 표준 방식: **다운로드 → 더블 클릭 → 드래그 앤 드롭** 하면 끝 [01:31–01:38].

### 설정 — Appearance(표시 방식·위치·테마)
- **표시 모드 2종**: `Always Show`(항상 보임, 화자 선택) / `Show on Hover`(마우스를 갖다 대면 올라옴). Appearance에서 스크롤을 살짝 내리면 나온다 [01:43–01:58].
- **배치 위치**: 좌/우로 옮길 수 있고, Edge 설정으로 left·top·bottom 등 원하는 변에 붙일 수 있다. 화자는 **오른쪽**이 편해서 오른쪽 사용 [01:15, 01:58–02:04].
- **테마**: Light(화자 기본) / `Solid Black`(다크, 검정색으로 더 명확하게 보임) / Liquid Glass(투명) [02:19–02:28, 03:19].
- [불명확: 원문 "쇼 드레"] — Appearance 안의 특정 항목명으로 보이나 자막만으로 확정 불가.

### 설정 — Accounts(에이전트 연동)
- **Accounts 탭이 컴퓨터에 이미 설치된 에이전트를 자동 감지**해서 목록에 올려준다 [02:04–02:12].
- 감지가 안 된 것은 목록 아래에서 **해당 항목 토글을 수동으로 켜면** 된다.
- 클라우드 요금제뿐 아니라 **로컬 LLM 런타임의 연결 상태**도 볼 수 있다는 화자 설명(미검증): Ollama(자막 "올라무나"), 그리고 [불명확: 원문 "딥 스튜디오"].

### 화자가 발견한 버그·미해결 옵션
- **Liquid Glass(투명) 테마가 적용되지 않는 버그** — Solid Black에서 투명으로 바꿔도 투명이 표현되지 않는다. 화자는 "버그 같다 / 좀 이상하다"고 평가하고 Solid Black을 계속 쓸지 고민하는 선에서 마무리. 재현 조건·앱 버전 언급 없음 [03:14–03:26].
- [불명확: 원문 "쇼 유제 페이스"] 옵션은 **화자 본인도 뭔지 모른다고 인정**하고 기본값(꺼짐)으로 둔다 [02:53–02:58]. 추측 설명을 하지 않는 태도.
- [의견] 앱 아이콘이 하얀색인 이유를 모르겠다며 "이분이 좀 약간 센스가 없다"고 가볍게 지적 [01:05].

### 추천 근거와 대상 사용자
- 대상은 **에이전트를 여러 개 병렬로 돌리는 사용자**. 영상 첫 문장부터 대상을 이렇게 좁힌다 [00:00].
- [의견] "요즘에 한 개만 쓰는 분은 거의 없다 / 여러 개 놓고 보는 사람이 상당히 많다" — 멀티 에이전트 사용이 보편적이라는 화자 체감 기반 주장(미검증) [02:33–02:39].
- [의견] 전체 총평은 "엄청 대단한 건 아닌데" + "멋있고 편리하다" + "굉장히 좋은 앱" + "강력 추천". 즉 혁신이 아니라 **편의성 소품**으로 추천한다 [00:26, 01:28, 03:04].
- 사용량·리셋 시점이 **바로바로 직관적으로** 표시되는 점을 실사용 가치로 꼽는다 [01:24].

### 출처·이해관계 고지
- 화자 본인이 발굴한 도구가 아니라 **지인 차지우가 알려준 것**이라고 출처를 명시하고, 영상 끝에 감사 인사를 다시 전한다 [00:07, 03:02].
- 차지우의 저서가 언급되지만 화자가 직접 **"책광고는 아니다, 말이 나온 김에 말하는 것"**이라고 선을 긋는다 [00:15].
- **금전적 이해관계 없음을 명시**: "이거 쓴다고 돈 받은 거 없다"(주장, 미검증). 대신 GitHub 스타를 눌러 개발자를 응원해달라고 요청하며 본인도 누르겠다고 말한다 [03:07].

### 향후 계획·예고
- 코드를 직접 열어 **한글 버전을 빌드해볼까** 하는 생각을 언급하지만, [의견] 한글이 아니어도 직관적으로 쓸 수 있게 만들어져 있어 굳이 필요하진 않다는 쪽으로 정리 [02:40–02:48].
- 앞으로도 유용한 툴이 나오면 바로바로 소개하겠다고 예고하며 마무리 [03:28].

## 3줄 오리엔테이션
- macOS에서 Claude Code·Codex 등 여러 AI 에이전트의 **요금제 사용량과 세션 잔여·리셋 시점**을 화면 가장자리 노치(notch) 형태로 상시 표시해주는 오픈소스 무료 앱 "Codenotch"를 소개하는 3분짜리 짧은 툴 추천 영상이다.
- 다운로드·설치(드래그 앤 드롭)부터 Appearance 설정(항상 표시 / 호버 시 표시, 배치 엣지, 테마), Accounts 탭에서 에이전트 자동 감지·수동 활성화까지 한 번 훑는다.
- 에이전트를 **여러 개 병렬로 돌리는 사람**에게 유용하다는 것이 화자의 추천 근거이며, 화자 본인이 발견한 것이 아니라 지인(차지우)이 알려준 도구라고 밝힌다.

## 전문 — 시간순 워크스루

### [00:00–00:07] 오프닝 — 에이전트 여러 개 쓰는 사람용 오픈소스
화자는 인사와 함께 "에이전트를 여러 가지 쓰시는 분들을 위해" 기가 막힌 오픈소스 애플리케이션을 알아봤다며 영상을 연다. 대상 독자를 처음부터 **멀티 에이전트 사용자**로 좁혀서 시작한다.

### [00:07–00:22] 출처 밝히기 — 지인 차지우가 알려준 도구
이 도구를 자기가 발굴한 게 아니라, 자기 쪽 도서의 저자 중 한 명인 차지우가 알려줬다고 출처를 명시한다. 차지우가 "이것저것 신기한 유틸리티 애플리케이션을 많이 알고 계신다"고 소개하면서, 그 사람의 책 이야기가 나온 것은 **광고가 아니라 말이 나온 김에 언급한 것**이라고 선을 긋는다.

> "책광고는 아니고 이제 말씀드리는 김에 그냥 말씀드리는 겁니다." [00:15]

### [00:22–00:39] 설치해 본 소감과 영상 성격 예고
화자는 Codenotch를 설치해 봤고, "엄청 대단한 건 아닌데 설치해 놓으니까 좀 약간 멋있기도 하고 그다음에 좀 편리한 것도 있다"고 평가한다. [의견] 대단한 혁신은 아니지만 병렬로 에이전트를 여러 개 돌리는 사람에게는 유용할 것 같아서 짧은 영상으로 준비했다는 것. macOS(애플 실리콘/맥 유저) 사용자에게 특히 반가운 소식이 될 것이라고 덧붙인다 — 자막상 "애플리 어 메고 유저분들"은 **macOS 유저**를 가리키는 음차로 보인다.

### [00:39–00:58] 무엇을 보여주는 앱인가 — 화면 오른쪽 status 창
화면 오른쪽에서 status 창이 돌고 있는 상태를 보여주며, 이 창으로 확인할 수 있는 것을 열거한다. (1) Claude Code 요금제·Codex 요금제 등 **내가 지금 요금제를 얼마나 쓰고 있는지**, (2) **세션이 얼마나 남았는지**, (3) 지금 **에이전트가 돌고 있는지 안 돌고 있는지**. 화자는 실제로 에이전트를 돌리는 중이라 그 상태가 반영되고 있다고 말한다. 이런 status 창을 누군가 **오픈소스로 공개했다**는 것이 이 영상의 본론이다.

### [00:58–01:08] 배포처와 아이콘에 대한 한마디
프로그램 이름은 Codenotch이고, GitHub(github.com) 링크를 영상 더보기란에 넣겠다고 안내한다. 곁들여 [의견] "이분이 좀 약간 센스가 없습니다. 이 아이콘이 왜 이렇게 하얀색인지 모르겠어요"라며 아이콘 색 선택을 가볍게 지적한다. 다만 기능 자체는 "명확하다"고 바로 이어 붙인다.

### [01:08–01:20] 노치 위치 이동 — 좌/우 배치
오른쪽에 노치를 띄워 놓고 위치를 옮길 수 있다는 점을 시연한다. 화면에서 이리저리 돌려보며 "이거 뭔지 모르겠지만" 하다가, 왼쪽·오른쪽으로 위치를 옮길 수 있다는 것을 확인한다. 원하는 자리에 배치하면 되고, **화자 본인은 오른쪽이 편해서 오른쪽을 쓴다**고 말한다.

### [01:20–01:29] 표시 정보의 직관성 평가
이 노치를 켜 두면 사용량(usage)이 얼마나 남았는지, **리셋이 언제 되는지**가 바로바로 직관적으로 표시된다고 정리한다. [의견] "굉장히 좋은 앱입니다"라는 것이 화자의 총평.

> "유제가 얼마나 남았는지 리셋이 언제 되는지 뭐 이런 것들을 바로바로 이게 직관적으로 표시를 해 줘 가지고 굉장히 좋은 앱입니다." [01:24]

### [01:29–01:38] 설치 방법 — macOS 표준 드래그 앤 드롭
GitHub 페이지에 macOS용 다운로드 버튼이 있다고 안내한다(자막 "다운로드 4 메고 S" = download for macOS). 설치 절차는 macOS 앱의 전형적 방식 그대로다: **다운로드 → 더블 클릭 → 드래그 앤 드롭** 하면 바로 설치된다.

### [01:38–01:58] Appearance 설정 — 항상 표시 vs 호버 시 표시
설치 후 화자처럼 노치를 **항상 보이게** 하려면 Codenotch를 켠 뒤 Appearance(자막 "어런스") 설정으로 들어간다. 스크롤바를 살짝 내리면 표시 관련 옵션이 있고, 여기서 두 가지 모드를 고를 수 있다: **Always Show**(항상 보이는 모드)와 **Show on Hover**(마우스를 갖다 댔을 때 올라오는 모드). 화자는 항상 보이는 쪽으로 설정했다. [불명확: 원문 "쇼 드레"] — Appearance 안의 특정 항목명을 부른 것으로 보이나 자막만으로는 확정 불가.

### [01:58–02:04] 배치 엣지 선택 — left / top / bottom
Edge(가장자리) 설정을 옮기면 left, top, bottom 식으로 노치를 화면 어느 변에 붙일지 고를 수 있다고 안내한다. 앞서 좌/우 이동을 보여준 것에 더해, **상·하 변까지 포함해 원하는 위치에 붙여 쓸 수 있다**는 설명이다.

### [02:04–02:19] Accounts 탭 — 에이전트 자동 감지와 수동 활성화
설정 맨 아래쪽에 **Accounts** 항목이 있는데, 이 부분에서 앱이 **컴퓨터에 이미 설치된 에이전트를 스스로 감지해서 목록에 올려둔다**. 감지가 안 된 것들은 목록 아래에서 해당 항목의 토글을 직접 켜주면 된다. 화자는 Ollama(자막 "올라무나")나 [불명확: 원문 "딥 스튜디오"] 같은 것들도 연결 여부·상태를 볼 수 있다고 언급한다 — 즉 클라우드 요금제뿐 아니라 **로컬 LLM 런타임의 연결 상태**도 대상에 들어간다는 화자 설명(미검증).

### [02:19–02:28] 테마 — Light / Solid Black
화자 본인은 라이트 테마를 쓰는 중이고, 다크 모드를 원하면 **Solid Black**을 쓰면 검정색으로 조금 더 명확하게 보인다고 안내한다. 이런 식으로 자기 취향의 "계기판"을 만들 수 있어서 시청자에게 추천해 봤다는 것.

### [02:28–02:40] 추천 근거 — 요즘은 다들 에이전트를 여러 개 쓴다
[의견] "요즘에 뭐 그 한 개만 쓰신 분들은 거의 없잖아요"라며, 여러 에이전트를 동시에 띄워 놓고 보는 사람이 상당히 많으니 이 앱이 되게 좋다고 본다는 것이 추천의 핵심 논리다. (사용자 다수가 멀티 에이전트를 쓴다는 것은 화자 체감에 근거한 주장, 미검증.)

### [02:40–02:53] 한글 버전 빌드 아이디어와 최종 추천
화자는 코드를 직접 들어가서 **한글 버전을 만들어볼까** 하는 생각도 든다고 말하지만, 곧바로 [의견] 한글 버전이 아니어도 바로바로 직관적으로 쓸 수 있게 만들어 놨다고 평가한다. 그래서 굉장히 좋은 애플리케이션이니 보시는 분들도 한번 써 보시라고 추천한다.

### [02:53–02:58] 모르는 옵션은 모른다고 — "Show Usage Pace"
설정을 넘기다 [불명확: 원문 "쇼 유제 페이스"] 항목을 만나자 화자는 "이건 뭐지? 예, 잘 모르겠네요"라고 솔직히 인정하고 **기본값(꺼짐) 그대로 두겠다**고 말한다. 추측으로 설명을 지어내지 않고 넘어간다.

### [02:58–03:14] 감사 인사와 이해관계 고지, 그리고 스타 요청
자신은 이 도구를 유용하게 쓰고 있다며 알려준 차지우에게 감사 인사를 전한다. 이어서 **금전적 이해관계가 없음을 명시**하고, GitHub에 들어가서 스타를 눌러 개발자를 응원해달라고 요청한다. (본인도 지금 스타를 누르겠다고 말한다.)

> "이거 쓴다고 전 저 돈 받은 거 없으니까 들어가셔서 여기 저도 지금 스타를 누를 건데 스타 이렇게 눌러 주시고 응원해 주시면은 개발자가 신나서 더 개발을 열심히 하겠죠." [03:07]

### [03:14–03:26] 발견한 버그 — Liquid Glass 테마가 적용 안 됨
테마를 Solid Black에서 투명(Liquid Glass)으로 바꿨는데 **투명이 적용되지 않는다**며, 이건 버그 같다고 지적한다. Solid Black과 Liquid Glass 두 선택지 중 Liquid Glass가 바로 표현되면 좋겠는데 안 되는 건 좀 이상하다는 것. 결국 Solid Black을 쓸지 고민하는 선에서 마무리한다. (재현 조건·앱 버전은 언급되지 않음.)

> "근데 검정색 했다가 이거 투명으로 바꾸니까 그 투명이 안 되는 거는 좀 버그 같네요." [03:14]
