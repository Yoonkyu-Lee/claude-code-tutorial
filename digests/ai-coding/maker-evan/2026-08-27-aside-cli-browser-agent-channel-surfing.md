# 클로드 코드가 못 하는 일을 Aside CLI에 시켜봤습니다 (채널 70곳 파도타기)

## 요약 (주제별)

### 문제 진단 — 클로드 코드의 웹 조사가 왜 "처참"한가
화자는 클로드 코드가 웹을 아예 못 보는 건 아니라고 먼저 선을 긋는다. 주소를 주면 페이지를 읽고 검색도 한다. 문제는 세 가지다. ① **읽어오는 방식** — 페이지를 글자로 변환해 가져오는데 유튜브처럼 자바스크립트로 화면을 그리는 사이트는 껍데기만 남아 구독자 수도 관련 채널 목록도 안 보인다. ② **로그아웃 상태** — 관련 채널 추천은 로그인 상태에서 나오는 정보라 애초에 접근이 안 된다. ③ **페이지 간 이동 개념 부재**(제일 큰 문제) — 한 페이지씩 따로 가져오므로 "여기서 저기로 넘어간다"가 없고, 검색 결과 열 개를 거르지 않고 그대로 덮어온다. 그 결과 10년 전 영상, 구독자 100명 채널, 코딩과 무관한 채널, 같은 채널 3회 중복이 섞여 나온다(화자 경험, 미검증). 화자의 결론은 "모델이 멍청해서가 아니라 브라우저가 없어서" [01:29].

### Aside라는 도구 — 정체와 기능 이름
Y Combinator를 거친 회사가 만든 브라우저이며 크롬과 같은 뿌리를 쓴다. **현재 맥 전용**. 겉모습은 평범한 브라우저이고 차이는 옆에 붙은 채팅창 하나 — 여기에 일을 시키면 브라우저가 직접 클릭·타이핑한다. 사용자가 **이미 로그인해 둔 세션을 그대로 쓰기 때문에 "연동" 절차가 없다**. 공식 홈페이지가 내세우는 용례는 로그인이 걸린 대시보드 확인, 실패한 빌드 로그 열기, 스테이징 화면 스크린샷. 알아둘 기능 이름은 기억(메모리) / 루틴 / 비밀번호 금고 / **울트라브라우즈**. 울트라브라우즈는 자료가 여러 페이지에 흩어져 있을 때 쓰는 모드로, 공식 설명은 "근거가 많이 필요한 조사, 페이지 사이의 비교" — 화자는 이걸 "파도타기"라 부른다.

### CLI 사용법 — 설치·옵션·호출 방식 3종
설치는 설치 스크립트를 받아 실행하는 **한 줄**(설정 화면 버튼 설치도 가능). 명령 이름은 `aside`이고 큰따옴표 안에 시킬 일을 한국어로 그냥 쓰면 된다. 기억할 옵션 세 개: ① 모델 선택(클로드 등), ② **생각의 깊이**(꺼짐~최대, 맨 끝이 울트라브라우즈), ③ **세션 이어붙이기**(터미널을 껐다 켜도 이어짐). 계정을 여러 개 두면 회사/개인 계정을 골라 쓸 수 있다. 호출 방식은 셋으로 정리된다 — **말로 시킬 땐 Aside, 클로드 코드에 붙일 땐 MCP(설정 파일 네 줄), 한 치도 안 틀리게 순서를 밟아야 하면 REPL**(자바스크립트로 브라우저 직접 조종, 탭 열기·요소 짚기·스크린샷; 공식 문서 표현으로 "Playwright 같다"). 주소만 던지면 그 페이지를 그냥 여는 용법도 있다. 화자가 강조하는 전제: **이건 검색 API가 아니라 내 브라우저가 직접 움직이는 것** [03:22].

### 실제 실행 결과 — 채널 70곳 파도타기 (화자 관찰, 1회, 미검증)
명령 한 줄, 깊이는 울트라브라우즈. 지시 내용은 "AI 코딩을 다루는 한국 채널에서 시작 → 관련 채널로 계속 이동 → 구독자 1만 명 넘는 채널 8곳 확보 → 표로 정리". 진행 순서: 자기 **방문 기록**을 뒤져 시작 채널을 잡음(화자 본인 채널에서 출발) → 유튜브 검색 → 채널 페이지 구조 확인 → 인기 영상 읽기 → 채널 홈에 걸린 다른 채널 수집. 숫자로는 **1차 파도타기 40여 개 → 2차까지 총 70개 → 구독자 수 개별 확인 + 대표 영상 실제 열람으로 걸러 8개**. 결과 표에는 채널명·구독자 수·대표 영상 주소가 한 줄씩 붙었고 규모는 11만·9만대부터 최소 18,000명까지. 총 소요 **6분 50초**. 진행 중 화면에 한국어로 상황 보고가 계속 올라와("1차 40여 개 수집", "2차까지 총 70개") 이상하면 중간에 끊을 수 있다.

### 시키지 않은 부가 행동 — 판단과 자체 증빙
표를 준 뒤 요청에 없던 두 가지를 더 했다고 한다. ① **협업 대상 1곳 추천 + 이유** — "구독자는 작은데 대표 영상 조회수 20만, 구독자 대비 배율 10배쯤으로 제일 높으니 협업 제안엔 여기가 최적". ② **증빙 스크린샷** — 채널 페이지를 직접 열어 구독자 수 캡처를 찍고, 화면에 못 띄운 나머지는 폴더에 저장. 화자는 이를 "표를 믿을 근거를 스스로 만든 것"으로 평가한다. [의견]

### 클로드 코드와의 분업 구조
핵심 대비: **클로드 코드는 목록을 받아서 끝내고, Aside는 목록에서 하나를 골라 들어갔다가 아니면 되돌아 나온다** — 그 판단을 스스로 반복한다 [04:03–04:16]. 클로드 코드에는 "거르는 단계"가 없어 모은 걸 그대로 준다. 화자의 현재 조합은 코드는 클로드 코드에 맡기고, 자료가 필요하면 클로드 코드가 Aside를 부르게 하고, Aside가 긁어온 표를 파일로 저장해 클로드 코드가 그 파일을 읽는 방식이다. 효과는 **사람의 중간 복사·붙여넣기 단계가 통째로 사라진 것** [06:46]. 반대 방향은 금지 — **코드를 Aside한테 시키지 말 것**, 그건 클로드 코드가 훨씬 잘한다. "둘 다 잘하는 도구가 아니라 각자 잘하는 게 다른 도구." [의견]

### 리스크·주의 9가지 (화자가 직접 나열)
① 맥 전용 — 윈도우 사용자에겐 해당 없음. ② 울트라브라우즈는 **유료**(무료 요금제는 안내 화면). ③ **느리다** — 해당 조사도 몇 분씩 소요, 빠른 답이 필요하면 부적합. ④ **결과를 그대로 믿지 말 것** — 브라우저가 화면을 읽어 옮긴 숫자이고 표는 늘 맞아 보이니 원본 채널을 한 번씩 열어볼 것. ⑤ **성능 순위는 자체 발표** — 1등이라고 적혀 있지만 자기들이 매긴 것. 덧붙여 공식 문서에 "운영 환경 설정은 바꾸지 않습니다"라고 적혀 있으며, 내 계정으로 움직이는 도구인 만큼 **권한 범위는 사용자가 직접 정하라**. ⑥ **방문 기록을 본다** — 시작 채널을 화자 기록에서 찾은 사례. 설정에서 기억·기록은 끌 수 있다. ⑦ **에러가 난다** — 증빙 이미지 생성에서 3회 연속 실패, 다만 다른 방법으로 스스로 복구. ⑧ **시킨 것보다 더 준다** — 8곳 요청에 덤으로 11곳을 더 붙임. ⑨ **아직 어린 제품** — 버전이 계속 올라가 오늘 되던 게 내일 달라질 수 있다.

### 처음 쓰는 사람을 위한 팁
① 처음부터 큰 작업을 시키지 말고 **페이지 하나 요약**부터. ② 생각의 깊이를 무조건 올리지 말 것 — **자료 모으기는 낮게, 비교·판단은 높게**. ③ 숫자가 나오면 **원본을 한 번 열어볼 것** ("표는 언제나 그럴듯해 보입니다"). 마무리로 시청자에게 어떤 조사를 먼저 맡기고 싶은지 댓글을 요청하며, 다음에 직접 돌려보겠다고 예고한다.

### 도입 — "사람이 하면 30분 걸리는 일" [00:00–00:24]

> "결과가 좀 처참했습니다. 엉뚱한 데이터가 잔뜩 섞여 나와요." [00:17–00:23]

### 오늘의 도구와 결론 선언 [00:24–00:36]

오늘 붙여볼 것은 **Aside CLI**라고 밝힌다. 명령 한 줄이면 브라우저가 대신 돌아다닌다는 설명과 함께, 지금 보이는 화면이 실제로 도는 장면이라고 한다. 결론부터 말하면 "꽤 잘한다"는 것이고, 왜 잘하는지와 무엇을 못하는지를 모두 보여주겠다고 예고한다. [의견]

### 짚고 갈 전제 — 클로드 코드가 웹을 아예 못 보는 건 아니다 [00:36–00:58]

먼저 오해를 정리한다. 클로드 코드가 웹을 전혀 못 보는 것은 아니다 — 주소를 주면 그 페이지를 읽어오고 검색도 한다. 문제는 **읽어오는 방식**이라고 한다. 페이지를 글자로 바꿔서 가져오는데, 유튜브 같은 사이트는 화면이 자바스크립트로 그려지기 때문에 글자로 변환하면 껍데기만 남는다는 것이다. 그 결과 구독자 수도, 관련 채널 목록도 보이지 않는다.

### 두 번째 문제 — 로그아웃 상태 [00:58–01:06]

두 번째 문제는 로그인이다. 클로드 코드가 가져오는 페이지는 로그아웃 상태인데, 유튜브의 관련 채널 추천은 로그인 상태에서 나오는 정보다. 그러니 애초에 볼 수가 없다는 구조적 한계를 지적한다.

### 세 번째 문제 — 페이지에서 페이지로 넘어간다는 개념이 없다 [01:06–01:33]

세 번째가 제일 크다고 한다. 클로드 코드는 한 페이지씩 따로 가져오기 때문에 "여기서 저기로 넘어간다"는 개념 자체가 없다는 것이다. 그래서 검색 결과 열 개를 그냥 덮어오고, 쓸 것과 못 쓸 것을 걸러내지 않는다. 화자가 말한 "처참한 결과"의 정체가 이것이라고 한다. 실제로 섞여 나온 것들로는 10년 전에 올라온 영상, 구독자 100명짜리 채널, 아예 코딩과 상관없는 채널, 심지어 같은 채널이 세 번 나오는 경우를 든다 (화자 경험, 미검증).

> "클로드 코드가 멍청해서가 아니라요. 브라우저가 없어서 생기는 일입니다." [01:29–01:35]

### Aside 소개 — YC 출신, 크롬과 같은 뿌리, 맥 전용 [01:33–01:56]

그래서 브라우저를 붙여준다는 논리로 Aside를 소개한다. Y Combinator를 거친 회사가 만든 브라우저이고, 크롬과 같은 뿌리(Chromium 계열)를 쓴다고 한다. 지금은 맥에서만 돌아간다. 생김새는 평범한 브라우저이고 다른 점은 옆에 붙은 채팅창 하나인데, 여기에 일을 시키면 브라우저가 직접 클릭하고 타이핑한다. 이미 로그인해 둔 사이트를 그대로 쓰기 때문에 "연동"이라는 절차가 아예 없다는 점을 강조한다.

### 공식 홈페이지가 내세우는 쓰임새와 기능 이름들 [01:56–02:13]

공식 홈페이지가 제시하는 용례로는 로그인이 걸린 대시보드 확인하기, 실패한 빌드 로그 열어보기, 스테이징 화면 스크린샷 찍기가 있다고 전한다. 개발자가 편집기 밖에서 하는 일들이라는 성격 규정이다. 알아둘 기능 이름으로 **기억(메모리)**, **루틴**, **비밀번호 금고**, 그리고 오늘의 주인공인 **울트라브라우즈(Ultrabrowse)**를 든다.

### 울트라브라우즈 = 파도타기 모드 [02:13–02:24]

울트라브라우즈는 자료가 여러 페이지에 흩어져 있을 때 쓰는 모드다. 공식 설명으로는 "근거가 많이 필요한 조사, 페이지 사이의 비교"이며, 화자는 이게 곧 자신이 말하는 파도타기라고 해석한다.

### CLI 설치와 기본 사용법 [02:24–02:38]

여기까지는 앱 이야기였고, 오늘 다루고 싶은 것은 CLI라고 선을 긋는다. 설치는 설치 스크립트를 받아서 실행하는 한 줄이며, 설정 화면에서 버튼으로 깔 수도 있다. 설치하면 명령 이름이 `aside`가 되고, 큰따옴표 안에 시킬 일을 그냥 한국어로 쓰면 브라우저가 뜨고 일을 시작한다.

### 기억할 옵션 세 개 + 계정 선택 [02:38–03:08]

옵션은 여러 개지만 세 개만 기억하면 된다고 정리한다. ① **모델을 고르는 옵션** — 클로드를 쓸지 다른 걸 쓸지 선택. ② **생각의 깊이를 정하는 옵션** — 꺼짐부터 최대까지 단계가 있고, 맨 끝에 울트라브라우즈가 붙어 있다(앞서 말한 파도타기 모드가 여기에 있다). ③ **세션을 이어붙이는 옵션** — 하던 조사를 그대로 이어서 시킬 수 있고, 터미널을 껐다 켜도 이어진다. 여기에 더해 계정을 여러 개 쓰면 계정도 골라 쓸 수 있어서, 회사 계정과 개인 계정을 나눠 쓰는 식이 가능하다.

### 나머지 세 가지 사용법 — 주소 직접 열기 / MCP / REPL [03:08–03:28]

사용법이 세 가지 더 있다고 한다. 주소만 던지면 그 페이지를 그냥 연다. MCP 서버로 띄울 수도 있다. 그리고 REPL이라고 부르는 방식도 있다. 뒤의 두 개는 영상 후반에서 따로 다루겠다고 예고한다. 여기서 한 가지를 강조한다.

> "이건 검색 API가 아닙니다. 제 브라우저가 직접 움직이는 겁니다. 그래서 제가 로그인해 둔 화면을 그대로 봅니다." [03:22–03:29]

### 실제 명령 — 시킨 내용 [03:29–03:44]

이제 실제로 시켜봤다며 명령을 공개한다. 명령은 한 줄이고, 깊이는 울트라브라우즈로 올렸다. 시킨 내용은 네 가지다 — ① AI 코딩을 다루는 한국 채널에서 시작해라, ② 관련 채널로 계속 옮겨가라, ③ 구독자 1만 명 넘는 채널 여덟 곳을 찾아라, ④ 표로 정리해라.

### 실행 관찰 — 방문 기록부터 뒤진다 [03:44–04:03]

엔터를 치면 브라우저가 뜨는데, 화자가 재밌다고 한 지점은 그다음이다. 먼저 **자기 방문 기록을 뒤져** 시작할 채널을 찾는다. 그다음 유튜브에서 검색을 하고, 채널 페이지를 열어 구조를 확인하고, 인기 영상을 읽고, 채널 홈에 걸린 다른 채널을 긁어온다. 로그에는 "관련 채널 넘어가기를 시험하는 중"이라고 찍힌다고 한다 — 말 그대로 파도타기다.

### 클로드 코드와 갈리는 지점 [04:03–04:16]

여기가 클로드 코드와 갈리는 지점이라고 짚는다. 클로드 코드는 목록을 받아서 끝내지만, Aside는 목록에서 하나를 골라 들어가고, 들어가서 아니면 되돌아 나온다. 그 판단을 스스로 반복하며, 사람은 그냥 화면을 보고 있으면 된다는 것이다. [의견]

### 숫자로 본 경로 — 40여 개 → 70개 → 8개 [04:16–04:50]

숫자로 정리하면 이렇다 (화자 관찰, 미검증). 먼저 출발할 채널을 하나 잡는데, 방문 기록에 남아 있었기 때문에 **화자 본인 채널에서 시작**했다고 한다. 거기서 1차로 넘어가 40여 채널이 모였고, 멈추지 않고 2차로 또 넘어가 총 70개가 됐다. 중요한 대목은 그다음이다 — 70개를 그대로 주지 않고, 후보들의 구독자 수를 하나씩 확인하러 가고 대표 영상도 실제로 열어본 뒤 걸러서 여덟 개를 남겼다. 70개를 모아 8개를 준 셈이다.

> "클로드 코드는 이걸 거르는 단계가 없습니다. 모은 걸 그대로 줍니다. 차이가 여기서 납니다." [04:45–04:51]

### 진행 상황을 한국어로 계속 보고 [04:50–05:04]

작업 중 화면에 한국어로 계속 보고가 올라온다는 점도 장점으로 든다. "파도타기 1차에서 40여 개 수집했습니다", "2차까지 총 70개 수집했습니다" 같은 식이다. 지금 뭘 하고 있는지 다 보이니 중간에 이상하면 바로 끊으면 된다는 것이다.

### 결과 표 [05:04–05:16]

결과는 채널 여덟 곳이 표로 정리돼 나왔다. 채널명·구독자 수·대표 영상 주소가 한 줄씩 붙었고, 구독자 규모는 11만짜리도 있고 9만짜리도 있었으며 제일 작은 곳이 18,000명이었다고 한다 (화자 화면 기준, 채널명은 영상에서 언급되지 않음).

### 시키지 않은 판단 — 협업 대상 추천 [05:16–05:33]

여기서 하나를 더 하더라고 한다. 여덟 곳 중 한 곳을 골라 이유까지 붙여 추천했다는 것이다. 근거는 구독자는 작은데 대표 영상 조회수가 20만이고, 구독자 대비 배율이 10배쯤으로 제일 높으니 협업을 제안하기엔 여기가 제일 낫다는 논리였다. 화자는 이를 "시킨 적 없는 판단"이라고 평가한다. [의견]

### 스스로 만든 증빙 — 스크린샷 [05:33–05:47]

숫자를 적어놓고 끝내지도 않았다고 한다. 채널 페이지를 직접 열어 캡처를 찍고 "구독자 수 증빙"이라고 붙였으며, 화면에 못 띄운 나머지는 폴더에 따로 저장해 뒀다는 것이다. 표를 믿을 근거를 스스로 만든 셈이라고 평한다. [의견] 여기까지 전부 **6분 50초**가 걸렸다고 밝힌다 (화자 측정, 1회 관찰).

### 왜 CLI로 쓰나 ① — MCP로 클로드 코드에 물리기 [05:47–06:08]

그렇다면 왜 앱이 아니라 CLI로 쓰는가. 클로드 코드에 물릴 수 있어서라고 답한다. 방법은 두 가지인데 하나가 MCP다. 설정 파일에 네 줄만 추가하면 클로드 코드가 Aside를 도구로 부른다. 자료를 긁는 건 Aside가 하고 코드를 고치는 건 클로드 코드가 하는, 서로 잘하는 걸 나눠 갖는 구조다.

### 왜 CLI로 쓰나 ② — REPL [06:08–06:22]

다른 하나는 REPL이다. 브라우저를 자바스크립트로 직접 조종하는 방식으로, 탭을 열고 요소를 짚고 스크린샷을 찍는다. 공식 문서 표현으로는 **Playwright 같다**고 한다. 정해진 순서대로 정확히 밟아야 할 때 쓰는 방식이라는 설명이다.

### 세 가지 호출 방법 정리 [06:22–06:32]

정리하면 세 갈래다 — 말로 시킬 땐 그냥 Aside, 클로드 코드에 붙일 땐 MCP, 한 치도 안 틀리게 밟아야 하면 REPL. 같은 브라우저를 세 가지 방법으로 부르는 것이라고 요약한다.

### 화자가 요즘 쓰는 조합 — 복붙 단계가 사라졌다 [06:32–06:59]

화자 본인의 현재 조합은 이렇다. 클로드 코드에게 코드를 맡기고, 자료가 필요해지면 Aside를 부르게 한다. Aside가 긁어온 표를 파일로 저장하면 그 파일을 클로드 코드가 읽어서 쓴다. 사람이 중간에서 복사·붙여넣기 할 일이 없어졌다는 것이다.

> "예전엔 제가 브라우저를 열어서 긁어다 줬거든요. 그 단계가 통째로 사라진 겁니다." [06:46–06:52]

반대로 **코드를 Aside한테 시키지는 말라**고 못 박는다. 그건 클로드 코드가 훨씬 잘한다는 것이다. 둘 다 잘하는 도구가 아니라 각자 잘하는 게 다른 도구라는 정리다. [의견]

### 단점 ①~③ — 맥 전용 / 유료 / 느림 [06:59–07:18]

좋은 얘기만 하면 광고가 된다며 쓰면서 걸린 것들을 나열한다. 첫째, **맥에서만 된다** — 윈도우 사용자에겐 오늘 이야기가 남 얘기다. 둘째, **울트라브라우즈는 유료**이고 무료 요금제에서는 안내 화면이 뜬다. 셋째, **느리다** — 방금 그 조사도 몇 분씩 걸렸으니 빠른 답이 필요하면 맞지 않는다.

### 단점 ④~⑤ — 결과를 그대로 믿지 말 것 / 자체 발표 성능 순위 [07:18–07:43]

넷째, **결과를 그대로 믿으면 안 된다**. 브라우저가 화면을 읽어서 옮긴 숫자이고, 표만 보면 다 맞아 보이니 꼭 원본 채널을 한 번씩 열어보라고 권한다. 다섯째, **성능 순위는 자기들이 매긴 것**이다 — 1등이라고 적혀 있지만 자체 발표다. 여기에 더해 공식 문서에도 "운영 환경 설정은 바꾸지 않습니다"라고 적혀 있다고 전하며, 브라우저가 내 계정으로 움직이는 도구인 만큼 권한을 어디까지 줄지는 직접 정하라고 조언한다.

### 단점 ⑥~⑦ — 방문 기록을 본다 / 중간에 에러가 난다 [07:43–08:03]

여섯째, **방문 기록을 본다**. 앞서 시작 채널을 화자의 기록에서 찾았던 그 대목이다. 편하지만 이건 아는 상태로 써야 하며, 설정에서 기억과 기록은 끌 수 있다. 일곱째, **중간에 에러도 난다** — 증빙 이미지를 만들다가 세 번 연속 실패했다고 한다. 다만 다른 방법으로 스스로 돌아가 복구하긴 했다.

### 단점 ⑧~⑨ — 시킨 것보다 더 준다 / 아직 어린 물건 [08:03–08:14]

여덟째, **시킨 것보다 더 준다**. 여덟 곳을 달라고 했는데 덤으로 11곳을 더 붙였다는 것이다. 많이 주는 게 늘 좋은 건 아니라고 평한다. [의견] 아홉째, **아직 어린 물건**이다 — 버전이 계속 올라가고 있어 오늘 되던 게 내일 달라질 수 있다.

### 마무리 정리 — 빈자리를 채우는 도구 [08:14–08:38]

정리하면 클로드 코드는 코드를 잘 고치지만 웹을 돌아다니는 건 약하고, 그건 브라우저가 없어서라는 것이다. Aside는 그 빈자리를 채우며 특히 여기저기 넘어다니며 긁는 일에서 강하다. CLI를 깔면 명령 한 줄로 쓰고, MCP로 붙이면 클로드 코드가 알아서 부른다.

> "자료는 A사이드가, 코드는 클로드 코드가. 이렇게 나누는 게 지금은 제일 편했습니다." [08:33–08:38]

### 처음 쓸 때 팁 세 개 + 마무리 [08:38–08:58]

마지막으로 팁 세 개를 준다. ① **처음부터 큰 걸 시키지 마라** — 페이지 하나 요약부터 시켜보라. ② **깊이를 무조건 올리지 마라** — 자료 모으기는 낮게, 비교·판단은 높게. ③ **숫자가 나오면 원본을 한 번 열어봐라** — "표는 언제나 그럴듯해 보입니다." 끝으로 어떤 조사를 제일 먼저 맡겨보고 싶은지 댓글로 남겨주면 다음에 직접 돌려보겠다고 마무리한다.
