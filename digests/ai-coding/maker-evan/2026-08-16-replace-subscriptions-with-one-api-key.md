## 요약 (주제별)

### 문제 인식 — 구독 모델의 비용 구조
- 이미지 툴·영상 툴·화질개선 프로그램을 각각 결제하면 툴 구독료로만 매달 10만 원 가까이 나갔다(주장/미검증). 여섯 달 이렇게 썼다.
- 정산해 보니 결과물은 한 달에 열몇 장 수준. "열몇 장 만들자고 10만 원"이라는 자평.
- [의견] 가장 아까운 건 한 달 내내 안 켰는데도 결제 문자가 똑같이 오는 것. 남은 크레딧은 이월 안 되고 그냥 사라짐.
- [의견] 가장 답답한 건 모델 선택권이 툴에 있다는 점 — 새 좋은 모델이 나와도 툴이 붙여줄 때까지 기다려야 하고(두 달 뒤 or 끝까지 안 들어옴), "돈은 내가 내는데 뭘 쓸지는 툴이 정함" [00:58].
- [의견] 툴마다 UI가 달라 재적응 비용이 있고, 다운로드→폴더→재업로드 "옮기는 작업"을 하루 몇 번씩 반복.

### 해법 구조 — 클로드 데스크톱 + API 키 하나
- 지금 쓰는 건 딱 둘: 클로드 데스크톱 앱 + API 키 하나.
- 비유: 뷔페 정기권(안 가도/두 접시만 먹어도 값 동일)을 끊고 단품 주문(먹은 것만 계산)으로 전환.
- API 키 = "가게 열쇠". 이미지·영상·화질개선 회사들을 한 군데 모아둔 곳(Replicate)에서 열쇠 하나 받으면 그 안의 모든 가게 이용 가능. 그 열쇠를 클로드에게 쥐여줌.
- 말로 시키면 클로드가 대신 주문·수령하고 쓴 만큼만 과금. 안 쓰면 0원(지난달 미사용 시 청구서 0원, 주장/미검증) [02:08].

### 스킬 = 클로드에게 주는 업무 매뉴얼
- 어렵게 볼 것 없이 "새 직원에게 주는 업무 매뉴얼". 이럴 땐 이렇게/저럴 땐 저렇게를 파일 하나에 적어둔 것.
- 예: 이미지 만들 땐 이 모델 쓰고, 비용은 미리 알려주고, 결과물은 이 폴더에 저장 — 미리 적어두면 매번 설명 불필요, 한번 적으면 계속 재사용.

### 실전 ① 이미지 생성 — 프롬프트 번역
- 대충 던진 한 문장("정장 입은 고양이가 지하철에서 신문 보는 사진")을 클로드가 모델용 상세 프롬프트로 다시 씀 — 털 색·정장 원단·창문 빛 방향·"85mm 렌즈 느낌, 배경 흐리게" 등을 화자가 말 안 해도 붙여줌.
- 이유: 이미지 모델은 구체적 지시가 필요한데, 그 번역을 클로드가 대신 → 화자는 아이디어만 던짐.
- 비용: 한 장 15센트(약 200원), 최고 화질 30센트(약 400원)(주장/미검증, [불명확: 자막 원문 "15cm트"·"30c"·"사케이 최고 화질"]). 결과물은 로그인·다운로드 없이 로컬 폴더에 바로 저장.

### 실전 ② 내 얼굴 유지 편집
- 문제: 보통 자기 사진을 넣으면 눈이 커지거나 턱이 깎여 남이 나옴. → 레퍼런스 처리 방식을 따로 잡아 "얼굴은 건드리지 말라"고 못박음.
- 실행: 프로필 사진 + "얼굴·안경·머리 그대로, 밝은 사무실 노트북 앞 장면으로, 창문 빛 왼쪽, 검은 자켓 유지". 결과에서 안경태·앞머리 갈래 유지, 본인이 봐도 자기라고 평가. 한 장 200원(주장/미검증).
- 활용: 프로필 한 장으로 썸네일·홍보물 무한 생성(스튜디오 촬영과 비교 불가). 배경/표정/옷 색 변경, 다중 사진 합성(내 사진+제품 사진 → "이 사람이 이 제품 든 걸로")도 가능. 예전 포토샵 작업을 말로 대체.

### 실전 ③ 영상 생성 — 초당 과금 & 실행 전 비용 고지
- 영상은 이미지(장당)와 달리 초당 과금 → 10초 vs 4초 가격 2배 넘게 차이.
- 지시: "4초짜리 영상, 소리 없이 화면만". 소리 빼면 초당 15센트→10센트로 하락, 나레이션은 따로 넣으므로 뺌(주장/미검증, [불명확: "15cm트"·"10트"]). 4초에 400원.
- [의견] 가장 마음에 드는 지점: 실행 전 "4초에 400원 진행할까요?"로 비용 고지 → 결제 후 후회 없음. 구독은 크레딧이 그냥 빠져나감.
- [의견] 팁: 길게 뽑지 말고 4초씩 여러 개. 길게 뽑으면 중간이 이상해도 통째로 버려야 하지만 4초는 문제 컷만 재생성, 편집도 편함. 웬만하면 4초로 통일.

### 모델 선택 기준
- 이미지: 어차피 200원이니 그냥 제일 좋은 모델. (몇백 원 아끼려다 결과물 아쉬운 게 더 손해)
- 영상: 초당이라 계산. '패스트' 버전을 기본(화질 차이 작고 값은 절반 아래), 정말 중요한 컷만 비싼 걸로 재생성.
- 전환은 설정 화면 없이 모델 이름만 바꿔 말하면 됨. 모르면 클로드에게 "이 작업에 뭐가 제일 싸냐" 물으면 후보 + 값 제시.

### 실전 ④ 화질 개선(업스케일)
- "이거 4K로 올려 줘" 한마디. 전용 프로그램은 30만 원 넘게 사야 하고 사용 횟수와 무관하게 값 동일(본인은 사놓고 1년에 몇 번 못 씀)(주장/미검증) → 이 영상 업스케일 비용 400원.
- 처리 시간: 4초짜리에 약 2분(백그라운드 처리, 끝나면 알림). 결과는 머리카락·윤곽 선명, 3,840×2,160 진짜 4K.
- 자기 영상뿐 아니라 남에게 받은/옛날 저화질 영상도 파일 던지면 동일하게 업스케일.

### 종합 효과 — 비용 + 워크플로 통합
- 네 작업(이미지 생성·얼굴 편집·영상 생성·업스케일) 합계 1,800원 vs 구독 10만 원(주장/미검증).
- [의견] 돈보다 큰 가치 둘: (1) 새 모델 나오면 그날 바로 사용(툴 회사 대기 불필요, 이름만 말함), (2) 다운로드→폴더→재업로드가 사라지고 이미지→영상→업스케일이 한 창에서 쭉 이어짐(손대는 것 없음) [08:47].

### 시작 절차 & 트러블슈팅
- 세 단계: ① Replicate 가입 → 프로필 → "API 토큰 만들기"로 열쇠 발급. ② 키는 채팅창에 붙여넣지 말고, 클로드에게 물어 파일에 보관. ③ 카드 등록 후 소액 충전(무료 크레딧 없음; 본인은 2만 원, 이 정도 사용이면 한참 감, 주장/미검증). + 스킬 파일 하나면 세팅 끝.
- [의견] 보안 습관: 남이 만든 파일은 넣기 전에 클로드에게 "보안상 문제 없는지" 먼저 검사시키기.
- 초보 막히는 두 지점: (1) 키 넣었는데 안 됨 → 대개 저장 후 앱을 껐다 켜지 않음, 재시작하면 됨. (2) 사진을 못 찾음 → 창에 드래그만 하면 위치를 모를 때가 있으니 우클릭→경로 복사로 파일 위치도 같이 전달.

### 세일즈·후속 안내
- 오늘 쓴 스킬과 세팅 방법은 설명란에 정리해 올린다고 함.
- 후속 예고: 나레이션 만들기도 같은 방식으로 전환한 편 예정. 시청자에게 구독 중인 툴을 댓글로 받아 대체법을 찾아주겠다고 유도.
- 커뮤니티: "스킬샵"과 "오픈톡방"에서 더 깊은 이야기.

## 3줄 오리엔테이션
- 이미지·영상·화질개선 툴 세 개를 각각 구독하면 안 써도 돈이 나가고 크레딧은 이월도 안 되는데, 화자는 이걸 클로드 데스크톱 앱 + Replicate API 키 하나로 바꿔 "쓴 만큼만" 내는 구조로 전환했다.
- 클로드가 대충 던진 요청을 모델용 프롬프트로 번역하고, 레퍼런스 사진의 얼굴을 유지한 편집, 초당 과금인 영상 생성(실행 전 비용 고지), 4K 업스케일까지 한 창에서 이어서 처리한다.
- 시작은 세 단계(Replicate 가입해서 API 토큰 발급 → 그 키를 파일에 안전하게 보관 → 카드 등록 후 소액 충전) + 스킬 파일 하나면 세팅 끝이라고 안내한다.

## 전문 — 시간순 워크스루

### [00:00–00:11] 훅 — 이번 달 1,800원
화자는 이번 달에 이미지와 영상을 만드는 데 쓴 돈이 1,800원이라고 밝히며 시작한다(주장/미검증). 원래는 툴 구독료로만 매달 10만 원 가까이 나갔는데, 그걸 끊고 무엇으로 바꿨는지 하나씩 보여주겠다고 예고한다.

### [00:11–00:26] 문제 제기 — 툴을 하나씩 결제하는 구조
AI로 이미지를 만들어 본 사람은 알 텐데, 이미지 툴 하나 결제하고, 영상 만드는 툴 또 하나 결제하고, 화질 올리는 프로그램은 아예 따로 사야 한다고 정리한다. 하나씩 보면 크지 않아 보이지만 카드값 나올 때 모아서 보면 얘기가 달라진다고 지적한다. 본인은 약 여섯 달 이렇게 썼다고 한다.

### [00:26–00:36] 정산 — 한 달에 열몇 장 만들자고 10만 원
한번 정산을 해봤는데, 결과물이 한 달에 몇 장이나 나왔는지 세어보니 열몇 장이더라는 것이다(주장/미검증). 열몇 장 만들자고 10만 원을 낸 셈이라고 자평한다.

### [00:36–00:45] 안 써도 나가는 결제, 사라지는 크레딧
[의견] 화자가 제일 아까웠던 순간은, 일이 바빠서 한 달 내내 한 번도 안 켰는데 결제 문자는 똑같이 오는 때라고 한다. 크레딧도 마찬가지여서, 이번 달에 남았다고 다음 달로 이월되지 않고 그냥 사라진다고 설명한다.

### [00:45–01:00] 가장 답답했던 점 — 모델 선택권이 툴에 있음
그를 제일 답답하게 한 건 따로 있었다며, 좋은 모델이 새로 나와도 그 툴이 붙여줄 때까지 기다려야 한다는 점을 든다. 어떤 건 두 달 뒤에 들어오고 어떤 건 끝까지 안 들어온다고 한다.
> "돈은 내가 되는데 뭘 쓸지는 툴이 정하는 거죠." [00:58]

### [01:00–01:22] 사소하지만 스트레스 — UI 파편화와 파일 옮기기
[의견] 툴마다 화면이 달라 버튼 위치·설정 깊이가 제각각이고, 오랜만에 들어가면 어디가 어딘지 다시 찾아야 하는 것도 은근한 스트레스였다고 한다. 결과물을 만들어 다운로드해 폴더로 옮기고, 그걸 다시 다른 툴에 올리는 "옮기는 작업"만 하루에 몇 번씩 했다고 토로한다.

### [01:22–01:40] 해법 구조 — 클로드 데스크톱 + API 키 하나 (뷔페 vs 단품 비유)
그래서 구조를 아예 바꿨다고 한다. 지금 쓰는 건 딱 두 개, 클로드 데스크톱 앱과 API 키 하나뿐이라고 밝힌다. 비유로는 "뷔페 정기권을 끊고 단품 주문으로 바꾼 것"으로, 뷔페는 안 가도(또는 두 접시만 먹어도) 값이 똑같지만 단품은 먹은 것만 계산하고 나오면 끝이라고 설명한다.

### [01:40–02:04] API 키 = 가게 열쇠 (모아둔 곳에서 하나로 다 씀)
API 키가 뭐냐는 질문에 "가게 열쇠"라고 답한다. 이미지 만드는 회사, 영상 만드는 회사, 화질 올려주는 회사가 각자 가게를 열어놨는데, 그 가게들을 한 군데 모아놓은 곳에서 열쇠 하나만 받아두면 그 안의 가게를 다 쓸 수 있다고 한다. 그 열쇠를 클로드한테 쥐여주는 게 핵심이다.

### [02:04–02:16] 말로 시키면 클로드가 대신 주문·수령, 안 쓰면 0원
말로 시키기만 하면 클로드가 대신 가서 주문하고 물건(결과물)을 받아오며, 쓴 만큼만 계산된다고 한다. 안 쓰면 0원이라며, 지난달에 바빠서 하나도 안 만들었더니 청구서에 0원이 찍힌 걸 보고 웃었다고 덧붙인다(주장/미검증).
> "쓴 만큼만 계산되고요. 안 쓰면 그냥 0원이에요." [02:08]

### [02:16–02:39] '스킬' = 클로드에게 주는 업무 매뉴얼
여기서 '스킬'이라는 말이 나오는데, 어렵게 생각하지 말라고 한다. 클로드한테 주는 업무 매뉴얼로, 새 직원에게 매뉴얼을 주듯 "이럴 땐 이렇게, 저럴 땐 저렇게"를 파일 하나에 적어둔 것이라고 설명한다. 이미지 만들 땐 이 모델 쓰고, 비용은 미리 알려주고, 결과물은 이 폴더에 저장하고 등을 미리 적어두면 매번 설명하지 않아도 되고, 한번 적어두면 계속 쓴다고 한다.

### [02:39–02:56] 데모① 시작 — 대충 던진 한 문장
말로만 하면 감이 안 오니 바로 보여주겠다며, 클로드 데스크톱 앱을 켜고 만들어둔 스킬을 하나 부른 뒤 대충 던진다. "정장 입은 고양이가 지하철에서 신문 보는 사진 하나 만들어 줘"라고만 말했고, 프롬프트 같지도 않다고 한다.

### [02:56–03:14] 클로드가 프롬프트를 다시 씀 (프롬프트 번역)
재밌는 지점은, 클로드가 이 요청을 그대로 넘기지 않고 모델이 알아듣기 좋은 문장으로 다시 쓴다는 것이다. 화면에는 클로드가 다시 쓴 프롬프트가 나오는데, 털 색깔·정장 원단·빛이 들어오는 창문 방향·"렌즈는 85mm 느낌, 배경은 흐리게" 같은 요소를 화자가 한 마디도 안 했는데 알아서 붙였다고 한다.

### [03:14–03:28] 왜 중요한가 — 모델은 구체적 지시가 필요
이미지 모델은 사람 말을 잘 못 알아듣는다고 설명한다. 사람에게는 대충 말해도 통하지만 모델은 구체적으로 써줘야 원하는 게 나오는데, 그 번역을 클로드가 대신해주니 화자는 아이디어만 던지면 된다고 한다.

### [03:28–03:48] 결과·비용·파일 자동 저장 (장당 과금)
결과가 나왔고 이 정도면 만족이라고 한다. 이 모델은 한 장에 15센트(약 200원)이고, 최고 화질로 뽑으면 30센트(약 400원)이라고 밝힌다(주장/미검증, [불명확: 자막 원문 "15cm트"·"사케이 최고 화질"·"30c"]). 결과물은 웹사이트에 로그인해 다운로드할 필요 없이 컴퓨터 폴더에 바로 떨어진다고 강조한다.

### [03:48–04:09] 데모② 핵심 니즈 — 내 얼굴 유지 편집의 어려움
화자에게 진짜 필요한 건 두 번째, 자기 얼굴을 넣고 편집하는 것이라고 한다. 보통 자기 사진을 넣으면 눈이 커지거나 턱이 깎여 다른 사람이 되어 나오는 게 문제인데, 그래서 레퍼런스 사진 다루는 방식을 따로 잡아 "얼굴은 건드리지 말라"고 못을 박아뒀다고 설명한다.

### [04:09–04:32] 얼굴 유지 편집 실행 — 지시와 결과
프로필 사진을 하나 넣고 "이 사람 얼굴·안경·머리는 그대로 두고, 밝은 사무실에서 노트북 앞에 앉아 있는 장면으로 바꿔줘. 창문 빛은 왼쪽에서, 옷은 지금 입은 검은 자켓 그대로"라고 지시했다고 한다. 결과에서 동그란 안경태 모양, 앞머리 갈라진 방향이 그대로 유지됐고 본인이 봐도 자기라고 평가한다.

### [04:32–04:45] 활용 가치 — 프로필 한 장으로 썸네일·홍보물 무한 생성
프로필 사진 딱 한 장만 있으면 썸네일이든 홍보물이든 계속 뽑을 수 있다고 한다. 스튜디오 예약하고 옷 챙겨 가서 촬영하는 것과 비교하면 비교가 안 된다며, 이것도 한 장에 200원이었다고 밝힌다(주장/미검증).

### [04:45–05:11] 응용 확장 — 배경/표정/옷 색 변경, 다중 사진 합성
이걸 알고 나면 쓸 때가 확 늘어난다며, 요즘 썸네일은 자기 사진 한 장 넣고 배경·표정만 바꿔 달라고 하거나 옷 색깔만 바꾸는 식으로 만든다고 한다. 사진 여러 장을 같이 넣는 것도 되어서, 자기 사진과 제품 사진을 함께 넣고 "이 사람이 이 제품 들고 있는 걸로 만들어 줘"라고 시키면 그대로 나온다고 한다. 예전엔 포토샵을 켰지만 지금은 말로 한다고 대비한다.

### [05:11–05:35] 데모③ 영상은 초당 과금 — 지시에 신경 써야
이미지가 나왔으면 이제 움직여야 하는데, 영상은 계산 방식이 달라 이미지가 장당이었다면 영상은 초당이라고 설명한다. 10초짜리와 4초짜리는 가격이 두 배 넘게 차이 나므로 신경 써서 시켜야 한다. 화자는 "방금 그 사진을 4초짜리 영상으로 만들어 줘. 소리는 필요 없고 화면만 움직이면 돼"라고 말했고, 소리를 뺀 것도 이유가 있다고 한다.

### [05:35–05:45] 소리 빼서 단가 절감
소리까지 같이 만들면 초당 15센트인데 빼면 10센트로 떨어지고, 어차피 나레이션은 따로 넣으니 뺐다고 한다(주장/미검증, [불명확: 자막 원문 "15cm트"·"10트"]). 결과적으로 4초에 400원인 셈이다.

### [05:45–06:01] 실행 전 비용 고지 — 구독과의 결정적 차이
[의견] 화자가 제일 마음에 들어하는 부분은, 실행 전에 얼마 나가는지 먼저 알려준다는 점이다. "4초에 400원 진행할까요?"라고 물어봐서 확인하고 넘기면 되고, 결제하고 나서 "아 이거 아닌데" 하는 일이 없다고 한다. 구독은 크레딧이 그냥 쓱 빠져나가고 끝이라는 점과 대비한다.

### [06:01–06:08] 영상 결과
영상이 나왔고, 사진 한 장이 고개를 살짝 돌리고 웃는 식으로 움직인다고 한다. 4초에 400원이 들었다고 다시 밝힌다.

### [06:08–06:27] 팁 — 영상은 4초씩 여러 개로
[의견] 영상은 길게 뽑으려 하지 말고 4초씩 여러 개 뽑는 게 훨씬 낫다고 조언한다. 10초를 한 번에 뽑으면 중간이 이상해도 통째로 버려야 하지만, 4초짜리는 마음에 안 드는 것만 다시 뽑으면 되고 편집할 때도 짧은 게 편하다고 한다. 길게 뽑아도 어차피 잘라 쓰게 되므로 웬만하면 4초로 통일한다고 한다.

### [06:27–06:56] 모델 선택 기준 — 이미지는 최고, 영상은 계산
많이 받는 질문이 "모델이 그렇게 많은데 뭘 골라야 되냐"인데, 기준은 단순하다고 한다. 이미지는 어차피 200원이니 그냥 제일 좋은 걸 쓴다(몇백 원 아끼자고 결과물이 아쉬운 게 더 손해라는 것). 영상은 초당이라 계산을 해서, 이름에 '패스트'가 붙은 빠른 버전을 기본으로 쓰는데 화질 차이는 크지 않으면서 값은 절반 아래로 떨어진다고 한다. 정말 중요한 컷 하나만 비싼 걸로 다시 뽑는다.

### [06:56–07:13] 모델 전환은 말 한마디 — 모르면 클로드에게 견적
좋은 점은 모델 이름만 바꿔 말하면 되고 설정 화면에 들어가 바꿀 필요가 없다는 것이다. "오늘은 이걸로 해 줘, 이건 저걸로 해 줘" 식이다. 잘 모르겠으면 클로드한테 "이 작업엔 뭐가 제일 싸게 먹히냐"고 물으면 후보 몇 개와 값을 같이 알려준다고 한다.

### [07:13–07:36] 데모④ 화질 개선(업스케일) — 프로그램 구매와 대비
지금 이 영상 화질이 720p라 아쉬워서 "이거 4K로 올려 줘"라고 한마디 했다고 한다. 짚고 갈 점으로, 화질 올려주는 제대로 된 프로그램은 30만 원 넘게 주고 사야 하고 한 번을 쓰든 100번을 쓰든 값이 똑같은데, 본인은 그걸 사놓고 1년에 몇 번 안 썼다고 한다(주장/미검증). 방금 이 영상 업스케일에 든 비용은 400원이라고 밝힌다.

### [07:36–07:56] 업스케일 처리 시간과 결과
업스케일은 시간이 좀 걸려서 4초짜리에 2분 정도 돌았고, 그동안 다른 작업을 하다가 끝나면 알려준다고 한다. 결과는 왼쪽 원본 대비 오른쪽(업스케일본)에서 머리카락이 한 올 한 올 살아나고 얼굴 윤곽이 훨씬 선명해졌으며 3,840×2,160의 진짜 4K로 나왔다고 한다.

### [07:56–08:08] 업스케일은 남의 저화질 영상에도 적용
이건 자기가 만든 영상에만 되는 게 아니라, 어디서 받은 화질 낮은 영상이나 옛날에 찍어둬 흐릿한 것들도 똑같이 올려준다고 한다. 그냥 파일 던지고 올려 달라고 하면 된다.

### [08:08–08:23] 총정리 — 네 가지, 합계 1,800원
여기까지 이미지 만들기, 내 사진 편집, 영상 만들기, 화질 올리기 네 가지를 다 해봤다고 정리한다. 원래 툴 세 개가 필요했던 작업이며, 오늘 쓴 돈을 전부 합치면 1,800원으로 구독료 10만 원과 비교하면 계산기 안 두드려도 답이 나온다고 한다(주장/미검증).

### [08:23–08:33] 새 모델 즉시 사용 — 돈보다 큰 가치
[의견] 하나 더 있다며, 새 모델이 나오면 그날 바로 쓴다는 점을 든다. 툴 회사가 붙여주기를 기다릴 필요 없이 쓰고 싶은 모델 이름만 말하면 되고, 화자는 이게 돈보다 더 크다고 생각한다고 말한다.

### [08:33–08:48] 옮기는 작업의 소멸 — 한 창에서 이어지는 파이프라인
[의견] 앞서 말한 다운로드→폴더→재업로드의 "옮기는 작업"이 통째로 사라졌다고 한다. 이미지를 만들고 그걸 바로 영상으로 만들고, 그 영상 화질을 바로 올리는 흐름이 한 창 안에서 쭉 이어져 사이에 손대는 게 없다고 한다.
> "솔직히 저는 돈보다 이게 더 좋더라고요." [08:47]

### [08:48–09:04] 시작 3단계 ① — Replicate 가입 & API 토큰 발급
어떻게 시작하냐면 세 단계면 끝이라고 한다. 첫째, "리플리케이트(Replicate)"라는 사이트에 가입하는데 여기가 앞서 말한 가게들이 모여 있는 곳이다. 가입 후 오른쪽 위 프로필을 눌러 "API 토큰 만들기"를 누르면 긴 글자가 하나 나오는데 그게 앞서 말한 열쇠다.

### [09:04–09:16] 시작 3단계 ② — 키 보관 (채팅창에 붙여넣지 말 것)
둘째, 이 열쇠를 어디다 둘지가 중요하다. 채팅창에 그냥 붙여넣지 말고, 클로드한테 "이거 어디다 넣어야 되냐"고 물어보면 파일 하나 만들어서 거기 넣으라고 알려준다고 안내한다.

### [09:16–09:26] 시작 3단계 ③ — 카드 등록 & 소액 충전
셋째, 카드 등록하고 조금 충전해 두라고 한다. 무료 크레딧은 없으며, 화자는 2만 원 넣어두고 쓰는데 오늘 보인 정도로 쓰면 한참 간다고 한다(주장/미검증). 여기까지 하고 스킬 파일 하나만 넣어주면 세팅은 끝이라고 정리한다.

### [09:26–09:37] 보안 습관 — 남의 파일은 클로드에게 먼저 검사
[의견] 습관처럼 하길 추천하는 게 있는데, 남이 만든 파일을 받아 넣기 전에 클로드한테 "이거 보안상 문제 없는지 먼저 봐 달라"고 하라는 것이다. 본인은 뭘 받든 항상 이것부터 시킨다고 한다.

### [09:37–09:59] 초보가 잘 막히는 두 지점
처음 하는 사람이 잘 막히는 데가 두 군데라고 한다. 하나는 열쇠를 넣었는데 안 되는 경우인데, 거의 다 저장하고 앱을 껐다 켜지 않은 것이라 한번 껐다 켜면 된다. 또 하나는 사진을 넣었는데 클로드가 못 찾는 경우로, 창에 끌어다 놓기만 하면 파일 위치를 모를 때가 있어 파일을 우클릭해 경로를 복사해 위치도 같이 알려주면 된다고 한다.

### [09:59–10:23] 마무리 — 후속 예고 & 커뮤니티 안내
오늘 쓴 스킬과 세팅 방법은 정리해서 아래(설명란)에 올려두겠다고 한다. 이런 식으로 구독료를 하나씩 걷어내고 있다며, 다음에는 나레이션 만드는 것도 같은 방식으로 바꾼 걸 보여주겠다고 예고한다. 시청자에게 지금 어떤 툴을 구독 중인지 댓글로 알려주면 그걸 대체하는 방법도 찾아보겠다고 하고, 더 깊은 이야기는 "스킬샵"과 "오픈톡방"에서 나눈다고 안내하며 끝맺는다.
