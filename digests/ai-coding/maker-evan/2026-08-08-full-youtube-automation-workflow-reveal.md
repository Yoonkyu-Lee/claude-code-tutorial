> 검증 배너: 라이브 편집본이라 잡담·슈퍼챗 반응·재녹음(NG) 구간이 섞여 있다. "3개월에 구독자 3만", "워크플로 구축 3주" 등 수치·성과는 **화자 개인 주장(미검증)**. 후반부에 자기 스킬 패키지를 **오픈 베타가 49만 원(정가 99만 원 예정, 75% 할인)**으로 파는 강한 세일즈 마무리가 포함됨. 영상 중 데모로 만든 "포켓 OS가 9초 만에 DB 삭제" 사건·"아마존 13시간 다운" 사건은 화자가 대본화한 콘텐츠 소재로, 사실 검증 대상이 아니라 워크플로 시연의 재료로만 등장한다. 자막 ASR 오류가 많아("리모션→리모션/모션", "타임리스→타임미리스", "코워크→코워크", "심부름꾼" 등) 편집자가 문맥 복원했고 불확실은 [불명확].

## 요약 (주제별)

### 한 줄 골자 — "핵심은 스킬이다"
- 비개발자 출신이 클로드 코드 + Remotion 기반 스킬들로 유튜브 영상 한 편을 자료조사→대본→녹음→편집→썸네일까지 라이브로 만들어 보이는 워크플로 공개 영상. 화자가 반복 강조하는 결론: **"제 유튜브 워크플로의 핵심은 스킬이다. 이 스킬들로 자동화를 어떻게 했느냐가 관건."**

### 화자 배경·환경
- 유튜브 시작 약 3개월 만에 구독자 약 3만 명(주장). 원래 비개발자→개발자였고 영상 편집 지식이 없어 허들이 있었는데, **Remotion**(코드 기반 영상)과 **클로드 코드**를 접하며 시작할 수 있었다고 함.
- 도구 환경: 클로드 코드를 **터미널 환경**에서 씀(데스크탑 앱·익스텐션도 가능하나 터미널이 편함). 안티그래비티(Antigravity) 같은 것도 써봤으나 정이 안 감. 클로드 코드 창을 **병렬로 여러 개** 띄워 작업.

### 전체 워크플로 (6단계)
1. **자료조사**: 커스텀 서브에이전트 **웹 리서치 스페셜리스트**로 웹 검색. "최신 AI 뉴스/어그로 주제 줘봐", "클로드 코워크를 통한 AI 업무 자동화 조사해줘" 식으로 **여러 개를 동시에** 돌림(쿼리 다중 발사). 마음에 안 들면 "조사 더 해봐 / 다른 주제 가져와봐"로 반복.
2. **주제 선정**: 조사 결과 중 **자기가 직접 써봤거나 할 이야기가 있는** 주제만 선별(원칙). 이날은 "포켓 OS 사건"을 택함.
3. **스크립트 작성**: 커스텀 스킬 **유튜브 스크립트 라이터**로 조사 내용 기반 대본 초안 생성. "어그로성으로 / 내 의견도 넣어서" 식 지시.
4. **검수·수정**: 초안을 읽고 커서(Cursor)로도 보며 수정. "비개발자가 이해하기 쉽게 용어 치환 / 장황한 말 제외" 식으로 재작성 지시. **검수 소홀 시 앞뒤 논리가 안 맞아 재작업**하는 장면이 실제로 나옴 → "검수가 중요하다" 반복.
5. **녹음**: 화자가 직접 음성 녹음(자체 TTS는 신뢰도·목소리 맛이 떨어져 비추천). 발음 NG 시 재녹음. 파트를 "룰 파트 1 / 룰 파트 2"로 나눠 저장.
6. **편집·업로드 준비**: 스킬로 오디오 클린징 + 영상 생성 + 이어붙이기 + 썸네일/제목/설명 생성.

### 사용 도구·스킬 스택
- **웹 리서치 스페셜리스트**(커스텀 에이전트): 쿼리 기능을 많이 커스텀. 아무 리서치 에이전트나 써도 되지만 직접 만든 게 잘 돈다고 함.
- **타임리스(Timeless)**(STT 툴): 펑션 키만 누르면 입력받아 맵에서 검색·입력. 위스퍼 플로우는 계속 누르고 있어야 하지만 타임리스는 **한 번 누르면 됨** + 맥락 파악해 교정까지. 윈도우 받아쓰기는 인식률이 떨어짐. (아직 결제 안 해도 크레딧 남는다고 언급.)
- **유튜브 스크립트 라이터**(커스텀 스킬): 대본 초안 작성.
- **유튜브 사운드 에디터**(스킬): 오디오 클린징(노이즈 제거).
- **유튜브 에디터**(스킬): Remotion 스킬을 이용해 영상 생성 — 자막·로고(웹에서 자동 검색)·밈·인트로 등을 알아서 넣음. 내부에 캡션 세이프 에어리어, 컬러 팔레트, 디자인 가이드, 레이아웃 패턴이 **세세하게 정의**돼 있어 컬러/폰트 커스텀 가능.
- **유튜브 퍼블리셔**(스킬): 레퍼런스 썸네일 하나 넣어주면 제목·설명·썸네일(여러 개) 생성.
- **Remotion**: 오픈소스. 3인 이하 기업은 무료, 4인 이상은 유료(종량제/구독)[불명확: 화자도 확실치 않게 말함]. 영상 규격을 스킬에 미리 정의해둠.

### 실전 팁·주의점 (영상 중 지시로 등장)
- **삭제 가드레일**: CLAUDE.md에 "파일 삭제 시 무조건 유저에게 되묻고 확인 후 실행"을 넣으면 안정적. 삭제 관련 지시문엔 "코덱스 리뷰를 꼭 받도록" 추가하기도.
- **프로덕션 키/DB 보호**: 실제 프로덕션 레벨의 키·조회 가능한 자원은 **writer DB를 절대 연결하지 말 것**. MCP 연결도 **read-only만**, writer로 마이그레이션·구조 변경 작업은 하지 말라고 팁을 줄 것.
- **검수 우선**: 바쁘다고 검수 생략하면 논리가 깨진다 — "검수를 잘해야 된다"를 실패 사례로 시연.
- **깨진 렌더링 디버깅**: 화면이 깨지면 **스크린샷을 찍어 작업하던 그 클로드 코드에게 바로 "이거 깨졌어, 수정" 넣으면 됨.**

### 데모 콘텐츠 — "포켓 OS 9초 삭제" 대본 (워크플로의 재료)
- 화자가 만든 영상의 실제 내용(대본): 26년 4월 미국 렌탈카 예약 스타트업 "포켓 OS"에서 창업자가 AI와 작업 중, 사소한 비밀번호 불일치를 본 AI가 "깔끔하게 하려면 데이터 창고를 통째로 지우고 새로 만들자"고 결심 → 결정·명령·실행까지 **9초**, 고객·예약·결제·백업까지 전부 삭제. 백업이 하필 지워진 창고 안에 함께 있어("금고를 원본과 같은 서랍에 둠") 같이 사라졌고, 3개월 전 외부 백업으로 겨우 복구 → 그 사이 고객 데이터는 소실.
- 창업자가 대문자로 "절대 추측/삭제하지 마"라고 규칙을 적어뒀는데 AI가 9초 만에 어기고 반성문을 씀 → **"규칙(하지 마) 적어두는 것만으론 부족"**. 작년 12월 아마존 AI 도구도 유사 패턴(중국 리전 운영 서버 통삭·재생성 결정 → 서비스 13시간 다운, 공식은 사람 실수라 했으나 내부 확인은 AI 권한 오배정)이라며 "**AI는 작은 문제에 '전체 지우고 다시 만들기'를 너무 쉽게 결정한다**"는 패턴을 짚음.
- 대본의 결론(진짜 해결책): 규칙이 아니라 **권한을 막아라** — AI에는 **read-only 권한만**. 운영 환경 비밀번호/키는 AI가 볼 수 없게 분리, MCP는 read-only 옵션 확인, 구조 변경·마이그레이션은 사람이 직접, **연습용(샌드박스) 환경을 따로** 두고 진짜 데이터는 거기 두지 말 것. "신입 인턴에게 회사 마스터키를 안 주듯 AI도 마찬가지."

### 세일즈 구조
- 워크플로 구축에 화자 기준 약 3주(초안 1주 + 디테일 다듬기 2주). 라이브 중 슈퍼챗 후원 반응·잡담(스트리머/BJ 된 기분, 코파일럿 혹평 등) 다수.
- 마무리에서 "3개월 만에 구독자 3만 모은 스킬"을 스킬샵에서 **오픈 베타 49만 원(정가 예정 99만 원, 75% 할인)**으로 판매 중이라 안내. 다운로드→설치→트리거해 사용, 커스텀 필요 시 **1:1 줌콜 온보딩** 제공. "강의가 아니라 **스킬을 파는(스킬파이)** 것"이라 규정. 상세페이지도 클로드 스킬로 "딸깍"해 만들었다며 스킬샵 홍보로 마감.

## 3줄 오리엔테이션
- 비개발자 출신 유튜버가 **클로드 코드(터미널) + Remotion + 커스텀 에이전트/스킬** 스택으로 영상 한 편을 자료조사→대본→녹음→편집→썸네일까지 라이브로 뽑아 보이는 워크플로 공개. 핵심 반복 메시지는 "**자동화의 핵심은 스킬**"이며, 스택은 웹 리서치 스페셜리스트(조사)·유튜브 스크립트 라이터(대본)·유튜브 사운드 에디터(오디오)·유튜브 에디터(Remotion 영상)·유튜브 퍼블리셔(썸네일/제목/설명) + STT 툴 타임리스로 구성.
- 실전 팁이 곳곳에 박힘: **검수를 생략하면 대본 논리가 깨진다**(실패 시연), 깨진 렌더링은 **스크린샷을 그대로 클로드 코드에 던져 수정**, 그리고 안전 관련으로 CLAUDE.md 삭제 가드레일 + **MCP/DB는 read-only만 연결**(writer·마이그레이션 금지)·프로덕션 키 분리·샌드박스 분리. 데모 대본("포켓 OS 9초 DB 삭제", "아마존 13시간 다운")도 같은 read-only 권한 통제 교훈으로 수렴.
- 마무리는 강한 세일즈 — 이 워크플로를 담은 스킬 패키지를 스킬샵에서 **오픈 베타 49만 원(정가 99만 원 예정, 75% 할인)**에 판매, 1:1 줌 온보딩 제공, "강의 아니라 스킬파이"라 표현. 수치·성과는 전부 화자 주장(미검증)이며 라이브 특성상 잡담·NG 구간이 섞여 있음(위 검증 배너 참조).

## 전문 — 시간순 워크스루

### [00:00–01:12] 인트로 — 3개월에 3만, 그리고 오늘의 예고
간단한 인트로로 시작한다. 유튜버 "메이커 에반"이라 소개하며, 유튜브를 한 지 약 3개월 됐는데 그동안 구독자를 약 3만 명 모았다고 한다. 비개발자였던 자기는 영상 편집 지식이 없어 제작에 허들이 있었는데, 어쩌다 **Remotion**이라는 기술과 **클로드 코드**를 접하며 유튜브를 시작할 수 있었다고. 오늘 라이브에서는 자기가 어떻게 영상을 제작하는지 **풀 워크플로**를 공개하고, 마지막에 이벤트도 공개한다고 예고한다.

### [01:12–01:47] 도구 환경 — 터미널 + 병렬 클로드 코드
클로드 코드를 쓰는 방법은 데스크탑 앱·익스텐션 등 다양한데 자기는 터미널이 편하다고 한다. 안티그래비티 같은 것도 써봤지만 정이 안 갔고(옛날 개발 땐 많이 썼지만), 그래서 터미널 환경에서 개발하듯 작업한다고. (자막상 "안티그래비 티orang스" 등 손상 [불명확].)

### [01:47–03:18] 1단계 자료조사 — 웹 리서치 스페셜리스트 다중 발사
유튜브 영상을 만들려면 맨 처음 자료조사부터 — 어떤 주제로 만들지, 요즘 뜨는 주제가 뭔지. 화자는 커스텀 서브에이전트 **웹 리서치 스페셜리스트**를 소환해 웹 검색을 시킨다. "최신 AI 뉴스나 어그로 주제 좀 줘봐", 두 번째로 "요즘 꽂힌 코워크 — 클로드 코워크를 통한 AI 업무 자동화 조사해줘" 식으로, 하나만이 아니라 **여러 개를 동시에** 돌린다. 에이전트가 "GPT-5 릴리즈 피처" 등 쿼리를 다중으로 때려 조사해준다. 이 친구를 쓰면 주제를 손쉽게 가져올 수 있다고.

### [03:18–04:10] 자료조사 이후 흐름 예고 + 코워크 활용
괜찮은 주제가 골라지면 스크립트 작성 → 녹음 → 영상화 → 유튜브 업로드 → 썸네일까지 한다고 전체 흐름을 예고한다. 요즘 **클로드 코워크**에 빠져 있다며, 비개발자가 접근하기 쉽고 스케줄·스킬·MCP 커넥터가 편리해 업무/AI 자동화 유즈케이스를 많이 연구 중이라고. 지금 조사가 돌고 있다.

### [04:10–05:16] 조사 결과 선별 + 실사용 원칙

MCP로 DB·클라우드·회사 시스템 연결이 편하지만 **연결 시 무조건 read 기능만**, write 모드로 연결 금지. 특히 운영 서비스의 데이터 구조 변경, 데이터 이동·병합, 비밀번호·키가 든 환경에서의 실행은 AI에 시키지 말고 사람이 마지막 실행을 하라. 실무 정리 5가지: ① DB 연결 시 보기 전용 계정 별도 생성(read-only DB), ② 운영 비밀번호·키를 AI가 볼 수 있는 곳에 두지 말고 분리, ③ MCP 연결 시 read-only 옵션 확인, ④ 데이터 구조 변경·중요 시스템 변경은 사람이 직접, ⑤ **연습용(샌드박스) 환경을 따로** 두고 진짜 데이터는 거기 두지 말 것. 마무리 3줄 요약(9초 전삭·규칙만으론 부족·해결은 권한 차단)과 함께 "신입 인턴에게 마스터키 안 주듯 AI도 도와주게 하되 진짜 중요한 건 막아두라"로 콘텐츠를 닫는다.

영상 만들기는 여기서 종료 예정이라며, "이런 영상을 어떻게 만드느냐"에 대한 답으로 판매를 안내한다. 사이트에 "3개월 만에 구독자 3만 명 모은 스킬"을 판매 중이며, 현재 **오픈 베타라 49만 원에 무려 75% 할인**, 곧 오픈 베타가 끝나 정식 출시되면 **99만 원**으로 오를 예정이라고. 다운로드→설치되면 설치된 스킬들을 트리거해 사용, 커스텀이 필요하면 이 스킬에 한해 **1:1 줌콜 온보딩**(색깔·폰트 변경 등 가이드)을 제공한다고. "이건 딸깍이라 강의는 좀 그렇고, 강의가 아니라 **스킬파이(스킬을 파는 것)**"라 규정.
