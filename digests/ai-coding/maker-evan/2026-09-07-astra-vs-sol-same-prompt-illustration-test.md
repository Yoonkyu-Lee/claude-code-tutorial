# 아스트라 vs 솔, 같은 그림을 시켰더니 차이가 보입니다

> 메이커 에반 · 2026-09-07 · 1,122회 · 10:00 · [영상 링크](https://youtu.be/EStckaBbIlE)
> 정리 방식: 시간순 심층 워크스루 (paraphrase) + 주제별 상세 요약
> 검증 배너: 두 모델의 우열 판정은 **화자 개인의 육안 비교와 취향**이며 정량 벤치마크가 아니다. 화자 본인도 "여덟 사례가 모든 작업의 성능을 증명하지 않는다"고 명시한다. 모델명(아스트라·솔)의 정체·버전은 영상에서 별도 설명되지 않는다.

## 요약 (주제별)

### 실험 설계 — 무엇을 어떻게 비교했나
- 아스트라와 솔에게 **동일한 문장 프롬프트 8개**를 주고 결과물을 육안 비교. 여기에 **제한 수정 요청 2건**을 추가로 붙였다.
- 결정적 전제: 두 모델이 **코드로 직접** 그림과 움직임을 생성했다. 외부 이미지 생성기 결과물을 가져다 붙인 것이 아니다 [00:16].
- 애니메이션도 "그림만 받아서 화자가 흔든 것"이 아니라, 각 모델이 부품을 그리고 **무엇을 언제 움직일지 모션 정의까지 작성**했다 [05:56].
- 화면 고지: 애니메이션 장면은 각 모델이 만든 **10초 동작의 반복 재생**이며, 모델의 실시간 생성 속도 녹화가 아니다 [07:15].
- 화자가 명시한 판정 원칙 — "**내가 더 마음에 든 장면**"과 "**조건을 더 잘 지킨 장면**"을 분리해서 봤다 [09:30].

### 8개 주문 목록과 각 과제의 시험 포인트
1. **토요일의 꽃시장** — 노란 비옷 인물이 꽃다발 건네기, 꽃집 직원·고양이·꽃통 3개·줄 조명, 꽃 정확히 5송이 (수량 준수 + 손 접점)
2. **망원경 보는 작은 여우** — 흰 언덕, 별 7개, 고리 있는 행성 (현실에 없는 풍경 → 구도를 모델이 스스로 결정)
3. **차 따르는 손** — 한 손은 주전자 손잡이, 다른 손은 찻잔, 주둥이→찻잔 안쪽까지 물줄기 연속, 레몬 3개 (의도적 고난도)
4. **두 층짜리 입체 서점** — **중간에서 꺾이는 계단**을 명시 지정, 책장·책상·두 사람·화분 4개 (3D 공간 구조)
5. **한글 책 축제 포스터** — 제목 "봄날의 책방", 부제 "책과 커피 그리고 우리", 날짜 포함 (한글 텍스트 렌더링)
6. **아이콘 6종 세트** — 카메라·자전거·현미경·커피포트·헤드폰·로봇, 선 굵기/모서리/시각적 크기 통일 (일관성)
7. **움직이는 에스프레소 머신** — 레버 당김 → 기어 회전 → 압력계 → 커피 추출 순서 (애니메이션 인과)
8. **하늘 나는 작은 배** — 돛·탐험가·매달린 등불·새·여러 층 구름, 배 진입 → 돛 펼침 → 새 통과 (다중 부품 동시 모션)

### 두 모델의 스타일 경향 (반복 관찰된 대비)
- **아스트라**: 세부 분할과 여백 중심. 옷깃·주머니·꽃집 안쪽까지 나누고, 손톱·손목선·손잡이 구멍, 자전거 바큇살, 고글·조타 장치·나무 무늬, 작은 톱니와 배관까지 그린다. 요소 간 간격을 남긴다.
- **솔**: 굵은 외곽선 + 크게 잡은 주피사체. 인물·주전자·여우·배를 화면 가득 키워 작은 화면에서도 강하게 보인다. 대신 세부는 단순화되고(잎보다 줄기 위주, 큰 덩어리), 요소가 화면 가장자리에 닿거나 서로 붙는다.
- 화자 정리: 같은 수량 조건을 지켜도 **그림의 분위기는 완전히 달라진다** [02:23].

### 과제별 판정 결과
- **꽃시장**: 무승부 성격. 두 모델 모두 꽃 5송이·꽃통 3개 준수. 다만 **양쪽 다 건네는 손과 꽃다발의 접점이 떨어져 있다** — "수량만으로 승부가 갈리지 않았다" [01:33].
- **여우**: 별 7개·고리 행성 양쪽 준수. 눈이 접안부를 향하는지도 둘 다 근접 배치. 단 아스트라는 코끝이, 솔은 눈 주변선이 겹쳐 연결 확인이 필요.
- **차 따르는 손**: 물줄기 연속성은 **양쪽 모두 성공**. 손-소품 관계 가독성은 아스트라 우세 [의견, 02:56], 솔은 굵은 손가락과 손잡이 선이 겹쳐 관통 여부 판별이 어렵다. 단서: "손가락을 사실적인 손처럼 믿을 수준은 아니다". 레몬은 컵·손 뒤에 많이 가려짐.
- **입체 서점**: **아스트라가 요청 구조를 더 구체적으로 구현**(아래/위 계단 방향 구분, 발판 꺾임 분명). 솔은 정면 가로 막대 겹침에 가까워 입체 방향이 덜 읽힌다. 단 아스트라도 계단-바닥, 인물-카운터 접점이 완벽하진 않다.
- **한글 포스터**: 제목·부제·날짜 모두 **두 모델 다 요청 문구대로**, 그리고 **이미지 흉내가 아닌 실제 텍스트** [04:43]. 차분한 행사 포스터라면 아스트라 선택 [의견], 강한 시인성을 원하면 솔 방향도 비교할 만하다.
- **아이콘 세트**: 간격·화면 여유는 아스트라가 더 안정적(아스트라도 카메라-현미경 시각적 무게는 완전히 같지 않음). 솔은 카메라-자전거가 붙고 아래 아이콘이 화면 끝에 닿음 — 축소 전에 잘림과 간격부터 고쳐야 한다.
- **비행선**: 솔이 **요청한 작은 섬을 배 아래가 아니라 왼쪽 위에 배치**(조건 위반). 아스트라는 섬을 아래에 두어 공간 이야기를 만듦.

### 정지 화면 완성도 ≠ 애니메이션 완성도 (영상의 핵심 발견)
- 에스프레소 머신 첫 동작에서 **아스트라는 레버가 몸체에서 분리되고 압력 바늘이 밖으로 이탈**, **솔은 압력계 바늘이 다이얼 중심축으로 자연스럽게 돌지 않았다**.
- 기어는 **두 모델 모두 반대 방향 회전**을 구현했지만, 방향이 반대라고 톱니 접촉까지 정확한 것은 아니다. 커피 추출·증기 동작은 양쪽 다 들어감.
- 비행선에서도 아스트라 첫 동작에서 **등불과 줄이 분리**되는 문제 발생. 구름은 앞뒤 레이어가 다른 속도로 움직여 깊이감을 만들었다.
- 화자의 결론 문장: "정교한 그림을 그렸다는 사실만으로 애니메이션까지 합격시킬 수 없었습니다" [06:45] / "정지 화면의 완성도와 애니메이션의 완성도가 나뉘는 지점" [07:07].
- 판정 기준의 엄격함: "배를 확대하는 효과만으로 움직였다고 말하지 않겠다"(부품이 개별 운동해야 인정) [07:47].

### 보정(리페어) 요청의 효과
- 두 모델에 **동일하게** "부품의 연결과 회전축을 고쳐 달라"고 재요청.
- 머신 보정본: 레버와 기어가 제자리를 지키게 됨. 스타일은 각자 유지(아스트라=섬세한 기계 묘사, 솔=큼직한 실루엣). 다만 톱니 맞물림과 커피 표현은 **여전히 단순한 일러스트 동작 수준**.
- 비행선 보정본: 아스트라는 등불 줄까지 함께 흔들리도록 연결, 솔은 새 동선을 위로 올려 탐험가 얼굴 가림을 줄임. 두 버전 모두 **돛을 키워 펼치는 방식이라 천이 실제로 접히는 움직임은 아니다**.

### 제한 수정(에디팅) 테스트 — 실무 연결의 진짜 관문
- 실험 의도: "보기 좋은 그림과 **수정하기 좋은 그림**이 같은가" [00:38].
- 요청 A(아이콘): 산호색만 제거, 모양과 위치는 유지 → **두 모델 모두 색상만 변경**, 좌표·크기·도형 모양 그대로.
- 요청 B(포스터): 날짜 변경 + 찻잔 색만 산호색으로 → **양쪽 모두 지정 항목만 변경**, 다른 문구나 그림을 새로 만들지 않음.
- 검증 방식: **화면 비교와 파일 비교를 병행**.
- 해석: "첫 그림의 완성도 차이가 수정도의 차이로 그대로 이어지지 않았다" [09:01]. 잘 그려도 수정 시 다른 부분이 흔들리면 실무에 못 쓰고, 원하는 부분만 바뀌면 작업 연결이 훨씬 쉬워진다.
- **범위 한정**: 오늘 검증한 건 "색상과 문구를 바꾸는 좁은 조건"뿐이다 [09:12].

### 총평과 화자가 스스로 건 한계
- 취향 판정: 아스트라의 여백·작은 디테일·공간 구성이 더 마음에 들었다 [의견, 09:18]. 동시에 솔의 굵은 실루엣과 직관적 큰 형태도 장점으로 인정.
- 세 가지가 **서로 다른 문제**였다는 정리 — ① 일러스트와 손의 연결(물리적 접점), ② 공간의 계단(구조 표현), ③ 움직임의 순서(모션 인과).
- 감상: 말로 주문한 장면이 그림과 움직임으로 연결되는 경험 — "진짜 AGI 같다는 감탄은 이런 순간에 나오는 것 같아요" [09:45] [의견].
- 자기 한정: "이 여덟 사례가 모든 작업의 성능을 증명하는 것은 아니다" [09:49]. 원본·수정본·실제 요청 문장·모션 파일까지 공개하겠다고 예고하고, 시청자에게 직접 비교를 권한다.

### 시청자용 관찰 체크리스트 (화자가 반복 제시한 판단 기준)
- 나란히 놓았을 때 **시선이 먼저 가는 자리**가 어디인가(인물 vs 배경).
- 화면을 **작게 줄여도** 이야기의 중심/아이콘의 정체가 남는가 — "실제 사용 기준" [05:36].
- 접점 검증: 손이 실제로 물건에 닿는가, 가구가 바닥에 닿는가, 계단이 발판을 거쳐 위층에 닿는가.
- 지정한 **수량과 위치 조건**(별 7개, 꽃 5송이, 섬의 위치)을 지켰는가.
- 애니메이션에서 **회전축·부품 연결·겹침 순서·레이어별 속도**가 물리적으로 말이 되는가.

## 3줄 오리엔테이션
- 두 AI 모델(아스트라·솔)에게 **똑같은 문장 8개**를 주고, 이미지 생성기 없이 **코드로 직접** 일러스트·애니메이션을 만들게 한 육안 비교 실험이다.
- 결과 경향: 아스트라는 여백·세부·공간 구조에서, 솔은 굵은 실루엣과 작은 화면 가독성에서 강했다. 다만 **정지 화면의 완성도와 애니메이션 완성도는 별개**였다.
- 마지막에 "날짜/색만 바꿔라"는 제한 수정 요청을 넣었는데, **두 모델 모두 정확히 그 부분만** 바꿨다 — 첫 결과의 우열이 수정 정확도로 이어지지는 않았다.

### [00:00–00:20] 이번 실험의 설정 — 코드로 직접 그린 그림과 움직임
지난 영상이 그림 몇 장을 너무 오래 보여줬다는 반성으로, 이번에는 아스트라와 솔을 직접 붙였다. 같은 문장을 줬을 때 그림이 얼마나 다르게 나오는지가 관심사이고, 정적 일러스트만 있는 것도 아니다 — 톱니바퀴가 맞물리고 커피가 내려오고 하늘을 나는 배가 움직인다. 중요한 전제 하나를 못 박는다.

> "지금 화면에 보이는 그림과 움직임을 두 모델이 직접 코드로 만들었어요. 다른 이미지 생성기가 그린 그림을 가져다 붙인 것은 아닙니다." [00:16]

### [00:20–00:41] 여덟 개 주문과 마지막 수정 실험
주문 목록은 꽃시장, 여우 천문대, 차를 따르는 손, 입체 서점, 한글 포스터, 아이콘 세트, 움직이는 기계, 비행선까지 여덟 가지다. 각각에 어떤 답이 나왔는지 차례로 보고, 마지막에는 **날짜와 색만 바꿔 달라는 수정 요청**도 넣었다. 이 수정 실험을 넣은 이유는 "보기 좋은 그림과 수정하기 좋은 그림이 같은지"가 궁금했기 때문이다. [의견/문제의식]

### [00:41–00:55] 1번 주문 — 토요일의 꽃시장, 조건 명세
첫 번째는 토요일의 꽃시장이다. 노란 비옷을 입은 사람이 꽃다발을 건네는 장면을 부탁했고, 조건에 꽃집 직원·고양이·세 개의 꽃통·줄 조명까지 넣었다. 같은 요청인데도 결과의 첫인상이 꽤 다르다.

### [00:55–01:14] 아스트라 vs 솔 — 세부 분할이냐 굵은 외곽선이냐
아스트라는 옷깃과 주머니, 꽃집 안쪽까지 세부를 나눴고 사람과 가게 사이에 여유(여백)가 있다. 솔은 굵은 외곽선과 크게 잡은 인물로 밀어붙여서, 작은 화면에서도 노란 비옷이 강하게 보인다. 두 그림을 나란히 놓으면 시선이 먼저 가는 자리(사람이냐 가게냐)가 비교된다고 시청자에게 권한다.

### [01:14–01:35] 접점과 수량 검증 — 손은 안 닿았지만 개수는 맞췄다
꽃다발과 손이 만나는 부분을 확대해 보면, 아스트라는 손 모양이 더 구체적이지만 꽃집 직원 손이 꽃다발에 닿지 않는다. 솔도 건네받는 접점이 떨어져 있다. 꽃을 정확히 다섯 송이로 지정한 이유가 여기 있는데, 두 모델 모두 다섯 송이 꽃과 세 개의 꽃통을 넣었다 — "여기서는 수량만으로 승부가 갈리지 않았다".

### [01:34–01:52] 2번 주문 — 망원경 보는 작은 여우 (아스트라)
두 번째는 망원경을 보는 작은 여우다. 초승달처럼 흰 언덕과 고리 있는 행성도 함께 요청했다. 현실에 없는 풍경이라 구도부터 모델이 스스로 정해야 한다는 점이 포인트다. 아스트라는 작은 여우와 길게 흰 언덕을 배치했고, 망원경과 식물의 안쪽 선도 더 잘게 나눴다.

### [01:52–02:01] 솔의 여우 — 캐릭터는 크게, 식물은 단순화
솔은 여우를 훨씬 크게 그렸다. 캐릭터는 선명하지만 식물은 잎보다 줄기 위주로 단순해졌다. 같은 크기로 펼쳐 놓고 비교하면 이 대비가 분명하게 드러난다.

### [02:01–02:13] "멋있다" 다음의 검증 — 눈이 접안부를 향하나
감상에서 한 걸음 더 들어가, 여우의 눈이 정말 망원경 접안부를 향하는지 확인한다. 두 결과 모두 얼굴을 접안부 가까이 놓았다. 다만 아스트라는 코끝이, 솔은 눈 주변선이 겹쳐서 실제 연결 관계는 따로 확대해 볼 필요가 있다.

### [02:13–02:28] 별 일곱 개와 고리 행성 — 수량은 지켜도 분위기는 다르다
밤하늘에 별 일곱 개와 고리 있는 행성을 넣어 달라고 했고, 양쪽 모두 일곱 개의 별과 고리 행성이 보인다. 화자의 정리는 "같은 수량을 지켜도 그림의 분위기는 이렇게 달라진다"이다. 화면을 작게 줄였을 때 이야기의 중심이 남는지도 함께 보라고 덧붙인다.

### [02:27–02:45] 3번 주문 — 일부러 어려운 "차 따르는 손" (아스트라)
세 번째는 난이도를 의도적으로 올린 주문이다. 한 손은 주전자 손잡이를 잡고 다른 손은 찻잔을 들며, 주둥이에서 찻잔 안쪽까지 차가 끊기지 않고 이어져야 한다. 아스트라는 손톱과 손목선을 넣고 손잡이 구멍을 남겼으며, 세 개의 레몬도 앞쪽에서 잘 보인다.

### [02:45–03:04] 솔의 같은 장면 — 동작은 크지만 선이 겹친다
솔은 주전자를 화면 가득 키웠다. 동작은 눈에 들어오지만 굵은 손가락과 손잡이 선이 복잡하게 겹쳐서, 손가락이 손잡이를 감싸는지 주전자 몸통을 뚫고 지나가는지 판별이 어렵다.

> "제 눈에는 이 사례의 손과 소품 관계는 아스트라 쪽이 더 읽기 쉽습니다." [02:56] [의견]

바로 이어 유보를 단다 — "그래도 손가락을 사실적인 손처럼 믿을 수준은 아니다".

### [03:02–03:13] 물줄기의 출발점과 도착점
물줄기를 확대해 보면 두 모델 모두 주둥이와 찻잔 사이에 **연속된 물줄기**를 만들었다. 즉 이 까다로운 조건은 양쪽 다 통과했다. 대신 레몬은 컵과 손 뒤에 많이 가려졌다.

### [03:13–03:35] 4번 주문 — 두 층짜리 입체 서점과 "꺾이는 계단"
네 번째는 두 층짜리 입체 서점이고, 이번에는 **계단이 중간에서 꺾이는 형태**임을 아주 분명하게 지정했다. 책장과 책상, 두 사람, 네 개의 화분도 조건이다. 아스트라는 아래 계단과 위 계단의 방향을 다르게 잡아 발판에서 꺾이는 형태가 더 분명하고, 솔의 계단은 정면의 가로 막대가 겹친 모습에 가까워 꺾이는 입체 방향이 덜 명확하게 읽힌다.

### [03:35–03:56] 구조 판정 — 아스트라 우세, 다만 완벽은 아님
건물 전체보다 계단이 어디서 시작하는지를 본다. 아래층에서 출발해 중간의 평평한 발판을 지나고, 방향을 바꿔 위층 바닥에 닿아야 한다. 이 사례에서는 아스트라가 요청한 구조를 더 구체적으로 표현했다. 다만 아래 계단과 바닥, 인물과 카운터의 접점까지 완벽한 건 아니다.

### [03:55–04:10] 정보량 대 정확도 — "책이 많다고 공간이 정확한 건 아니다"
화자는 물량과 정확도를 분리한다. 아스트라는 작은 책과 자전거 바큇살까지 나눴고, 솔은 큰 덩어리로 정리했다.

> "저는 이 공간에서는 아스트라 쪽에 정보량이 좋았습니다." [04:00] [의견]

사람이 앉아 있는 위치, 가구가 바닥에 닿는 부분도 같이 보라고 안내한다.

### [04:08–04:29] 5번 주문 — 한글이 들어간 책 축제 포스터 (아스트라)
다섯 번째는 그림만 잘 그려서 끝나지 않는 과제다. 한글 제목·문구·날짜가 들어간 책 축제 포스터로, 제목은 "봄날의 책방", 그 아래에는 "책과 커피 그리고 우리"를 주문했다. 아스트라는 제목과 날짜를 왼쪽에 두고 독서하는 사람과 나무를 오른쪽에 모았으며, 여백이 넓고 제목 글꼴도 다르게 썼다.

### [04:29–04:46] 솔의 포스터와 한글 렌더링 검증
솔은 굵은 제목과 날짜 배지, 큰 꽃나무를 썼다. 정보는 강하게 보이지만 가장자리까지 그림이 꽉 차 있다. 한글 검증 결과, 제목·부제·날짜가 두 쪽 모두 요청한 문구로 들어갔다.

> "글자를 이미지로 흉내낸 것이 아니라 실제 텍스트입니다." [04:43]

### [04:46–05:03] 용도별 선택과 수정 실험 예고
멀리서 볼 때 제목이 먼저 읽히는지, 날짜를 찾기 쉬운지를 기준으로 제시한다.

> "차분한 행사 포스터라면 저는 아스트라를 고르겠습니다." [04:48] [의견]

반대로 크게 눈에 들어오는 구성을 원하면 솔의 방향도 비교할 만하다. 이 포스터 장면은 뒤에서 다시 등장하는데, **날짜 하나만 바꿔 달라고 했을 때 나머지를 지켜주는지**를 확인하기 위해서다.

### [05:02–05:26] 6번 주문 — 아이콘 세트 (통일성 시험)
여섯 번째는 카메라·자전거·현미경·커피포트·헤드폰·로봇 여섯 개짜리 아이콘 세트다. 선의 굵기, 모서리, 시각적 크기가 통일돼야 하는 과제다. 아스트라는 여섯 개 사이 간격을 충분히 남겨 모양을 하나씩 구분하기 편하고, 솔은 선과 크기를 더 굵게 잡았지만 카메라와 자전거가 가까이 붙고 아래 아이콘은 화면 끝에 닿는다.

### [05:25–05:46] 아이콘 판정 — 안정성은 아스트라, 굵은 선의 장점도 인정
가로로 넓은 물건(자전거)과 세로로 긴 물건(현미경)을 어떻게 맞췄는지 같은 자리에서 비교한다. 아스트라도 카메라와 현미경의 시각적 무게가 완전히 같지는 않지만, 이번 세트의 간격과 화면 여유[불명확: 원문 "강역과 화면 안유"]는 더 안정적이다. 실제 사용 기준은 "작은 크기에서도 무엇인지 알아볼 수 있는가"이고, 굵은 선은 작은 화면에서 선명하다는 장점이 있다 — 다만 크기를 줄이기 전에 잘린 부분과 아이콘 사이 간격을 먼저 고쳐야 한다.

### [05:46–06:07] 7번 주문 — 움직이는 에스프레소 머신 (실험의 핵심)
여기서부터가 이번 영상에서 꼭 보여주고 싶었던 부분이라고 화자가 명시한다. 두 모델에게 움직이는 에스프레소 머신을 직접 만들게 했고, **그림만 받은 뒤 화자가 임의로 흔드는 실험이 아니다** — 각 모델이 부품을 그리고 무엇을 언제 움직일지도 따로 작성했다. 요구 동작은 레버를 당기고 기어가 돌고 압력계와 커피 추출이 이어지는 순서다.

### [06:06–06:26] 첫 동작 결과 — 양쪽 다 결함
아스트라는 작은 톱니와 배관까지 세밀하게 그렸지만, 첫 동작에서 **레버가 몸체에서 떨어지고 압력 바늘이 밖으로 나간다**. 솔은 큰 기어와 굵은 배관으로 움직임을 강조했는데, 이쪽도 압력계 바늘이 다이얼 중심을 축으로 자연스럽게 돌지는 않는다.

### [06:26–06:49] 기어 회전 방향과 커피 추출 시점
둘을 함께 재생하면 순서와 리듬이 비교된다. 확인 포인트는 기어가 같은 방향으로 돌기만 하는지, 맞물리는 방향을 고려했는지다. 결과적으로 **두 모델 모두 기어를 반대 방향으로 회전**시켰다 — 다만 방향이 반대라고 톱니의 접촉까지 정확해지는 것은 아니다. 커피 추출과 증기 동작도 양쪽 모두 들어갔다.

> "여기서는 정교한 그림을 그렸다는 사실만으로 애니메이션까지 합격시킬 수 없었습니다." [06:45]

### [06:49–07:19] 보정 요청과 그 결과, 그리고 녹화 방식 고지
그래서 두 모델에 **부품의 연결과 회전축을 고쳐 달라는 같은 요청**을 추가했다. 보정본에서는 레버와 기어가 제자리를 지키도록 다시 잡혔고, 아스트라는 섬세한 기계 묘사를, 솔은 큼직한 실루엣을 유지했다. 다만 톱니의 맞물림과 커피 표현은 여전히 단순한 일러스트 동작 수준이다.

> "정지 화면의 완성도와 애니메이션의 완성도가 나뉘는 지점이에요." [07:07]

또 하나의 고지 — 이 장면은 각 모델이 작성한 **10초 동작을 반복 재생**하는 화면이며, 실시간 모델 생성 속도를 녹화한 것이 아니다.

### [07:19–07:47] 8번 주문 — 하늘을 나는 작은 배
마지막 그림은 하늘을 나는 작은 배로, 돛과 탐험가, 매달린 등불, 새, 여러 층의 구름을 넣었다. 요청한 이야기는 "배가 들어오고 돛이 펼쳐지고 새가 앞을 지나가는" 짧은 시퀀스다. 아스트라는 고글과 조타 장치, 나무 무늬까지 넣고 작은 섬을 배 아래에 배치해 이야기의 공간을 만들었다. 솔은 배와 돛을 크게 잡고 굵은 선으로 구분했지만, **요청했던 작은 섬이 아래가 아니라 왼쪽 위에 걸쳐 있다**(조건 위반).

### [07:47–08:11] 움직임 검증 — 확대만으로는 "움직였다"고 안 친다
화자는 배를 확대하는 효과만으로 움직였다고 말하지 않겠다고 선을 긋고, 돛과 등불과 새가 따로 움직이는지 확대해서 본다. 두 모델 모두 부품을 따로 움직이게 했다. 그런데 첫 아스트라 동작에서는 **등불과 줄이 서로 분리되는 문제**가 보였다. 앞쪽 구름과 뒤쪽 구름이 서로 다른 속도로 움직여 앞뒤 깊이가 달라 보이고, 새가 배 앞을 지나는 순간에는 겹침 순서도 비교할 수 있다.

### [08:10–08:29] 보정 후 — 각자 다른 방식으로 개선
보정 후 아스트라는 등불의 줄까지 함께 흔들리게 연결했다. 솔은 새의 동선을 위로 올려 탐험가 얼굴을 덜 가리게 했다. 다만 두 버전 모두 돛 크기를 키워 펼치는 방식이라 **천이 실제로 접히는 움직임까지는 아니다**. 중심을 보는 동안 주변 동작이 방해하지 않는지도 같이 살펴보라고 권한다.

### [08:29–08:59] 제한 수정 요청 실험 — 색과 날짜만 바꿔라
앞서 만든 두 결과에 수정 요청을 넣었다. 아이콘에서는 **산호색만 없애고 모양과 위치는 유지**해 달라고 했고, 포스터에서는 **날짜를 바꾸고 찻잔 색만 산호색으로** 바꿔 달라고 했다. 둘 다 그림을 새로 그려 달라는 요청이 아니다. 결과적으로 아이콘 수정에서 두 모델 모두 색상만 바꿨고 좌표·크기·도형의 모양은 그대로였다. 포스터도 양쪽 모두 지정한 날짜와 찻잔 채움색[불명확: 원문 "차잔 체험생"]만 바꿨고, 다른 문구나 그림을 새로 만들지 않았다. 검증은 **화면 비교와 파일 비교를 같이** 했다.

### [08:59–09:12] 수정 정확도의 의미 — 첫 완성도와 별개
이번 두 가지 제한된 수정은 둘 다 정확했다. 화자의 해석은 "첫 그림의 완성도 차이가 수정도의 차이로 그대로 이어지지는 않았다"는 것이다. 잘 그린 첫 결과가 있어도 수정할 때 다른 부분까지 흔들리면 곤란하고, 반대로 원하는 부분만 바뀌면 실제 작업에 연결하기가 훨씬 편해진다. 단, 오늘 확인한 것은 **색상과 문구를 바꾸는 좁은 조건**뿐이라는 범위 한정도 함께 붙인다.

### [09:12–09:34] 총평 — 취향과 조건 준수를 분리
여덟 가지 주문과 두 가지 수정 조건을 비교한 결과다.

> "제 취향으로는 이번 일러스트에서 아스트라의 여백과 작은 디테일, 공간 구성이 더 마음에 들었습니다." [09:18] [의견]

동시에 솔의 굵은 실루엣과 직관적인 큰 형태도 장점이라고 인정한다. 날짜·색상 수정은 두 모델 모두 정확했다. 중요한 방법론적 태도로, 화자는 "**내가 더 마음에 든 장면**"과 "**조건을 더 잘 지킨 장면**"을 구분했다고 밝힌다.

### [09:34–09:57] 마무리 — 한계 고지와 자료 공개
일러스트와 손의 연결, 공간의 계단, 움직임의 순서는 서로 다른 문제였다는 것이 정리다. 그럼에도 말로 주문한 장면이 그림과 움직임으로 연결되는 건 확실히 재미있다고 소감을 남긴다.

> "진짜 AGI 같다는 감탄은 이런 순간에 나오는 것 같아요." [09:45] [의견]

마지막으로 범위를 다시 좁힌다 — 이 여덟 사례가 모든 작업의 성능을 증명하는 것은 아니다. 원본과 수정본, 실제 요청 문장과 모션 파일까지 함께 남겨두겠다고 예고하며, 시청자에게 직접 비교해 보라고 권하며 끝낸다.
