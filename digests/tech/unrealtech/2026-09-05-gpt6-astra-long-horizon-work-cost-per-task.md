## 요약 (주제별)

### 1. 출시 타임라인 — 사흘 사이 3사 최신 모델
- 9월 1일 앤트로픽 **클로드 페이블 5.1**, 9월 2일 구글 **제미나이 3.8 플래시**, 9월 3일 오픈AI **GPT6 아스트라(Astra)**.
- 아스트라는 일부 조직 대상 제한 배포로 먼저 나갔고, 이후 ChatGPT 플러스·프로·비즈니스·엔터프라이즈와 API로 순차 확대 중. 전면 개방이 아니라 단계적 롤아웃 상태.

### 2. 아스트라 초기 사용 사례 (모두 화자 인용, 출시 초기 일부 사례)
- **닷새 연속 게임 제작**: AI 크리에이터 매튜 버먼(자막 음차 "메우 벌맨")이 심시티 스타일 게임을 맡긴 뒤 장기 작업을 닷새 연속 구동 — 데모 공개 시점에도 여전히 작업 중이었다.
  - 화자의 오해 차단: 모델 **한 번의 응답**이 닷새 이어진 게 아니라, **코덱스의 장기 작업 환경**에서 하나의 목표를 유지하며 만들고 수정하는 과정을 이어간 것. (해당 슬래시 명령의 정확한 명칭은 [불명확: 자막 원문 "슬래시골"].)
- **3D 데모(오픈AI 직접 공개)**: 블렌더에서 집을 모델링 → 결과물을 언리얼 엔진 5로 이전 → 내부를 실제로 걸어다닐 수 있는 공간까지 제작.
- 초기 사용자 반응도 장시간 작업·3D 제작 능력에서 좋은 편. 단 화자는 "출시 초기 일부 사례를 전체 성능으로 일반화할 수 없다"고 명시.
- 요점은 "답변을 잘한다"가 아니라 **한번 맡긴 일을 오래 붙잡고 결과물을 계속 만들어낸다**는 것.

### 3. 학습 규모 — 10만 GPU 초과, 오픈AI 역사상 최대
- 오픈AI 연구 부사장 **에이든 클라크**: 아스트라는 회사 역사상 가장 큰 학습이며, **텍사스 스타게이트에서 처음으로 10만 개가 넘는 GPU를 하나의 사전 학습에 사용**(주장/미검증).
- 화자 표현: "GPT 하나를 만들기 위해 거대한 AI 데이터센터의 컴퓨팅을 통째로 동원하는 규모."
- 스타게이트에는 지난해부터 엔비디아 **GB200 랙**이 투입되기 시작. 단 아스트라의 정확한 GPU 구성은 미공개 → **10만 개 전부가 GB200이라고 말할 수는 없음**(화자가 명시적으로 단정 회피).
- 다만 GPT 세대가 **블랙웰급 대형 클러스터가 실제 가동되는 시기**에 들어선 건 분명하다고 봄([의견]).

### 4. 벤치마크 — 종합 1등은 GPT6가 아니다
- **Artificial Analysis 종합 지표**(화자 인용): 클로드 페이블 5.1 **65.7점** > GPT6 아스트라 **61.2점** > 제미나이 3.8 플래시 **58.7점**.
- GPT6가 앞서는 평가도 많지만, 10만 GPU를 쓴 신형 GPT가 **모든 영역에서 압도적 1등이 된 건 아니다**.
- **오토메이션 벤치**(여러 프로그램을 오가며 업무를 끝까지 처리): GPT 5.6 솔 **18.1%** → GPT6 아스트라 **41.4%**, 클로드 페이블 5.1 **31.4%**. (이전 세대 모델명은 자막 음차가 "소홀/솔"로 흔들림 — [불명확: 정확한 표기].)
- 화자 균형: 세대 차이는 크지만 사용자 입장에선 **여전히 절반 이상의 작업을 완벽히 끝내지 못한다**는 뜻.

### 5. 컴퓨팅이 향한 곳 — "컴퓨터를 직접 쓰며 긴 일을 끝내는 능력"
- 오픈AI가 크게 끌어올린 지점은 종합 지능이 아니라 **컴퓨터 직접 사용 + 장기 업무 완수**.
- **메일 예시**: "지난달 자료를 최신 숫자로 고치고 이번 주 가능한 날짜도 확인해서 보내 주세요." 답장만 쓰는 건 요즘 AI도 잘함. 그러나 일을 통째로 넘기면 파일 탐색 → 내용 판단·수정 → 일정 확인 → 최종 전달까지, **앞 정보를 기억하며 여러 행동을 연속 성공**시켜야 하는 문제로 성격이 바뀜.
- **43% 산수**: 각 행동 성공률을 90%로 가정해도 8단계를 한 번에 통과할 확률은 약 **43%**. 화자는 실제 오류가 독립 발생하는 건 아니라고 단서를 달면서도, 짧은 질문엔 강한 AI가 긴 업무에서 급격히 실패하는 이유를 이해하기 좋은 예시라고 봄([의견]).

### 6. 사업 맥락 — 엔드투엔드 워크와 기업 시장
- 오픈AI 매출에서 **기업 사업 비중이 빠르게 확대 중**(주장/미검증). ChatGPT·코덱스도 "답을 만들어 준다"에서 "사용자가 하던 일을 직접 처리한다"로 확장.
- 수요 흐름 논리: "이 자료를 어떻게 고치면 될까"라고 묻는 사용자가 늘면 다음은 **"네가 고쳐 줘"**. 코드도 설명에서 끝나는 게 아니라 파일을 열어 수정하고 테스트까지 실행.
- GPT6는 오픈AI가 **엔드투엔드 워크**를 특히 강조한 모델.

### 7. 시스템 카드 — 사이버 보안 '크리티컬' 첫 진입
- 최신 소프트웨어 취약점 평가 과정에서 아스트라가 **아직 알려지지 않은 제로데이 취약점을 직접 발견해 공격 경로에 사용**(오픈AI 시스템 카드, 화자 인용).
- 전문가 주도 평가에서 구성한 체인 두 가지:
  - **하드닝된 브라우저** 샌드박스 탈출 → 호스트에서 명령 실행하는 전체 공격(익스플로잇) 체인
  - **하드닝된 OS** 내에서 비권한 사용자 → 루트 권한으로 올라가는 로컬 권한 상승 체인
- 그 결과 GPT6는 오픈AI 모델 중 **처음으로 사이버 보안 능력 기준 '크리티컬' 단계**에 진입.
- **크리티컬의 정의**: 충분한 도구·접근 권한이 주어졌을 때, 사람의 디테일한 지시 없이도 새 취약점을 찾고 검증해 실제 공격 체인으로 연결할 수 있는 기반 능력.
- 대응: 아스트라 자체가 순차 배포 중이고, 실제 ChatGPT 제품에는 **별도 안전장치와 권한 제한**이 적용됨.

### 8. AI가 AI를 학습시키는 평가 — 그리고 화자의 과장 차단
- 오픈AI는 GPT6에게 **다른 AI의 학습 개선**을 맡겨 봤다. 작은 언어 모델의 학습 코드 + 제한된 컴퓨팅 환경을 주고, 정해진 시간 안에 코드를 고치고 학습 설정을 바꿔 성능을 높이게 함.
- **포스트트레인 벤치 계열** 평가에서도 작은 오픈소스 모델과 GPU를 주고, 어떤 데이터를 쓸지·무엇을 다시 학습할지를 스스로 결정하게 함.
- 화자의 단서: GPT6가 자기보다 좋은 GPT7을 혼자 만든다는 뜻이 **아니고**, 작은 모델·제한 환경 평가이며, 오픈AI도 이 항목에서 아스트라가 **자사 '하이 케이퍼빌리티' 기준에는 미도달**이라고 판단.
- 그럼에도 장면 자체는 인상적 — 10만 GPU로 GPT6를 만든 뒤, 그 GPT6에게 제한된 GPU를 주고 "네가 AI를 더 잘 학습시켜 봐라"라고 시킨 구도([의견]).

### 9. 3사 전략 차이 (모두 화자 관점 [의견])
- **오픈AI**: 컴퓨터 직접 조작 + 엔드투엔드 장기 업무 완수. 기업 매출 확대와 ChatGPT·코덱스 제품 방향이 맞물림.
- **앤트로픽**: 페이블 5.1에서 **몇 시간 이어지는 어려운 작업**을 반복 강조 — 거대 프로그램 전체 수정, 다량 문서 독해·결과물 생성, 중간 실패해도 재시도하며 계속 진행. 클로드를 특정 서비스 하나에 묶지 않고 여러 기업 시스템·클라우드에 투입 → **개발·법률·금융처럼 사람이 오래 붙잡던 값비싼 지식 업무**에 강점.
- **구글**: 출발점이 다름. **워크스페이스 + 구글 클라우드 + 자체 TPU**를 이미 보유 → 제미나이를 넣을 장소를 새로 만들 필요 없이, **사람들이 이미 쓰는 서비스에서 계속 호출**되게 만들 수 있음. 메일·문서·기업 서버에서 다수 에이전트 동시 구동.

### 10. 가격 — 13배 차이, 그러나 '토큰 단가'가 답이 아니다
- **API 100만 토큰당**(화자 인용): GPT6 및 클로드 페이블 5.1 = 입력 **$10** / 출력 **$50**. 제미나이 3.8 플래시 = 올해 말까지 입력 **$0.75** / 출력 **$3.75** → **약 13배 차이**.
- 구글은 '플래시'지만 가벼운 보조 모델이 아니라 **장시간 소프트웨어 개발·자율 에이전트까지 커버하는 주력 모델**로 포지셔닝.
- 단 **13배 싸다고 실제 업무가 13배 싸지지 않는다**: 긴 일을 맡기면 **호출 1회 가격 ≠ 작업 1건 완수 가격**. 파일을 잘못 찾아 재검색, 코드를 틀리게 고쳐 재실행하면 호출이 계속 누적됨. 반대로 단가가 비싸도 시행착오가 적어 한 번에 끝내면 총 비용은 낮아질 수 있음.

### 11. 벤치캐드 사례 — 비싼 모델이 작업당 43% 저렴
- 아스트라는 GPT 5.6 솔보다 **토큰 단가가 약 2배 안팎 높음**.
- 그런데 3D 설계 작업 벤치마크 **벤치캐드(BenchCAD)**에서 오픈AI가 계산한 **작업 1건당 추정 API 비용은 오히려 약 43% 낮았다**(오픈AI 자체 계산, 화자 인용).
- 화자의 단서 두 가지: ① 솔에 **프로모션 가격**이 별도 적용 중이라 정확한 배수는 기준 가격에 따라 달라짐, ② 이건 **회사 자체 평가이고 특정 테스트에서 나온 숫자**.
- 그럼에도 **더 높은 성공률 + 적은 시행착오 → 최종 작업 비용 하락**이라는 사례가 실제로 나왔다는 게 요점.

### 12. 화자의 결론 — 앞으로 봐야 할 두 개의 숫자
- 지금까지 AI 가격표에서 가장 먼저 보던 건 "100만 토큰이 몇 달러인가"였다.
- 사람에게 한 시간짜리 일을 넘기듯 AI에게 일을 통째로 맡기기 시작하면 옆에 붙어야 할 숫자([의견]):
  1. **일을 시키면 몇 번이나 제대로 끝내는가**(성공률)
  2. **제대로 끝난 일 하나에 실제로 얼마가 들었는가**(작업당 비용)
- 이 두 숫자의 변동 속도가 앞으로 GPT·클로드·제미나이의 차이를 훨씬 현실적으로 보여 줄 가능성이 높다.
- 마무리 문장: "AI와 대화하는 시간이 늘어나는 것"과 "내가 하던 일을 AI에게 실제로 넘겨 놓는 것"은 전혀 다른 문제.

## 3줄 오리엔테이션
- 2026년 9월 1~3일 사흘 사이에 앤트로픽 클로드 페이블 5.1, 구글 제미나이 3.8 플래시, 오픈AI GPT6 아스트라가 연달아 나왔고, 아스트라는 10만 개가 넘는 GPU를 하나의 사전 학습에 투입한 오픈AI 역사상 최대 규모 학습이다(화자 인용).
- 그런데 종합 지능 지표에서 GPT6가 1등이 아니다. 오픈AI가 그 컴퓨팅으로 집중해 끌어올린 건 "컴퓨터를 직접 쓰면서 긴 업무를 끝까지 끝내는" 능력이고, 그 결과 사이버 보안 위험 등급은 처음으로 '크리티컬'에 진입했다.
- 마지막 논점은 가격이다. 제미나이 3.8 플래시가 토큰 단가로 13배 싸지만, 화자는 앞으로 봐야 할 숫자가 "100만 토큰당 몇 달러"가 아니라 "일을 몇 번이나 제대로 끝내는가 + 끝낸 일 하나에 얼마가 들었는가"로 옮겨간다고 본다.

얼리 액세스로 아스트라를 써온 AI 크리에이터 매튜 버먼(Matthew Berman, 자막 음차 "메우 벌맨")이 심시티 스타일 게임 하나를 만들어 보라고 맡긴 뒤 장기 작업을 닷새 동안 연속으로 돌렸는데, 데모를 공개할 때까지도 아스트라가 작업을 계속하고 있었다고 한다(화자 인용, 미검증). 화자는 여기서 곧바로 오해를 차단한다 — 모델 한 번의 응답이 닷새 이어졌다는 뜻이 아니라, 코덱스의 장기 작업 환경에서 하나의 목표를 계속 유지하면서 만들고 수정하는 과정을 이어간 사례라는 것이다. (자막상 "슬래시골 작업"이라는 표현이 나오는데, 코덱스의 슬래시 명령 계열로 보이나 정확한 명칭은 [불명확: 원문 "슬래시골"].)

### [00:58–01:10] 초기 사용 사례 ② — 블렌더에서 언리얼 엔진 5로 이어진 3D 데모
3D 쪽에서는 오픈AI가 직접 공개한 데모가 있다. 아스트라가 블렌더에서 집을 모델링한 다음, 그 결과물을 언리얼 엔진 5로 옮겨서 실제로 내부를 걸어다닐 수 있는 공간까지 만들었다는 내용이다(오픈AI 공개 데모, 화자 인용).

### [01:10–01:28] 초기 반응과 화자의 유보
초기 사용자들 사이에서도 이런 장시간 작업 능력과 3D 제작 능력 때문에 반응이 꽤 좋다고 한다. 다만 화자는 아직 출시 초기의 일부 사례를 전체 성능으로 일반화할 수는 없다고 선을 긋는다. 그럼에도 이번에 눈에 띄는 지점은 "답변을 잘하는 것"이 아니라 **한번 맡긴 일을 오랫동안 붙잡고 결과물을 계속 만들어내는 모습**이라고 정리한다.

> "단순히 그냥 답변을 잘하는 것보다 한번 맡긴 일을 오랫동안 붙잡고 결과물을 계속해서 만들어내는 그런 모습이 눈에 띄는 거죠." [01:21]

### [01:29–01:52] 학습 규모 — 오픈AI 역사상 최대, 10만 GPU 초과
이런 결과물을 만든 GPT6의 학습 규모에서 더 큰 숫자가 나온다. 오픈AI 연구 부사장 에이든 클라크(Aidan Clark)에 따르면 아스트라는 회사 역사상 가장 큰 학습이었고, 텍사스 스타게이트에서도 처음으로 10만 개가 넘는 GPU를 하나의 사전 학습에 사용했다(화자 인용, 미검증). 화자는 이를 "GPT 하나를 만들기 위해 거대한 AI 데이터센터의 컴퓨팅을 통째로 동원하는 규모까지 온 것"이라고 표현한다.

### [01:53–02:09] GB200 랙과 '단정할 수 없는' 부분
스타게이트에는 지난해부터 엔비디아 GB200 랙이 들어가기 시작했다. 다만 아스트라에 사용된 GPU의 정확한 구성은 공개되지 않았기 때문에, 화자는 10만 개가 전부 GB200이었다고 말할 수는 없다고 명시한다. 그래도 GPT 세대가 블랙웰급 대형 클러스터가 실제 가동되는 시기에 들어선 것은 분명하다고 본다([의견]).

### [02:10–02:36] 그런데 종합 지표 1위는 GPT6가 아니다
그 정도 컴퓨팅을 넣었다면 다른 모델을 멀찍이 따돌렸을 것 같지만, 결과는 그렇게 단순하지 않다. Artificial Analysis 종합 지표에서 클로드 페이블 5.1이 65.7점, GPT6 아스트라가 61.2점, 제미나이 3.8 플래시가 58.7점이다(화자 인용). 화자는 GPT6가 앞서는 평가도 많다고 덧붙이면서도, 10만 GPU를 쓴 신형 GPT가 모든 영역에서 압도적 1등이 된 건 아니라고 정리한다.

### [02:37–02:45] 그 많은 컴퓨팅이 향한 곳 — "컴퓨터를 직접 쓰며 긴 일을 끝내는 능력"
그렇다면 오픈AI가 그 컴퓨팅으로 크게 끌어올린 부분은 어디인가. 화자는 그것이 **컴퓨터를 직접 사용하면서 긴 일을 끝내는 능력**이라고 짚는다. 이 영상 전체의 축이 되는 문장이다.

### [02:46–03:09] 메일 예시로 본 '긴 업무'의 구조
예시는 이렇다. "메일로 지난달 자료를 최신 숫자로 고치고, 이번 주에 가능한 날짜도 확인해서 보내 주세요." 답장만 쓰는 것은 요즘 AI가 잘한다. 그러나 일을 통째로 넘기면 파일을 찾고, 내용을 판단해 수정하고, 일정까지 확인한 다음 최종 결과를 전달해야 한다 — 앞에서 얻은 정보를 계속 기억하면서 여러 행동을 연속으로 성공시켜야 하는 문제로 성격이 바뀐다.

### [03:10–03:30] 90%를 여덟 번 통과하면 43%
화자는 아주 단순한 산수로 실패 구조를 설명한다. 각각의 행동을 90% 확률로 성공한다고 가정해도, 여덟 단계를 전부 한 번에 통과할 확률은 약 43%까지 내려간다. 실제 오류가 이렇게 독립적으로 발생하는 건 아니라고 단서를 달면서도, 짧은 질문에는 잘 대답하던 AI가 긴 업무에서 갑자기 많이 실패하는 이유를 이해하기엔 좋은 예시라고 본다([의견]).

### [03:31–03:57] 오토메이션 벤치 — 18.1% → 41.4%
여러 프로그램을 오가면서 업무를 끝까지 처리시키는 오토메이션 벤치에서 GPT 5.6 솔은 18.1%, GPT6 아스트라는 41.4%를 기록했고, 클로드 페이블 5.1은 31.4%였다(화자 인용). (자막 음차상 이전 세대 모델명은 "소홀/솔"로 나오는데 여기서는 GPT 5.6 솔로 표기한다 — [불명확: 정확한 표기].) 화자는 18.1%에서 41.4%면 세대 차이가 꽤 크다고 평가하면서도, 사용자 입장에서는 여전히 **절반 이상의 작업을 완벽하게 끝내지 못한다는 뜻**이기도 하다고 균형을 잡는다.

### [03:57–04:25] 이 능력에 자원을 쏟는 사업적 이유
오픈AI가 이 능력에 많은 자원을 쓰는 이유는 현재 사업과도 잘 맞는다. 오픈AI 매출에서 기업 사업의 비중이 빠르게 커지고 있고(화자 주장, 미검증), ChatGPT와 코덱스도 답을 만들어 주는 것에서 사용자가 하던 일을 직접 처리하는 방향으로 확장 중이다. 화자의 논리는 수요 흐름이다 — "이 자료를 어떻게 고치면 될까"라고 묻는 사용자가 늘어나면, 다음 단계는 수정 방법을 설명하는 데서 끝나는 게 아니라 AI가 직접 고쳐 주기를 원하게 된다는 것.

> "자, 그럼 네가 고쳐 줘. 이렇게 요청을 할 거예요." [04:25]

### [04:26–04:41] 엔드투엔드 워크를 강조한 모델
코드도 마찬가지로, 설명해 주는 데서 끝나는 게 아니라 파일을 열어 수정하고 테스트까지 돌리는 방향이다. GPT6 역시 오픈AI가 처음부터 끝까지 이어지는 업무, 즉 **엔드투엔드 워크**를 특히 강조한 모델이라고 화자는 정리한다.

### [04:41–05:12] 시스템 카드 — 아스트라가 미공개 제로데이를 직접 찾아 사용
시스템 카드를 보면 이 능력이 훨씬 어려운 환경에서 어디까지 올라왔는지가 나온다. 오픈AI가 최신 소프트웨어 취약점을 대상으로 평가하던 과정에서, 아스트라가 아직 알려지지 않은 제로데이 취약점을 직접 찾아내 공격 경로에 일부러 사용했다(오픈AI 시스템 카드, 화자 인용). 전문가 주도 평가에서는 하드닝된 브라우저에서 샌드박스를 탈출해 호스트에서 명령을 실행하는 전체 공격(익스플로잇) 체인과, 하드닝된 운영체제 안에서 비권한 사용자로부터 루트 권한까지 올라가는 로컬 권한 상승 체인도 구성했다.

### [05:12–05:18] 사이버 보안 '크리티컬' 첫 진입
그 결과 GPT6는 오픈AI 모델 가운데 처음으로 회사의 사이버 보안 능력 기준에서 **크리티컬 단계**에 들어갔다.

### [05:18–05:38] '크리티컬'의 정의와 배포 제한
화자는 크리티컬이 무엇을 의미하는지 풀어 준다. 충분한 도구와 접근 권한을 줬을 때, 사람의 디테일한 지시 없이도 새로운 취약점을 찾아내고 검증해 실제 공격 체인으로 연결할 정도의 기반 능력이 생겼다는 의미다. 그래서 아스트라 자체도 순차 배포 중이고, 실제 ChatGPT 제품에서는 별도의 안전장치와 권한 제한이 적용된다.

### [05:38–06:14] AI에게 AI 학습을 맡겨 본 평가
오픈AI는 GPT6에게 다른 AI의 학습을 개선하는 일도 맡겨 봤다. 작은 언어 모델의 학습 코드와 제한된 컴퓨팅 환경을 주고, 정해진 시간 안에 직접 코드를 고치고 학습 설정을 바꿔 성능을 높여 보게 한 것이다. 포스트트레인 벤치 계열 평가에서도 작은 오픈소스 모델과 GPU를 주고, 어떤 데이터를 쓰고 무엇을 다시 학습할지를 스스로 결정하게 했다. 화자는 곧바로 과장을 차단한다 — GPT6가 자기보다 좋은 GPT7을 혼자 만든다는 의미가 아니고, 작은 모델과 제한된 환경에서 진행한 평가이며, 오픈AI 역시 이 항목에서는 아스트라가 자사의 '하이 케이퍼빌리티' 기준에는 도달하지 못했다고 판단했다.

### [06:14–06:30] 그래도 인상적인 장면
그럼에도 장면 자체는 인상적이라고 화자는 말한다. 10만 개가 넘는 GPU로 GPT6를 만든 다음, 완성된 GPT6에게 제한된 GPU 자원을 주고 "이번에는 네가 AI를 더 잘 학습시켜 봐라"라고 시킨 구도이기 때문이다([의견]).

### [06:30–07:08] 앤트로픽의 전략 — 장시간 난이도 높은 지식 업무
GPT6·클로드·제미나이를 나란히 놓으면 세 회사가 최신 모델에 맡기려는 역할이 조금씩 다르게 보인다. 앤트로픽은 페이블 5.1에서 몇 시간 동안 이어지는 어려운 작업을 반복해서 강조했다 — 거대한 프로그램 전체를 수정하거나 많은 문서를 읽고 결과물을 만들면서, 중간에 실패해도 다시 시도하며 계속 진행하는 형태다. 앤트로픽도 기업 시장을 강하게 공략하는데, 클로드를 특정 서비스 하나에 묶기보다 여러 기업 시스템과 클라우드에 넣어서 개발·법률·금융처럼 **사람이 오랫동안 붙잡고 있던 값비싼 지식 업무**를 맡기는 쪽에 강점이 있어 보인다([의견]).

### [07:08–07:30] 구글의 전략 — 이미 가진 배포 장소
구글은 출발점이 다르다. 워크스페이스부터 구글 클라우드, 자체 TPU까지 이미 갖고 있기 때문에, 제미나이를 넣을 장소를 처음부터 새로 만들기보다 **사람들이 이미 쓰는 서비스에서 계속 호출할 수 있게** 만들 수 있다. 메일에서도 쓰고 문서에서도 쓰고, 기업 서버에서도 수많은 에이전트를 동시에 돌릴 수 있다는 것이다.

### [07:30–07:57] 제미나이 3.8 플래시 가격 — 13배 차이
가격도 이 방향과 맞아 보인다. GPT6와 클로드 페이블 5.1은 API 입력 100만 토큰당 10달러, 출력 50달러다. 제미나이 3.8 플래시는 올해 말까지 입력 0.75달러, 출력 3.75달러다(화자 인용). 화자는 "이게 13배 차이"라고 강조한다. 그리고 플래시라는 이름이 붙었지만 구글은 이번 모델을 가벼운 보조 모델이 아니라 **장시간 소프트웨어 개발과 자율 에이전트까지 커버하는 주력 모델**로 설명하고 있다고 덧붙인다.

### [07:57–08:24] 호출당 가격 ≠ 작업당 가격
그렇다고 제미나이가 13배 싸다고 실제 업무도 13배 싸지는 건 아니다. AI에게 긴 일을 시키기 시작하면 **한 번 호출할 때의 가격과 일 하나를 끝내는 가격이 달라지기** 때문이다. 파일을 잘못 찾아 다시 검색하고, 코드를 틀리게 고쳐 다시 실행하면 호출은 계속 쌓인다. 반대로 모델 한 번의 가격이 비싸도 적은 시행착오로 한 방에 끝내면 총 비용은 낮아질 수 있다.

### [08:24–08:56] 벤치캐드 사례 — 비싼 모델이 작업당 43% 저렴
GPT6에서 그 사례가 하나 나왔다. 아스트라는 GPT 5.6 솔보다 토큰 단가가 대략 두 배 안팎으로 높은 수준인데, 3D 설계 작업을 수행하는 벤치캐드(BenchCAD)에서는 오픈AI가 계산한 **작업 한 건당 추정 API 비용이 오히려 43% 정도 낮았다**(오픈AI 자체 계산, 화자 인용). 화자는 솔에 현재 프로모션 가격이 별도 적용되고 있어 정확한 배수는 어느 가격을 기준으로 하느냐에 따라 달라진다고 단서를 단다. 그래도 벤치캐드에서는 비싼 모델이 더 높은 성공률과 적은 시행착오로 최종 작업 비용을 낮춘 사례가 나온 것이다.

### [08:56–09:02] 단서 — 회사 자체 평가, 특정 테스트

### [09:02–09:29] 앞으로 봐야 할 두 개의 숫자
지금까지 AI 가격표에서 가장 먼저 확인하던 건 "100만 토큰이 몇 달러인가"였다. 그러나 사람에게 한 시간짜리 일을 넘기듯 AI에게도 일을 통째로 맡기기 시작하면, 옆에 다른 숫자가 하나 더 붙어야 한다는 게 화자의 결론이다 — **일을 시키면 몇 번이나 제대로 끝내는지**, 그리고 **제대로 끝난 일 하나에 실제로 얼마가 들었는지**. 이 두 숫자가 올라가고 내려가는 속도가 앞으로 GPT·클로드·제미나이의 차이를 훨씬 현실적으로 보여 줄 가능성이 높다고 본다([의견]).
